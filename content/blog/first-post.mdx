> **TL;DR:** Bài này hướng dẫn setup Ollama + OpenWebUI để chạy LLM hoàn toàn local, offline, không cần GPU xịn. Mất ~10 phút.

## Tại sao cần setup local?

- **Privacy**: Data không rời khỏi máy bạn
- **Offline**: Không cần internet để dùng
- **Miễn phí**: Không tốn chi phí API
- **Customizable**: thoải mái fine-tune, thêm model

OpenWebUI giống như ChatGPT nhưng chạy trên máy bạn. Ollama là runtime để chạy các model (Llama 3, Mistral, Phi3...).

## Prerequisites

- macOS / Linux / Windows (WSL2)
- RAM ≥ 8GB (16GB khuyến nghị)
- Disk ≥ 10GB free

## Step 1: Cài Ollama

### macOS / Linux

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### Windows

Download installer từ [ollama.com/download](https://ollama.com/download)

### Verify

```bash
ollama --version
```

### Pull model đầu tiên

```bash
ollama pull llama3.2
```

Model ~2GB, tùy speed internet. Sau khi xong:

```bash
ollama list
```

## Step 2: Chạy OpenWebUI

### Cách 1: Docker (recommended)

```bash
docker run -d \
  -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  --name open-webui \
  ghcr.io/open-webui/open-webui:main
```

### Cách 2: Không Docker

```bash
pip install open-webui
open-webui serve
```

### Truy cập

Mở browser: [http://localhost:3000](http://localhost:3000)

Đăng ký account đầu tiên → admin account.

## Step 3: Kết nối Ollama với OpenWebUI

OpenWebUI tự động nhận Ollama nếu nó chạy trên cùng máy.

### Verify kết nối

1. Vào Settings → Connections
2. Kiểm tra phần Ollama API
3. Status phải hiện "Connected"

### Test thử

1. Chọn model `llama3.2` từ dropdown
2. Gửi prompt bất kỳ
3. Nếu có response → thành công!

### Lỗi thường gặp

**Ollama không chạy?**

```bash
ollama serve
# keep terminal open
```

**OpenWebUI không nhận Ollama?**

Kiểm tra biến môi trường:

```bash
# macOS/Linux
export OLLAMA_BASE_URL=http://localhost:11434

# Windows (PowerShell)
$env:OLLAMA_BASE_URL="http://localhost:11434"
```

## FAQ

**Q: Cần GPU không?**
A: Không bắt buộc. Ollama chạy CPU được, nhưng chậm hơn nhiều so với GPU.

**Q: Dùng bao nhiêu RAM?**
A: Tùy model. Llama 3.2 1B cần ~1GB RAM, 3B cần ~4GB, 8B cần ~8GB.

**Q: Thay đổi model?**
A: Chạy `ollama pull <tên-model>`, vd: `ollama pull mistral`.

**Q: Ollama API có dùng được bên ngoài?**
A: Có, `curl http://localhost:11434/api/generate -d '{"model":"llama3.2","prompt":"hi"}'`
