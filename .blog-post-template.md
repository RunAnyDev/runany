# Blog Post Template for runany.dev

## File Location

Tất cả bài viết đặt tại: `apps/web/src/content/blog/`

## Frontmatter Schema

```yaml
---
title: "Tiêu đề bài viết"
description: "Mô tả ngắn 150-200 chars, cho SEO và AI extract"
pubDate: "2025-05-27"
tags: ["tag1", "tag2", "tag3"]
category: "ai-setup"  # hoặc: tutorial, dev-tools, self-hosted, review, news
author: "Du"
featured: false
draft: false
---
```

## Category Options

| Category | Use for |
|---|---|
| `ai-setup` | Setup AI tools, LLM, local inference |
| `tutorial` | How-to guides, step-by-step |
| `dev-tools` | Developer tools, editors, CLIs |
| `self-hosted` | Self-hosted services, VPS |
| `review` | Product/app reviews |
| `news` | Industry news, updates |

## Post Structure (AI-Friendly Format)

```
## TL;DR (optional - summary box sẽ extract)

> **TL;DR:** Một sentence tóm tắt nội dung bài viết.

## Section 1: Context/Why

- Context ngắn
- Problem being solved
- Target audience

## Section 2: Prerequisites

- List requirements
- Version numbers if specific

## Section 3: Main Content (Step-by-step)

### Step 1: Task name
Code blocks với language identifier

### Step 2: Another task

## Section 4: FAQ (optional)

**Q: Câu hỏi thường gặp?**
**A:** Trả lời ngắn gọn.

## Conclusion

Tóm tắt + next steps
```

## Example: Minimal Post

```mdx
---
title: "Cách setup Cursor AI trên macOS"
description: "Hướng dẫn setup Cursor AI editor trên macOS nhanh chóng."
pubDate: "2025-05-27"
tags: ["cursor", "editor", "ai"]
category: "dev-tools"
author: "Du"
draft: false
---

> **TL;DR:** Cài Cursor AI trong 5 phút, tích hợp GPT-4, tăng productivity.

## Tại sao dùng Cursor?

- **Speed**: GitHub Copilot nhanh hơn nhưng Cursor cho code quality tốt hơn
- **Context**: Hiểu full project structure
- **Pricing**: Miễn phí cho students

## Prerequisites

- macOS 13+
- Node 18+

## Step 1: Download & Install

Download từ [cursor.sh](https://cursor.sh), kéo vào Applications.

## Step 2: Connect API Key

1. Mở Preferences (Cmd+,)
2. Tab "Model"
3. Paste OpenAI key của bạn

## FAQ

**Q: Có dùng được Claude API không?**
**A:** Có, vào Preferences > Model > Anthropic.

## Next Steps

- Cài extension cho VSCode theme
- Explore Cmd+K cho code generation
```

## Commit Message Format

Khi commit bài viết mới, dùng format:

```
feat: add [slug] - [title]

- Category: [category]
- Tags: [tags]
- Description: [description]
```

## Workflow

1. **Tạo file**: `apps/web/src/content/blog/[slug].mdx`
2. **Viết content** theo structure trên
3. **Commit**: `git add apps/web/src/content/blog/[slug].mdx && git commit -m "feat: add [slug] - [title]"`
4. **Push**: `git push`
5. **CI/CD**: Vercel tự động rebuild

## Validation Checklist

- [ ] frontmatter đầy đủ (title, description, pubDate, tags, category)
- [ ] description ≤ 200 chars
- [ ] tags phù hợp, lowercase, hyphenated
- [ ] có TL;DR block (>)
- [ ] code blocks có language identifier (bash, python, javascript, etc.)
- [ ] headings hierarchy rõ ràng (H2 > H3)
- [ ] FAQ section nếu có nhiều câu hỏi thường gặp

## SEO Tips

- **Title**: ≤ 60 chars, chứa keywords chính
- **Description**: ≤ 160 chars, hấp dẫn để click
- **Headings**: chứa keywords, không spam
- **Links**: internal links cho SEO juice distribution
