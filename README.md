# RunAny

Local-first AI setup with Ollama + OpenWebUI.

## Apps

- `apps/web` - Web application
- `apps/api` - API server
- `apps/webhook` - Webhook service
- `packages/shared` - Shared packages

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```
