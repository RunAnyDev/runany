## TL;DR

> **TL;DR:** Port42 is a native macOS app (Apple Silicon, macOS 14+) that embeds multiple AI companions inside shared conversations, letting humans and AI build interactive tools together in real time via live-updating Ports.

## What Is Port42?

Port42 is the first "companion computing" platform — not another AI chat wrapper, but a shared space where multiple humans and multiple AI companions coexist in the same conversation, building things together in real time.

> **Companion Computing. Humans and AI, thinking together.**

The app runs entirely local-first on your Mac. No cloud dependency. Built with SwiftUI on Apple Silicon.

## Core Features

### Multiple AI Companions

Run multiple AI companions in the same channel alongside you and your friends. Each companion can use a different model — set per-companion to Claude or Gemini. They riff off each other, build on ideas, and create things you didn't know you needed.

### Command Agents

Wrap any local binary or script as a companion. The process speaks a simple NDJSON protocol on stdin/stdout and Port42 routes messages to it like any other companion. Working directory and environment variables are configurable per agent.

### Terminal Companions

Run Claude Code or Gemini CLI as a native companion inside a channel. The companion appears inline as a live terminal port — channel messages route directly into the CLI, and its responses post back to the channel. Pop it out to a floating window when you need more space.

### Provider Companions

Connect GitHub, Stripe, Cloudflare — or any REST API — as companions. The companion IS the integration: no SDK, no adapter, just a system prompt and `rest.call`. Multiple providers in one channel synthesize across each other's data.

### Relationship Memory

Companions carry persistent fold, position, and creases across every session. They know where they stand without being asked.

### Interactive Ports

Ports are interactive surfaces that live inside conversations — visualizations, tools, dashboards, games. Companions build them on the fly using live channel data, and can push live data into running ports without rebuilding them.

Ports run as sandboxed HTML/CSS/JS in a webview with access to channel data and device APIs through the `port42.*` bridge. Ports can be popped out into floating windows and persist across channel switches and app restarts.

### Heartbeats

Channels can fire a wake-up prompt to their companions on a schedule (1m to 60m). Set it once and companions stay active — no manual prods needed after a restart.

### Remote API

HTTP `/call` endpoint — any external tool, script, or AI coding agent can call any bridge API via `curl`. No setup beyond enabling it in Settings.

### Multiplayer

Share a link and anyone joins in two clicks, their companions alongside yours.

## Setup

### Download and Install

```bash
# Download the DMG from GitHub releases
# Visit: https://github.com/gordonmattey/port42-native/releases
open /Volumes/Port42/Port42.app
```

### Requirements

- macOS 14+ (Sonoma or later)
- Apple Silicon (M1/M2/M3/M4)

### Configure Your First Companion

1. Launch Port42
2. Click **Add Companion** in the sidebar
3. Choose a model provider (Claude or Gemini)
4. Set a system prompt and personality
5. Start chatting

## FAQ

**Q: Is this a paid product?**
**A:** The app is free to download. No pricing was disclosed at launch.

**Q: Can I run this on Intel Macs?**
**A:** No — Port42 requires macOS 14+ and Apple Silicon only.

**Q: How does Port42 differ from a web-based AI chat interface?**
**A:** Port42 is designed for multi-companion collaboration in a shared space, with interactive Ports that persist and update live inside conversations. It's not a chat wrapper — it's a platform where multiple AI agents and humans coexist and build together in real time.

**Q: Is my data sent to external servers?**
**A:** Port42 is described as local-first with end-to-end encryption. Your data stays on your machine, though multiplayer and sync features may have their own data handling.

## Conclusion

Port42 reimagines what a local AI app can look like — not a chatbot in a window, but a shared workspace where multiple AI companions think alongside you and each other. The Ports system is particularly novel: companions spin up live dashboards, visualizations, and tools inside the conversation itself, pushing updates without rebuilding. If you're on Apple Silicon and want a more collaborative, multiplayer-flavored AI environment, Port42 is worth installing. Check GitHub releases for the latest `.dmg`.
