## What Is Armature?

Armature is a product analytics and evaluation platform purpose-built for AI agents built on the Model Context Protocol (MCP). It captures sessions from MCP servers, Claude Connectors, and ChatGPT Apps, then turns real user workflows into reusable eval suites.

The core problem it solves: when an agent breaks in production, you have no visibility into *what the user was trying to do*, *where the agent thought it was going wrong*, and *which specific call failed*. Armature reconstructs the full trace — user intent, agent reasoning, tool calls, and outcome — for every session.

Key capabilities:

- **Session replay** — full agent trace with user intent, thinking, tool calls, and a pass/fail score
- **Use case discovery** — AI groups sessions by what users came to do, ranked by volume and success rate
- **Issue detection** — catches agent loops, dead ends, and silent failures even when every API response was HTTP 200
- **Auto-eval generation** — prompts your coding agent to draft evals from real sessions in three lines of code
- **PII redaction** — detection models scan and redact personal information and secrets before storage

## Setup Workflow

### Step 1: Generate an API Key

Sign up at [armature.tech](https://armature.tech) and generate an `ARMATURE_API_KEY`. Add it to your deployment secrets.

### Step 2: Install the SDK

```bash
npm install @armature-tech/mcp-analytics
```

Or via Python (if available):

```bash
pip install armature-sdk
```

### Step 3: Wire the SDK into Your MCP Server

Follow the guide at [docs.armature.tech](https://docs.armature.tech). The SDK provides a prompt that your coding agent uses to instrument the server — you paste the prompt, and the agent handles the integration.

### Step 4: Deploy and Watch Sessions Flow In

Ship the instrumented MCP server. Sessions appear in the Armature dashboard within minutes. Each session is scored against criteria you define, and real agents run every eval end-to-end on all major models.

## Security Notes

Armature processes potentially sensitive agent sessions that may contain personal information, secrets, and proprietary workflow data. The platform applies automatic redaction to PII and secrets before storage. Review your data retention policies and ensure your use case complies with the AI provider terms (Anthropic, OpenAI) relevant to your agent's telemetry.

## FAQ

**Q: Does Armature work with MCP servers outside the Claude ecosystem?**
**A:** Yes. Armature supports MCP servers broadly, including connectors for ChatGPT Apps and any MCP-compliant client.

**Q: How is the eval scoring calculated?**
**A:** You define criteria for each eval. Armature runs a judge model against those criteria on every session, producing a score from 0 to 100.

**Q: What happens to my session data?**
**A:** Sessions are scanned and redacted automatically. You retain control over your data and can delete sessions at any time.
