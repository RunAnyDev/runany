Astro 5 brings powerful new features for building content-driven websites. In this guide, we'll explore the key concepts.

## What is Astro?

Astro is a static site generator that ships zero JavaScript by default, making your pages incredibly fast.

## Key Features

- **Content Collections**: Type-safe content management
- **MDX Support**: Write JSX in your markdown
- **Partial Hydration**: Only load JavaScript when needed

## Getting Started

Create your first Astro project:

```bash
npm create astro@latest
```

## Conclusion

Astro 5 makes building fast websites easier than ever.
