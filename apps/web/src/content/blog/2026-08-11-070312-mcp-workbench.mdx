## What Is MCP Workbench?

MCP Workbench is a browser-based visual debugger and test client for servers built on the **Model Context Protocol (MCP)** — the open standard that lets AI assistants like Claude connect to external tools and data sources.

If you are building an MCP server or integrating one into an AI agent pipeline, you need to verify that:
- Your server correctly advertises its available **tools** and **resources**
- Incoming JSON-RPC requests are properly formatted
- Responses conform to the MCP spec
- **OAuth 2.0 authentication** flows work end-to-end

MCP Workbench gives you a GUI for all of the above, instead of debugging raw HTTP streams with curl.

## Setup Workflow

MCP Workbench requires no installation — it runs entirely in the browser at [mcp-workbench.ai](https://www.mcp-workbench.ai).

### Step 1: Connect Your MCP Server

Open the app and point it at your server's **Streamable HTTP** endpoint. The workbench supports authentication via Bearer tokens.

```text
Server URL: https://your-mcp-server.example.com/mcp
Auth token: (your Bearer token if required)
```

### Step 2: Inspect the Server Manifest

Once connected, MCP Workbench reads and displays your server's manifest — the list of available tools, resources, and their parameter schemas. You can browse these without sending any requests.

### Step 3: Test Individual Tools

Select any tool from the manifest and invoke it with custom arguments. The workbench shows:
- The full **JSON-RPC request** sent to your server
- The **raw response** payload
- Any errors with line-level detail

### Step 4: Inspect OAuth Flow

If your MCP server uses OAuth 2.0, MCP Workbench has a dedicated OAuth inspector panel that walks through the authorization code flow and displays token exchange details.

## Practical Evaluation Checklist

- Works entirely in-browser, no desktop app or CLI required

## Security Notes

- All debugging sessions happen client-side in the browser — no telemetry is sent to MCP Workbench's servers
- Credentials are stored in browser memory only and are not persisted
- If your MCP server is behind a firewall or VPN, it must be accessible from wherever you open the browser
