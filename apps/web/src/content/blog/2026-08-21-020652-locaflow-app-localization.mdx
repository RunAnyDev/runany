## TL;DR

> **TL;DR:** LocaFlow connects to App Store Connect and uses AI to generate and translate your app's listing metadata for every supported App Store region, then pushes the changes directly — no manual export, no spreadsheets.

## What Is LocaFlow?

LocaFlow is a web-based tool that automates the tedious process of localizing an iOS (or Android, Flutter, web) app's App Store presence. You connect your Apple Developer account, and LocaFlow fetches your existing listing metadata — title, subtitle, keywords, description — and uses AI to translate and localize everything for up to 175+ App Store regions.

The core workflow:

1. **Connect** your App Store Connect account via OAuth
2. **Fetch** existing metadata for your base locale
3. **AI generates** localized listings in your target languages
4. **Push** the localized metadata back to App Store Connect in one click

LocaFlow supports `.strings`, `.stringsdict`, `.xcstrings`, `strings.xml`, JSON, and XLIFF file formats for code-level string localization alongside the App Store listing work.

## Setup Workflow

### Step 1: Connect Your App Store Connect Account

Sign up at [locaflow.dev](https://locaflow.dev) and authenticate with your Apple Developer account. LocaFlow reads your existing app metadata but does not have write access until you approve the per-app push permission.

### Step 2: Select Apps and Target Markets

Choose which app you want to localize and which App Store regions to target. You can select individual markets or bulk-select by language family.

### Step 3: AI-Generated Listings

LocaFlow's AI generates localized versions of:

- **App name** and **subtitle**
- **Keywords** (Apple's 100-character-per-field limit is respected)
- **Description** (localized tone and formatting for each market)
- **Promotional text** and ** What's New** release notes

### Step 4: Review and Push

Review AI-generated content in the editor before pushing. You can edit any field before committing. Once approved, LocaFlow pushes directly to App Store Connect — no manual CSV export required.

## Supported Formats and Languages

LocaFlow's AI supports translation in 100+ languages. Code-level string files are handled natively:

- `.strings` (iOS/macOS)
- `.stringsdict` (iOS pluralization)
- `.xcstrings` ( Xcode 15+ strings catalog)
- `strings.xml` (Android)
- JSON and XLIFF for cross-platform workflows

Translation memory tracks prior translations per account, so incremental updates only translate changed strings.

## Pricing

LocaFlow is **free to start**. Paid plans unlock higher volume, additional seats, and API access for CI/CD integration.

## Security Notes

LocaFlow requires App Store Connect API access, which is granted via standard Apple OAuth. The tool does not store your Apple credentials — only the short-lived API token. For teams, each member connects their own Apple ID with role-appropriate permissions.

## FAQ

**Q: Does LocaFlow work with Android app listings?**
**A:** Code-level string localization (strings.xml) is supported. App Store listing automation currently targets Apple App Store Connect.

**Q: Can I use my own AI key?**
**A:** Yes. LocaFlow supports BYOK for OpenAI, Anthropic, and Google Gemini.

**Q: Does it handle Apple's 100-character keyword limit?**
**A:** Yes. The AI respects Apple's field-level constraints and warns before pushing if a keyword set exceeds limits.
