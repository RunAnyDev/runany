> **TL;DR:** `n8n-io/n8n` is a TypeScript, fair-code workflow automation platform with 400+ native integrations, native AI capabilities, and both self-host and managed cloud deployments. 205,027 stars on GitHub, homepage at `https://n8n.io`.

## What it is

`n8n-io/n8n` describes itself as "Fair-code workflow automation platform with native AI capabilities. Combine visual building with custom code, self-host or cloud, 400+ integrations." The repository is written in TypeScript, has 205,027 stars, and the GitHub API returns `NOASSERTION` for the license field, which reflects the project's Sustainable Use License rather than an OSI-approved license. The homepage is `https://n8n.io`. The GitHub topic list is unusually long — `ai`, `apis`, `automation`, `cli`, `data-flow`, `development`, `integration-framework`, `integrations`, `ipaas`, `low-code`, `low-code-platform`, `mcp`, `mcp-client`, `mcp-server`, `n8n`, `no-code`, `self-hosted`, `typescript`, `workflow`, `workflow-automation` — which is itself a signal of how broad the surface area is.

## What it does well

n8n sits at the intersection of three categories — Zapier-style no-code, traditional iPaaS, and AI-agent plumbing — and the metrics show it is one of the most-used projects in any of them.

- **Visual plus code.** Workflows are built on a node graph, but every node can drop into a JavaScript or Python expression block, so the ceiling is not capped at what the GUI exposes.
- **AI-native.** Native AI nodes, MCP client and MCP server roles, and 400+ integrations cover the usual SaaS APIs alongside model providers. That combination lets you wire a Slack trigger into an LLM into a database write without leaving the workflow editor.
- **Self-hostable.** Self-hosting is a first-class deployment shape, and the topic list flags it explicitly. For teams that cannot send business data to Zapier, that is the deciding factor.
- **CLI plus UI.** The CLI is in the topic list, so n8n is scriptable from CI, not just clickable from a browser.

## How to try it

The fastest self-host path is the official Docker image, which exposes the editor on a local port.

```bash
docker volume create n8n_data
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n

# Open the editor
open http://localhost:5678
```

A managed cloud option also exists at `https://n8n.io` if you do not want to operate the runtime yourself.

## When it fits, and when it doesn't

n8n fits teams that have outgrown Zapier on price or data-residency grounds, that need both visual building and real code in the same workflow, and that want to slot AI steps and MCP calls into business automations. It is less attractive if all you need is a five-step linear webhook chain — a small script will be faster — or if you are committed to a vendor-specific automation tool that already owns your data model. The 205,027 star count places n8n among the top repositories in the entire automation category, and the topic list spanning `low-code`, `mcp`, and `self-hosted` is a reasonable proxy for "this is where the convergence is happening."
