## What Is Defencecore?

Defencecore is an AI-native security operator purpose-built for Supabase backends. It watches platform logs across authentication, API traffic, Postgres, Storage, Realtime, and Edge Functions, then runs detection rules over all of them together.

The free tier is the **Supabase Scanner** at `defencecore.com/scan` — a browser-based tool that audits a Supabase project's access-control configuration without requiring an API key.

## The Free Supabase Scanner

The scanner targets three specific Supabase misconfigurations:

### 1. Row Level Security and policies

Supabase relies on RLS to control row-level access in Postgres. The scanner looks for:

- Tables that have no Row Level Security enabled
- API grants on unprotected tables
- Missing applicable policies
- Policies that allow every row unconditionally

### 2. Storage bucket exposure

Supabase Storage buckets can be public or private. The scanner identifies buckets whose objects can be served without an authenticated download request — meaning anyone with the URL can access the contents.

### 3. Read-only Postgres catalogue scan

The scanner inspects Postgres `pg_*` catalogue metadata and Storage metadata through a server-owned read-only query. It does **not** select application rows, generate SQL migrations, or write any settings.

## How the Scanner Works

The scan uses Supabase's own OAuth flow, not a raw API key:

1. You enter your email to receive the report.
2. You authorize via Supabase OAuth — Defencecore never sees your credentials.
3. The tool selects your project and runs fixed, read-only catalogue checks.
4. Results appear in the browser and are emailed as a report.

The scanner explicitly states it never asks for a service-role key, database password, personal access token, or SQL from your browser. The scan takes about 30 seconds.

> **Important:** Defencecore advises against scanning projects that contain sensitive or regulated data (health, payment, government ID, children's data, etc.) even though the scan reads only metadata.
