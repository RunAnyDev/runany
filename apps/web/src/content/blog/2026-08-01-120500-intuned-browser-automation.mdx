## What Is Intuned?

Intuned describes itself as "a code-first browser automation platform" for building integrations with services that offer no public API. Rather than relying on a fixed connector library, Intuned Agent reverse-engineers the network calls and browser interactions your workflow needs, then generates and maintains that code for you.

The core value proposition, as stated on their landing page:

> "Build reliable integrations for services with no APIs. Intuned Agent generates and maintains the integration code — reverse-engineered network calls or browser automation — and runs it at scale with auth, captcha solving, and observability."

**Key capabilities:**

- **AI-powered code generation** — Intuned Agent writes the automation code; you review and deploy
- **Auth session management** — handles login flows, OTP, and cookie-based sessions
- **Captcha solving** — built-in support for reCAPTCHA, Cloudflare, and custom captchas
- **Browser SDK** — TypeScript and Python libraries for deterministic element selection and data extraction
- **Local dev CLI** — `intuned dev run api` lets you test automations locally before deploying
- **Cloud hosting** — run automations as hosted APIs at scale, with observability tooling

## Setup Workflow

### Step 1: Install the CLI

```bash
npm install -g @intuned/cli
```

### Step 2: Create a project from a template

```bash
npx create-intuned-project@latest
```

The wizard asks for:
- **Language** — TypeScript or Python
- **Template** — choose from examples (e.g., `starter`, `rpa-example`, `e-commerce-scrapingcourse`, `computer-use`)
- **Project name** — a name for your new project

### Step 3: Configure your API key

Create a `.env` file in your project root:

```
INTUNED_API_KEY=your_key_here
```

Get your API key from the [Intuned dashboard](https://app.intuned.io).

### Step 4: Run an automation locally

**TypeScript:**

```bash
yarn install
intuned dev run api <api-name> .parameters/api/<api-name>/default.json
```

**Python:**

```bash
uv sync
intuned dev run api <api-name> .parameters/api/<api-name>/default.json
```

## Architecture Overview

Intuned's automation stack has two distinct modes:

**1. Agent-authored mode** — Intuned Agent watches your browser and reverse-engineers the network calls and DOM interactions needed to replicate a workflow. It outputs TypeScript or Python code that you can review, modify, and commit to your repo.

**2. Direct SDK mode** — Write automations directly using the Intuned Browser SDK, which wraps Playwright with helper functions for deterministic element selection, data extraction, and session management.

Both modes produce **deterministic, production-ready code** — not a black-box run. You own the code, version it in Git, and can run it locally via the CLI before deploying to Intuned's cloud.

## FAQ

**Q: Is Intuned open source?**
**A:** The cookbook repository ([github.com/intuned/cookbook](https://github.com/intuned/cookbook)) is MIT-licensed and contains 30+ automation examples. The core platform is hosted software. The `intuned` CLI is published on npm.

**Q: Does it work with existing Playwright scripts?**
**A:** Yes. The cookbook includes `playwright-basics` and `hybrid-automation` templates that combine Playwright with Intuned's Browser SDK. You can also run standard Playwright scripts through Intuned's infrastructure.

**Q: How does captcha solving work?**
**A:** The cookbook includes `captcha-solving-basic` which demonstrates reCAPTCHA, Cloudflare Turnstile, and custom captcha handling via Intuned's built-in solving infrastructure.

**Q: What languages are supported?**
**A:** Both TypeScript and Python. The SDK ships examples for both, and the CLI works with either `yarn` (TypeScript) or `uv sync` (Python).

**Q: Is there a free tier?**
**A:** Yes. The pricing page indicates a free tier is available. Refer to [intunedhq.com/pricing](https://intunedhq.com/pricing) for current plan details.

## Conclusion

Intuned occupies a practical middle ground between hand-rolled Playwright scripts and fully-managed integration platforms. The code-first approach means you are not locked into a proprietary runtime — the generated TypeScript or Python is yours to own, version, and debug. The 30+ cookbook examples cover the most common automation patterns (auth, captcha, scraping, AI computer-use), giving you a starting point without needing to reverse-engineer everything from scratch.

If you are building integrations for API-less services — scraping, RPA, or AI data collection pipelines — Intuned is worth evaluating. The local dev CLI and free tier make it low-risk to try.
