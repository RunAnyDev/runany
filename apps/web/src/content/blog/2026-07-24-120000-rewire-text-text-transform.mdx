## TL;DR

> **TL;DR:** Rewire Text is a menu bar text-transform tool for macOS and Windows — deterministic transforms run instantly on-device, AI transforms use your own API key or a local model, and it costs $29 once.

## What Is Rewire Text?

Rewire Text is a desktop app from [Sunset Mesa Software](https://sunsetmesasoftware.com/) that lives in the menu bar until you need it. Select text anywhere, press a hotkey, pick a transform, and the result replaces the selection in place. The pitch: no subscriptions, own your license, run AI locally if you want.

The problem it solves: subscription fatigue in desktop software. When you want a text transform — say, converting a paragraph to bullet points or rewriting something in formal tone — most tools lock you into a monthly plan. Rewire Text is a one-time $29 purchase that works on two devices.

**Source:** [Rewire Text product page](https://sunsetmesasoftware.com/rewire-text/)

## Setup

### Step 1: Install

Download from [sunsetmesasoftware.com/rewire-text](https://sunsetmesasoftware.com/rewire-text/). The page has builds for macOS and Windows. Install and launch — it appears in the menu bar (macOS) or system tray (Windows).

### Step 2: Configure a Hotkey

On first launch, set your trigger hotkey. The default is a global keyboard shortcut that opens the transform menu over any selected text.

### Step 3: Deterministic Transforms (No Setup Required)

These run immediately after install with no configuration and nothing sent over the network:

- Case conversion (upper, lower, title, sentence)
- Whitespace cleanup (trim, normalize spacing)
- Markdown fixes (shift headings, convert bullet styles)

### Step 4: AI Transforms (BYOK or Local)

AI-based transforms — style rewrites, proofreading, summarization, translation, expand, simplify — need a provider. Two options:

**Cloud (BYOK):** Bring your own key from Gemini, Anthropic, OpenAI, OpenRouter, or any OpenAI-compatible API. A free Google AI Studio key or free OpenRouter tier is enough to start.

**Local:** Run a model through Ollama, LM Studio, or llama.cpp. Nothing leaves your machine. Setup guide is on the product page.

AI results stream in as they are generated.

## Deeper Analysis

### What Makes It Different

The $29 one-time price with a two-device license is the main differentiator. Most text-transform or writing-assistant tools are subscriptions. Rewire Text also ships all deterministic transforms as on-device features — no API call, no latency, no network dependency.

The AI layer is BYOK-first rather than bundled. The app doesn't have its own AI service to maintain or upsell. It also supports local models, which is a relatively rare feature for a $29 desktop tool.

### Transform Categories

**Deterministic (on-device, no API):**
- Case: UPPER, lower, Title Case, Sentence case
- Whitespace: trim, collapse spaces, normalize line endings

**AI-based (cloud BYOK or local):**
- Tone rewrite (formal, casual, technical, etc.)
- Proofreading
- Bullets from prose, prose from bullets
- Summarize / expand
- Translate to 29+ languages
- Custom rewrite instructions
