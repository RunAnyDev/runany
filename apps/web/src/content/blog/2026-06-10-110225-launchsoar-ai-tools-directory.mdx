## What Is Launchsoar?

Launchsoar is a curated directory for AI-powered content creation tools. It organizes tools across four main categories:

- **Video** — AI tools for video generation, editing, and captioning
- **Audio** — voice synthesis, music generation, podcast tools
- **Image** — AI image generation, editing, and enhancement
- **Social Media** — AI tools for scheduling, analytics, and content optimization

The directory tracks new launches and includes user-submitted reviews, giving creators a single place to discover and evaluate tools as they hit the market.

## Setup Workflow

Launchsoar is a web directory — no installation required.

### Step 1: Browse by Category

Open [https://launchsoar.com](https://launchsoar.com) and select a category from the top navigation: Video, Audio, Image, or Social Media.

### Step 2: Filter and Compare

Use the search bar to filter tools by keyword. Each tool listing shows:

- Tool name and brief description
- Category tags
- Launch date
- User review count

### Step 3: Submit a Tool

Launchsoar accepts community submissions. If you have an AI tool to add, use the submission form on the site.
