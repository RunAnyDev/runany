## What Is the Screen Time Network?

Apple does not expose iOS Screen Time data to third-party developers. The Screen Time Network, built by Oliver and Royce at [Clearspace](https://www.clearspace.com), solves this by measuring screen time through their own iOS app and exposing it via a public REST API.

Since the team collects the data themselves via the Clearspace app (rather than accessing Apple's private APIs), they can expose it to developers who want to build downstream tools. The launch HN post gives concrete examples of what developers have asked for:

- Auto-donate to charity when daily screen time limits are exceeded
- Group visibility for accountability groups (e.g., "75 Hard" challenge teams)
- Notify personal AI agents when it's a good time to tackle tasks
- Report anomalous screen time deviations to therapists

## API Overview

The API is available at `https://www.thescreentimenetwork.com/api/`. According to the HN launch post, developers can query screen time data after connecting their Clearspace account.

**Key characteristics:**

- REST-based access — standard HTTP GET/POST requests
- Screen time data collected through the Clearspace iOS app (not Apple's private Screen Time API)
- Requires a Clearspace account to authenticate

The launch post links to a [demo video on Google Drive](https://drive.google.com/file/d/1QahETj3xaaIsn0JiNbuqvTaSLdxo-eTu/view) showing the setup and API usage flow.

## Setup Workflow

### Step 1: Create a Screen Time Network account

Sign up at [thescreentimenetwork.com](https://www.thescreentimenetwork.com). The HN post recommends creating an account through the API docs to get a specialized onboarding flow for API setup rather than general app setup.

### Step 2: Install the Clearspace iOS app

The screen time data originates from the [Clearspace iOS app](https://apps.apple.com/us/app/clearspace-reduce-screen-time/id1572515807), which tracks usage on your device. Connect the app to your API account.

### Step 3: Query the API

Once connected, make REST calls to your screen time endpoint. The API returns structured data on daily and weekly usage, broken down by app category or individual apps.

### Example use case (from HN comments)

One HN commenter described using Apple Health data imported into a Jupyter notebook alongside journal sentiment and finance data. Screen Time adds another dimension to personal analytics — understanding how digital habits correlate with mental well-being, productivity, and financial outcomes.

## Developer Considerations

**This is not an official Apple API.** The Screen Time Network measures data through its own app instrumentation, which means:

- Data accuracy depends on Clearspace's measurement, not Apple's system-level APIs
- Requires users to install the Clearspace app and grant it screen time permissions
- API behavior and rate limits may change as the service evolves

**Practical uses beyond personal dashboards:**

- Habit tracking apps that reward low screen time
- Parental control integrations
- Workplace wellness program integrations
- Academic research data collection on digital behavior

## FAQ

**Q: Does this work without the Clearspace app installed?**
**A:** No. The screen time data originates from the Clearspace iOS app, which must be installed and connected to your API account.

**Q: Is this an official Apple API?**
**A:** No. Apple does not expose Screen Time data to third-party developers. The Screen Time Network collects this data through their own app's measurement.

**Q: Can I access other people's screen time data?**
**A:** No. Each user must explicitly connect their own Clearspace account. The API is scoped to your own data.

**Q: What platforms are supported?**
**A:** Currently iOS only, since the measurement is done through the Clearspace iOS app.

**Q: Is there a free tier?**
**A:** Check the pricing page at thescreentimenetwork.com for current plans.

## Conclusion

The Screen Time Network API is a novel approach to a long-standing gap in Apple's developer ecosystem. With no official Screen Time API from Apple, Clearspace built their own measurement layer and exposed it via REST — enabling a category of attention-tracking tools that were previously impossible without deep OS integration.

For developers building wellness apps, productivity tools, or personal analytics dashboards, this API fills a genuine gap. The main caveat is the dependency on Clearspace's own measurement rather than system-level data, which means verifying accuracy against Apple's own Screen Time settings in iOS Settings is advisable before building critical integrations.
