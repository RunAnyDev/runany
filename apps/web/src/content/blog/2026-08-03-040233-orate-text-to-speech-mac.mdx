## What Is Orate?

Orate is a macOS utility that converts written text into natural-sounding speech you can listen to while doing other things. It positions itself as a "read-it-later, for your ears" — select any text in any app and Orate reads it aloud in a queue, so you can stack articles and process them sequentially without switching windows.

The core pitch: **on-device TTS** means no internet required and no data leaves your machine. Apple Silicon (M1 or later) is required. The app runs as a menu bar resident with a minimal UI.

**Key features from the product page:**
- On-device text-to-speech (macOS 14.0+)
- Queue-based listening — add multiple items, listen in order
- Select text in any app and send it to Orate's queue
- $4.99 one-time purchase (no subscription)
- Natural voice output using Apple's built-in voices

## Setup and Usage

Orate is a standalone Mac app downloaded from the developer's site. No homebrew or App Store listing mentioned. Installation is a standard drag-to-Applications workflow.

**Typical workflow:**

1. Launch Orate — it appears in the menu bar
2. Select text in any app (Safari, Notes, Readwise, etc.)
3. Send to Orate's queue via a keyboard shortcut or menu
4. Orate reads aloud through the next item in queue

The queue system is central — you can add several articles and work through them while multitasking. Orate uses macOS's native voice synthesis, so voice quality depends on which Apple voice you have selected in System Settings.

## Limitations

Orate is a thin wrapper around macOS's built-in text-to-speech. Its voice quality and language support are whatever Apple provides on your system — not a replacement for cloud TTS services that offer more natural or multilingual voices.

It is a menu bar utility with no mobile companion, no web clipper, and no sync across machines. If you need cross-device listening, a dedicated read-it-later service with audio playback (Pocket, Instapaper) may be more suitable.

## FAQ

**Q: Does Orate work on Intel Macs?**
**A:** No. The product page specifies Apple Silicon (M1 or later) and macOS 14.0 or later.

**Q: Can it read web pages automatically, or only selected text?**
**A:** You select and send text manually from any app. There is no automatic web page detection or URL importing.

**Q: Is the purchase a subscription?**
**A:** No — $4.99 one-time purchase.

**Q: What voices are available?**
**A:** Orate uses macOS's built-in system voices. The voices available depend on your macOS language settings and installed voice packages.

## Conclusion

Orate is a focused utility for people who prefer listening over reading and want a local, private TTS experience on a single Mac. At $4.99 it is priced for impulse territory, and the queue model fits an "audio article backlog" use case well. It is not a full read-it-later service — it relies on whatever text you can select and send from other apps. If that workflow fits your routine and you want on-device processing with no subscription, it is worth trying.
