## TL;DR

> **TL;DR:** PI-Desktop is a local-first desktop app for AI-assisted coding. The architecture is Electron for the UI, a Rust host core, and the pi Agent Harness as the agent runtime. Plugins are user-installable, which makes the desktop a thin shell over a pluggable agent stack rather than a monolithic IDE.

## What Is PI-Desktop?

The repository description: "Local-first AI coding agent desktop: Electron + Rust host core + pi Agent Harness + user-installable plugins." That tells you almost the entire story. PI-Desktop is a desktop client for a coding agent — not a full IDE — designed so the heavy lifting happens on the user's machine.

The "local-first" label matters. It signals that the project cares about where state lives. Code, conversation history, and configuration stay on the user's filesystem. Cloud models are still used, but the host shell that wires everything together is local.

## How It Works

The TypeScript codebase wraps a Rust host core. That split is intentional: Electron gives you the UI surface area, Rust gives you the low-overhead host that talks to the agent runtime and the filesystem. The agent itself is the pi Agent Harness, which is a third-party piece that does the actual model calls and tool execution.

Plugins are the extension model. Users drop plugins into a known location and the host picks them up. That keeps the desktop itself small and pushes every interesting behavior into a separate plugin — easier to swap, easier to disable, easier to maintain.

## When To Use It

PI-Desktop is the right tool when:

- You want a desktop client for a coding agent but not a full IDE replacement.
- You care that conversation history and code context stay on your machine.
- You are comfortable installing plugins to shape the agent's behavior.
- You are willing to live with the LGPL-3.0 license for any redistribution.

It is not a VS Code killer. It is a shell for an agent. If you want deep editor integration — refactoring tools, language servers, debugger hooks — pair it with your existing editor.
