## What Is Dynbox?

Dynbox is an AI-powered file organizer that helps you sort, search, and manage files across multiple storage locations. It works with cloud storage providers and local disk directories, using AI to automatically categorize and surface the files you need.

  - Local disk directories

### Step 3: Let AI Organize

Dynbox scans your files and automatically:
- Categorizes by file type, date, and content
- Creates smart folders
- Removes duplicates
- Tags files with relevant labels

### Step 4: Search and Retrieve

Use natural language search to find any file:

```text
Example queries:
  "presentation slides from last month"
  "contracts not opened this year"
  "photos from my trip to Barcelona"
```

## Deeper Analysis

Dynbox targets a real pain point: file chaos. Most AI file managers focus on local disk, but Dynbox bridges cloud and local. The AI categorization is the core differentiator — instead of manual folder hierarchies, it builds smart, searchable collections.

The interface is designed around search-first workflows. Instead of navigating nested folders, you query and the AI surfaces relevant files.
