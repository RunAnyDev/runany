## TL;DR

> **TL;DR:** pascalorg/editor is an open source 3D architectural editor with a twist — it ships a local CLI and Model Context Protocol (MCP) tools, so both humans and AI agents can drive it. You get a 3D editor for architecture, plus a programmatic surface that lets your coding agent lay out walls, place windows, and inspect the model.

## What Is the Editor?

The repository description: "Open-source 3D architectural editor with a local CLI, MCP tools, and practical workflows for humans and AI agents." The project sits in the same category as ArmorPaint — open source tooling for 3D — but with a different target domain. Where ArmorPaint is about textures, this editor is about architecture.

The topics — `3d`, `agent-skills`, `ai-agents`, `architecture` — confirm the dual audience. The editor is built for humans who model buildings, and for AI agents who model buildings programmatically through the CLI and MCP surface.

## How It Works

The TypeScript codebase runs as a local app with a CLI alongside the GUI. The architecture implied by the description is:

- A 3D scene graph that represents the architectural model — walls, floors, openings, stories, etc.
- A local CLI that exposes the scene graph to scripts and other tools.
- MCP tools that wrap the CLI in a protocol agents understand, so a coding agent can drive the editor through conversation.
- A GUI for humans that reads the same scene graph.

The practical workflow angle is the differentiator. The project is not trying to be a generic 3D editor — it is trying to be the architectural editor you can script and the architectural editor your agent can use.

## When To Use It

The Editor is the right tool when:

- You want an open source 3D editor focused on architecture, not a generic DCC.
- You want to drive the editor from a CLI or from an AI agent via MCP.
- You are comfortable building your own workflow on top of the editor's primitives.

It is not a Blender replacement for general 3D work, it is not a CAD system with engineering-grade precision, and it is not a turnkey architectural design tool. It is a focused editor with an open programmatic surface.
