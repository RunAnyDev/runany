## What Is BreezePDF?

BreezePDF is a privacy-first PDF editor that runs **entirely in your browser** using client-side JavaScript. It handles editing, merging, signing, converting, and more — without uploading your documents to any server.

The product positions itself around three pillars:

1. **Privacy** — files never leave your device
2. **Features** — 39+ tools covering editing, conversion, security, and automation
3. **Pricing** — free tier with 3 downloads per month; Pro desktop app unlocks unlimited downloads, OCR, and CLI tools

## Core Features

### Editing Tools

- Add and edit text anywhere on a PDF page
- Insert images (JPG/PNG) with full positioning control
- Freehand drawing, shapes, lines, arrows
- Strikethrough, underline, text highlight
- Find and replace text across the document
- Watermarks, page numbers, crop, rotate

### Conversion & Export

- Export PDF to editable **DOCX** (Word)
- Export tables to **CSV**
- **OCR** for scanned documents (desktop Pro only)

### Organization & Security

- **Merge** multiple PDFs into one
- **Split** PDFs by page ranges or extract specific pages
- Reorder and delete pages with drag-and-drop
- **Password protect** PDFs with AES-256 encryption
- Redact and whiteout sensitive content
- Compress PDFs to reduce file size

### Forms & Signatures

- Create fillable form fields (text inputs, checkboxes, radio buttons, dropdowns)
- Digital signatures — draw, type, or upload your signature
- Digital certificates support

### Automation (Pro)

- Batch processing
- Mail merge
- CLI tools for terminal-based batch workflows

## Setup Workflow

BreezePDF requires **no installation** for the web editor. The free tier works immediately in any modern browser.

### Step 1: Open the Editor

Navigate to [breezepdf.com](https://breezepdf.com) and click **Open Editor**. No account or email required.

### Step 2: Upload Your PDF

Click the upload area or drag-and-drop your PDF file. Because processing is client-side, your file stays in your browser tab throughout the session.

### Step 3: Use Any of the 39+ Tools

Select a tool from the toolbar — text editing, signatures, merge, export, etc. Changes are applied in memory. Download when ready.

### Step 4: Download or Go Pro

Free users get **3 downloads per month**. The Pro subscription ($12/month) includes:

- Unlimited downloads
- Desktop app (macOS, Windows, Linux) — works offline after install
- CLI tools for batch automation
- OCR text recognition

## Security Notes

BreezePDF explicitly states that **all processing happens locally in your browser**. Files are never uploaded to their servers. No tracking, no analytics on documents, no third-party access.

For the free web tier, this claim is verifiable: the entire toolset runs as client-side JavaScript. The Pro desktop app installs locally and similarly processes files offline.

That said, if you handle highly sensitive legal or medical documents, consider running the **desktop app** on an air-gapped machine rather than relying on the browser version.

## FAQ

**Q: Is BreezePDF actually free?**
**A:** Yes. The web editor is free with a limit of 3 downloads per month. Beyond that, the Pro subscription ($12/month) adds unlimited downloads, a desktop app, CLI tools, and OCR.

**Q: How is my privacy protected?**
**A:** The site explicitly states that files are processed locally in your browser via JavaScript. Nothing is uploaded to BreezePDF's servers. The free tier has no server-side component for document processing.

**Q: Can I use BreezePDF offline?**
**A:** The web editor requires an internet connection for the initial page load. After that, the page works offline (service worker caching). The Pro desktop app works fully offline.

**Q: What file formats does it export to?**
**A:** PDF to DOCX (Word) and PDF to CSV are confirmed. The Pro tier also includes OCR text recognition for scanned documents.

**Q: Does it support digital signatures?**
**A:** Yes — you can sign PDFs by drawing, typing, or uploading your signature. Digital certificates are also supported on the Pro plan.
