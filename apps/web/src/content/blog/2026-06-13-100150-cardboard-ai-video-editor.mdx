## What Is Cardboard?

Cardboard is a web-based video editor purpose-built for short-form content creators. It runs entirely in the browser using WebAssembly and WebGPU for hardware acceleration — no desktop app, no plugin install, no server upload of your footage.

Key capabilities:

- **Timeline editor** with track-based layering
- **AI subtitle generation** with styling and caption sync
- **Smart reframing** (Portrait/Landscape/Square) for YouTube Shorts, Instagram Reels, TikTok
- **Export** to MP4 (H.264) or WebM

## Setup Workflow

### Step 1: Open in Browser

Navigate to [https://www.usecardboard.com](https://www.usecardboard.com) — no sign-up required for basic use.

### Step 2: Import Media

Drag-and-drop your video file into the editor. Cardboard supports MP4, MOV, and WebM input.

### Step 3: Add Subtitles

Click the **Subtitles** panel. Cardboard transcribes speech using an on-device model. You can manually adjust timing and edit text.

### Step 4: Choose Aspect Ratio

Click **Format** and select your target:
- **9:16** — YouTube Shorts, TikTok, Reels
- **16:9** — Standard YouTube
- **1:1** — Instagram Feed

The smart crop AI reframes to keep the subject centered.

### Step 5: Export

Click **Export**, choose quality (720p / 1080p), and download the rendered file.

## Deeper Analysis

Cardboard's differentiator is the **client-side-first architecture**. Most browser video editors send footage to a cloud API for processing. Cardboard uses a WebAssembly + WebGPU pipeline that keeps everything local. For creators with privacy-sensitive footage, this is a meaningful distinction.

The subtitle model runs on-device, which means:
- No server round-trip latency
- Works offline after first load
- No subscription required for basic transcription

Smart reframing uses a lightweight vision model to detect faces and text overlays, pan-and-scanning dynamically. Results are good but not as precise as manual keyframing in Premiere.

## Security Notes

All video processing is **client-side**. Footage never leaves your browser. This makes Cardboard suitable for NDA-protected or proprietary content that cannot be uploaded to cloud services.

Subtitle transcription is also on-device. No audio data is sent to external APIs.

## FAQ

**Q: Is Cardboard free?**
**A:** Yes, the core editor is free to use. A paid tier adds higher export quality and longer video support.

**Q: Does it work offline?**
**A:** After the initial page load, most features work offline. Smart reframing may use cloud APIs depending on your plan.

**Q: What video formats does it support?**
**A:** Input: MP4, MOV, WebM. Output: MP4 (H.264) and WebM.

**Q: Can I use it for commercial projects?**
**A:** Yes, exported content is yours to use commercially.

## Conclusion

Cardboard fills a specific gap: creators who need AI-assisted short-form video editing without the friction of desktop software or cloud uploads. The client-side WebGPU pipeline is technically sound, and the smart reframing saves significant manual work. For one-off shorts and quick turnarounds, it is worth keeping open in a browser tab.

If you regularly edit long-form content or need frame-level control, a desktop NLE is still the right tool. But for rapid subtitle-to-short-form pipeline, Cardboard delivers.
