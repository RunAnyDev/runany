## What Is Dopeloop?

Dopeloop is a generative online drum machine that creates beats using algorithmic composition rather than pre-recorded samples or loop libraries. The title on its page reads "Beat Maker - dopeloop.ai online drum machine", and the site describes it as "music apps using AI and procgen" — though the beat generation itself is algorithmic composition rather than ML-based AI.

Built with ClojureScript, it runs entirely in the browser with no backend required. Each time you play, Dopeloop generates a unique rhythmic pattern procedurally — meaning no two sessions produce the same beat.

The author, Chris McCormick, has been building generative music tools since 2019. His site also features a melody generator, and he maintains several open-source Clojure projects including `jsfxr` for retro sound effects synthesis.

## How It Works

### Step 1: Open in Browser

Navigate to [https://dopeloop.ai/beat-maker/](https://dopeloop.ai/beat-maker/) in any modern browser. No account, no install, no dependencies.

### Step 2: Generate a Beat

Click play. Dopeloop immediately starts generating a rhythmic pattern. Each generated beat is unique — the algorithm composes drum patterns on the fly using mathematical relationships between rhythmic subdivisions.

### Step 3: Modify Parameters

While music plays, you can interact with the generative parameters to nudge the composition in different directions — adjusting density, complexity, or rhythmic feel. The interface is designed for live performance rather than step-by-step sequencing.

## Under the Hood

Dopeloop is built with ClojureScript — a dialect of Clojure that compiles to JavaScript. This places it in the tradition of Lisp-based creative coding tools. The entire app is a single-page web application with no backend, no database, and no sample library.

Key technical characteristics:
- **Language:** ClojureScript (Lisp targeting JavaScript)
- **Audio:** Web Audio API via the browser
- **No samples:** All sounds are procedurally generated
- **No server required:** Runs fully client-side
- **Offline capable:** Service worker registered at `/dopeloop-sw.js`

The site uses a custom CSS framework with an inline SVG favicon and logo, giving it a distinct visual identity distinct from generic web apps.

## FAQ

**Q: Is the source code open source?**
**A:** The author has published various ClojureScript projects on his GitHub, but the specific Beat Maker source repository was not found during verification. Check the author's [GitHub profile](https://github.com/chr15m) for related repositories.

**Q: Can I download or export the beats you make?**
**A:** The app plays audio in-browser. No explicit download or export feature was identified on the product page.

**Q: Does it work offline?**
**A:** Yes, a service worker is registered for offline caching. Once loaded, the app works without an internet connection.

**Q: How does it compare to a traditional drum machine like the Roland TR-808?**
**A:** Dopeloop does not emulate any specific hardware. It generates rhythms algorithmically rather than simulating analog circuits or playing back recorded samples. The musical aesthetic is more experimental and generative compared to the fixed patterns of hardware drum machines.
