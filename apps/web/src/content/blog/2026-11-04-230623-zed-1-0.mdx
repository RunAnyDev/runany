> **TL;DR:** Zed 1.0 is the first stable release of the code editor Zed Industries rebuilt from scratch in Rust after walking away from Atom and Electron. It renders its UI on the GPU, runs multiple AI agents side by side through the Agent Client Protocol, and now has a multiplayer beta called Delta where review happens inside the agent thread rather than a pull request. The editor itself is free forever; the hosted models are not.

## What 1.0 actually is

Zed's history explains its architecture. Zed Industries built Atom, which was a fork of Chromium and spawned the Electron framework in the process, and Electron eventually became the foundation of VS Code. The team walked away from that architecture and started over, writing their own UI framework, GPUI, in Rust, and organizing the whole application around feeding data to shaders running on the GPU. The stated reason was that a web-page architecture puts a ceiling on how fast an editor can feel, and no amount of work could make Atom better than the platform it was built on.

Five years of work produced a real surface area: more than a million lines of code, Git integration, SSH remoting, a debugger, rainbow brackets, and support for macOS, Windows and Linux. The v1.0.0 tag shipped on April 29, 2026 with bookmarks, a `git: view commit` palette action, GIF animation support in the Markdown preview, and DeepSeek-V4-Pro and DeepSeek-V4-Flash model support.

The project has not slowed down since. The stable channel was on 1.26.2 by late October 2026, with a 1.27.0 preview following, and the repository sits at 92,674 stars and 11,399 forks.

## Installing it

Each platform has a first-party path.

```bash
# macOS, stable channel
brew install --cask zed

# macOS, preview channel
brew install --cask zed@preview

# Windows
winget install -e --id ZedIndustries.Zed

# Linux, x86_64 and AArch64
curl -f https://zed.dev/install.sh | sh
```

The Linux script covers Ubuntu, Arch, Debian, RedHat, CentOS, Fedora and similar distributions, and it accepts a `ZED_CHANNEL=preview` variable for the preview build. If it installed Zed for you, `zed --uninstall` removes it and asks whether to keep your preferences.

Agent behavior lives in `settings.json`, and Zed-hosted models and external agents are configured separately.

```json
{
  "agent": {
    "auto_compact": {
      "enabled": true,
      "threshold": "90%"
    },
    "commit_message_instructions": "Use Conventional Commits format with a type, an optional scope in parentheses, and a short description."
  }
}
```

Automatic compaction is on by default and fires when a thread reaches 90% of the model's context window, summarizing earlier messages so the conversation stays usable instead of starting a new thread.

## The agent story

Zed treats agents as part of the editor's foundation rather than an add-on. You can run multiple agents in parallel, and edit predictions suggest the next change at keystroke granularity.

The more interesting piece is the Agent Client Protocol, an open interface that lets Zed host an agent thread while the agent keeps its own runtime, authentication, model selection and tools. Zed's docs list these agents as available through the ACP Registry:

- Claude Agent
- Codex
- OpenCode
- Copilot
- Cursor
- Pi Coding Agent

The list is curated rather than exhaustive, and Zed also documents company-specific setup paths for Gemini and Poolside. Two details matter if you are billing this to someone. Zed does not charge for external agents, and the billing, legal terms, retention and data handling all sit between you and the agent provider. And an Anthropic API key configured for Zed's own agent does not automatically configure Claude Agent, so you wire up each provider separately.

You can browse the registry from inside the editor with the `zed: acp registry` command, and the agent panel opens with `Cmd+Shift+A` on macOS or `Ctrl+Shift+A` on Linux and Windows.

## Where it goes next

The 1.0 announcement pointed at Delta, and Delta went into public beta on September 16, 2026. Delta is a multiplayer environment for coding with agents, built around the idea that pull requests break down when agents write most of the code. Instead of opening a pull request, you invite a teammate into the agent conversation. They see the same worktrees, can ask the agent why you chose one design over another, and can pick up the thread where you left off even if you logged off. Each review gets an isolated copy of the parent worktree, so experimenting with an agent cannot disturb the original work.

Zed turned off pull requests on Delta's own repository before launching it, and now builds Delta inside Delta. DeltaDB, the synchronization engine underneath, uses CRDTs and tracks every change at character-level granularity so several people and several agents can share one consistent view of a codebase. Delta runs on macOS, Linux and Windows, in the browser without a download, and from a mobile browser.

## What to watch for

The launch thread on Hacker News has 2,153 points and 690 comments, and the complaints in it are worth reading. One commenter reported that 1.0 still shipped with wrong colors under Wayland and no bitmap font support, with another noting the color problem on macOS too. Another reported memory usage ballooning until a 128 GB machine needed daily session kills, and had moved back to VS Code. People working through ACP pointed out that Zed's wrapper blocks Claude Code commands such as `/mcp` and `/plugins`, and the extension ecosystem is thin enough that one commenter described the only CMake extension as basic.

The backlog is the other honest caveat: 3,037 open issues on the repository, many of them open for years. The team's own framing is that 1.0 does not mean done. If you bounced off Zed a year or two ago because something was missing, the announcement is an invitation to try again, but the extension story and the long tail of open issues are still work in progress.
