## What Is Intuned?

Most automation tools assume an API exists. Intuned is built for the other 90% of software — services that only expose a web UI and offer no programmatic access.

Intuned Agent is an AI agent that builds browser-based integrations by either:

1. **Copying network calls** the service's own frontend makes to its backend
2. **Automating the browser directly** via Playwright — navigating, filling forms, clicking through flows

Once generated, the platform runs these integrations at scale and manages the operational burden: login sessions, captcha solving, scheduling, and observability are all handled.

The product is aimed at engineers who need to extract data or automate workflows on sites that were never designed to be automated.

## Key Features

### Selector Forge

Selector Forge is Intuned's visual tool for pinpointing the exact DOM element a scraper or automation should interact with. Instead of hand-writing CSS selectors that break when the site changes, you visually point at the element and Intuned generates the most resilient selector available.

### Scraper Generation

You describe what you want to scrape in a prompt, along with a schema for the output. Intuned Agent generates Playwright code that targets the right elements, runs fast, and produces predictable structured data. Self-healing is available — when the site changes, Intuned monitors and fixes the scraper automatically.

### Authenticated Scrapers

Scrape sites behind login without managing cookies manually. Intuned's infra handles authentication state: you log in once through the platform, and Intuned maintains that session for subsequent runs.

### Crawlers

Build crawlers that discover, navigate, and collect data across thousands of pages. Features include:

- Follow links and parse sitemaps
- Built-in stealth to avoid bot detection
- Scheduling and scaling without managing infrastructure
- First-class Crawl4AI support — deploy and scale without managing servers

### Observability

Every run is recorded with full traces and logs. When something breaks, you can replay the exact state of the browser at each step and see what went wrong.

### Standalone Runs

Run any automation locally on your own machine with full access to your development tools and debugging workflow. Runs are not locked into the platform.

## Setup Workflow

### Step 1: Create a Free Account

Sign up at [intunedhq.com](https://intunedhq.com). The free tier includes 3 compute hours, 5 API machines, and 10 job runs per month.

### Step 2: Install the CLI

```bash
pip install intuned
```

Or use the dashboard directly at `app.intunedhq.com`.

### Step 3: Define Your First Scraper

From the dashboard, click **New Scraper** and describe what you want to extract:

```text
Scrape all job listings from example.com/remote-jobs.
Output schema: { title, company, location, salary_range, posted_date }
```

Intuned Agent generates the Playwright code, runs a test scrape, and surfaces any issues for you to confirm or correct.

### Step 4: Connect Auth (If Needed)

For sites requiring login, use the **Authenticated Scraper** mode. You'll authenticate once through Intuned's built-in browser session, and the platform maintains your session state across runs.

### Step 5: Schedule and Route

Set up a Job to run on a schedule and route output to your backend via webhook or another sink:

```yaml
# Job configuration (via dashboard or API)
schedule: "0 6 * * *"   # Run daily at 6 AM UTC
output:
  - type: webhook
    url: https://your-backend.com/ingest
    headers:
      Authorization: "Bearer ${INTUNED_WEBHOOK_SECRET}"
```

## FAQ

**Q: Does Intuned work with sites that use Cloudflare or other bot protection?**
**A:** Advanced stealth mode is available on all plans (included in the free tier as a trial feature). The platform uses techniques to avoid detection, though no automation tool can guarantee uninterrupted access to any site.

**Q: Is the generated Playwright code mine to keep?**
**A:** Yes. The code is generated as a reference implementation. For fully self-hosted deployments, you can run the Playwright scripts independently using your own infrastructure.

**Q: What happens when a site changes its UI and the scraper breaks?**
**A:** Self-healing mode (available on paid plans) monitors scraper runs and attempts to automatically repair broken selectors when site changes are detected. You'll also receive an alert so you can review the fix.

**Q: Can I use this with Python instead of JavaScript?**
**A:** Yes. While the default generated code uses Playwright (JavaScript/TypeScript), the platform supports custom code in Python and any framework you prefer, including Crawl4AI.

**Q: How does it compare to tools like Skyvern or Browserbase?**
**A:** Intuned positions itself as a managed platform rather than infrastructure — you describe what you want, and the platform generates and maintains the automation. Skyvern is more of a framework you deploy and manage yourself. Browserbase provides browser infrastructure without the AI code generation layer.
