## What Is mcp-use?

mcp-use is the **fullstack MCP framework** for building MCP Apps (for ChatGPT/Claude) and MCP Servers (for AI agents). It is developed by [Manufact](https://manufact.com), a YC S25 company.

> **mcp-use** is the fullstack MCP framework to build MCP Apps for ChatGPT / Claude & MCP Servers for AI Agents.

The framework ships in both TypeScript and Python:

```bash
# TypeScript
npm install mcp-use

# Python
pip install mcp_use
```

At the time of writing, the GitHub repo has **10.4k stars**, making it one of the most popular MCP frameworks in the ecosystem.

### Key Features

- **SDK for TypeScript and Python** — build MCP servers and apps with a developer-friendly DX
- **MCP Inspector** — [online](https://inspector.mcp-use.com/inspector) or [open-source](https://github.com/mcp-use/mcp-use/tree/main/libraries/typescript/packages/inspector) for testing and debugging
- **MCP Apps** — interactive widgets that run across ChatGPT, Claude, and other MCP clients
- **Skills for coding agents** — install the [mcp-use skill](https://skills.sh/mcp-use/mcp-use/mcp-apps-builder) into Claude Code, Codex, or Cursor
- **Deploy on Manufact Cloud** — connect a GitHub repo and have the MCP server running in production with observability, logs, and branch deployments

## Setup Workflow

### Step 1: Scaffold an MCP Server or App

```bash
npx create-mcp-use-app@latest
```

Or create a server manually:

```typescript
import { MCPServer, text } from "mcp-use/server";
import { z } from "zod";

const server = new MCPServer({
  name: "my-server",
  version: "1.0.0",
});

server.tool({
  name: "get_weather",
  description: "Get weather for a city",
  schema: z.object({ city: z.string() }),
}, async ({ city }) => {
  return text(`Temperature: 72°F, Condition: sunny, City: ${city}`);
});

await server.listen(3000);
// Inspector at http://localhost:3000/inspector
```

## Deeper Analysis

### Cross-Client Testing

Manufact Cloud's **cross-client testing** runs the same checks against ChatGPT, Claude, and other MCP clients. This is useful for verifying your MCP app behaves consistently across surfaces before publishing.

### Publishing Checks

Before submitting to the ChatGPT Apps Store or Claude Connectors, Manufact Cloud audits your MCP app against the platform requirements — catching metadata issues, missing permissions, and scope problems early.

### Cloud Inspector

Production MCP traffic can be traced, replayed, and debugged via the Cloud Inspector. Errors in deployed agents become easier to reproduce without needing to replay live sessions locally.

## FAQ

**Q: What is the difference between an MCP Server and an MCP App?**
**A:** An MCP Server exposes tools and resources to AI agents. An MCP App is an interactive widget that renders in the chat surface of ChatGPT or Claude. Both are built with the mcp-use SDK.

**Q: Does mcp-use work with LangChain, Mastra, or Vercel AI SDK?**
**A:** The README lists OpenAI Agents, Claude Agent SDK, Mastra, Langchain, and Vercel AI SDK as compatible stacks. Verify integration details in the [official docs](https://mcp-use.com/docs).

**Q: Is there a self-hosted option for the Inspector?**
**A:** Yes — the Inspector is open source and can be run locally. See the [GitHub repo](https://github.com/mcp-use/mcp-use/tree/main/libraries/typescript/packages/inspector) for self-hosting instructions.
