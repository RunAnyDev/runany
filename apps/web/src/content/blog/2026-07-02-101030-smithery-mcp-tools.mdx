## What Is Smithery?

Smithery is an MCP (Model Context Protocol) tool marketplace. It lets you connect AI agents to hundreds of pre-built tools — things like weather APIs, crypto price feeds, DNS lookups, web search, QR code generators, JWT decoders, and currency converters — without managing auth keys or credentials yourself.

The platform acts as a middleware layer between your AI agent and the underlying services. Smithery handles authentication, credentials, and session management so you do not have to.

## How It Works

### Browse and Connect

Each tool on Smithery has a dedicated page showing its name, a short description, and how many times it has been used. Tools are listed with usage counts — for example, Exa Search shows 41k uses and Tavily shows 5k uses — which gives a rough sense of community adoption.

### Authentication Handled for You

One of Smithery's core value propositions is credential management. Rather than setting up API keys for each underlying service, you authenticate once through Smithery and the platform propagates your credentials to connected tools.

### Pricing: Pay-as-You-Go

Smithery uses a pay-as-you-go model. Rather than a monthly subscription, you pay per call. The API Hub2 server (334+ free tools) is available at $5 per 500 calls, with each call consuming one credit.

Some tools like thelocalintel.com (20 MCP tools) charge $0.01–$0.05 per call and offer a free discovery tier.

### MCP Protocol

All tools on Smithery implement the MCP protocol, making them compatible with any MCP-compatible AI agent or client. This means you can swap tools in and out without changing your agent's core logic.

## Setup

Smithery tools are accessed through an MCP-compatible client. You configure your MCP client to point at Smithery's server endpoints, authenticate with your Smithery account, and then the tools become available to your agent.

Specific server URLs are listed on each tool's Smithery page. For example, the API Hub2 MCP server is available at `smithery.ai/servers/scotia1973/api-hub2`.

## FAQ

**Q: Is Smithery free to use?**
**A:** Smithery itself is free to browse. Tool access is priced per call. Some servers like API Hub2 charge $5 per 500 calls. Individual tools may have their own pricing tiers.

**Q: What MCP clients work with Smithery?**
**A:** Any client implementing the MCP protocol should be compatible. Smithery provides server endpoints that conform to the MCP spec.

**Q: Do I need my own API keys for the underlying services?**
**A:** It depends on the tool. Some tools are available through Smithery's shared quota; others require you to bring your own API key for the underlying service.

**Q: Can I self-host Smithery?**
**A:** No. Smithery is a hosted SaaS platform. There is no self-hosted version available.

**Q: How is Smithery different from building tools directly?**
**A:** Smithery's main value is saved setup time — you get pre-built, MCP-compatible tools without managing auth, credentials, or session state yourself.
