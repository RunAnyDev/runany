## What Is Smooth CLI?

[Smooth](https://smooth.sh) is a serverless browser agent API built by Circlemind. Rather than exposing click, type, and scroll actions to your agent, it exposes a simple natural-language interface. You tell the agent what you want; Smooth figures out the browser steps.

The core pitch from the product page:

> "Give your AI agent a browser that actually works."

Unlike tools that expose hundreds of low-level primitives, Smooth uses a specialized model to handle browser navigation — freeing your agent to think about goals instead of button coordinates.

## The Problem with Existing Browser Automation

Current tools for AI browser agents — Chrome DevTools, Playwright MCP, agent-browser — all expose low-level actions:

- `click(x=342, y=128)`
- `type("search query")`
- `scroll(down=500)`

This creates three problems the docs call out explicitly:

1. **Slow and expensive** — using a massive model to click buttons wastes tokens and time on UI navigation instead of the actual task.
2. **Context pollution** — every keystroke and click fills your context window with UI noise rather than task-relevant information.
3. **Wrong expertise** — general-purpose models are not trained on the quirks of iframes, shadow DOMs, and the messy reality of real websites.

## How Smooth CLI Works

Instead of a long sequence of low-level commands, your agent sends a single natural-language instruction:

```
"Search for flights from NYC to LA and find the cheapest option"
```

Smooth's specialized browser model handles all the clicking, scrolling, and form-filling internally. Your agent receives the result, not the step-by-step journey.

The docs compare it this way:

> Instead of this: `click(x=342, y=128)` → `type("search query")` → `click(x=401, y=130)` → ... (50 more steps)
>
> Your agent just says: "Search for flights from NYC to LA and find the cheapest option"

## Setup Workflow

### Step 1: Get an API Key

Sign up at [smooth.sh](https://smooth.sh) — no credit card required for the free tier. Grab your API key from the dashboard.

### Step 2: Install the CLI

```bash
npm install -g @usesmooth/smooth-cli
```

### Step 3: Configure Claude Code (or other agents)

For Claude Code, add this to your MCP settings (`Cmd+I` then navigate to GitHub linkedin discord):

```json
{
  "mcpServers": {
    "smooth": {
      "command": "npx",
      "args": ["@usesmooth/smooth-cli", "serve", "--token", "your-api-key"]
    }
  }
}
```

OpenClaw and other agents have similar setup steps documented in the [CLI docs](https://docs.smooth.sh/cli/overview).

### Step 4: Run a task

```bash
smooth run "Search for flights from NYC to LA"
```

Or from code:

```javascript
import { Smooth } from '@usesmooth/smooth-sdk';

const agent = new Smooth({ apiKey: process.env.SMOOTH_API_KEY });
const result = await agent.run('Search for flights from NYC to LA and find the cheapest option');
console.log(result);
```

## Key Features

- **P2P Tunnel** — routes browser traffic through your machine to avoid CAPTCHAs, access geo-restricted content, and reach localhost services
- **Secure by design** — runs in an isolated environment with no permissions by default
- **Unlimited browsers** — launch as many parallel browsers as needed, on-demand
- **Fully managed** — no infrastructure to set up; browsers run in the cloud instantly
- **Persistent sessions** — stay logged into sites across task runs (Starter tier and up)
- **Stealth mode** — reduces detection by anti-bot systems

## FAQ

**Q: Is this open source?**
**A:** No. Smooth is a proprietary SaaS product. The documentation is hosted on Mintlify, and the CLI package (`@usesmooth/smooth-cli`) is published to npm, but the underlying browser agent technology is not open source.

**Q: How does it compare to browser-use?**
**A:** The docs claim Smooth is 5x faster and 7x cheaper than browser-use, using smaller specialized models instead of large general-purpose models for browser navigation.

**Q: Can I self-host it?**
**A:** On-prem deployment is available only on the Enterprise plan. There is no self-hosted option for smaller teams.

**Q: What happens if the browser gets stuck or the page changes?**
**A:** Smooth runs in an isolated managed environment. Task timeouts and retry logic are handled by the SDK. Specific error handling behavior should be verified against the SDK documentation before production use.
