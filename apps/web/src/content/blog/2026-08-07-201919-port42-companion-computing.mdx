## What Is Port42?

Port42 is a **companion computing platform** — not another AI chat wrapper. It is a native macOS app (SwiftUI, Apple Silicon, macOS 14+) where multiple humans and multiple AI companions share the same live conversation space, building things together in real time.

The core primitive is the **companion**: an AI agent with a persistent identity, memory of past sessions, and the ability to emit **ports** — interactive surfaces rendered live inside the conversation. Multiple companions can be active in the same channel simultaneously, riffing off each other and synthesizing across their respective data sources.

The README describes it as:

> A native Mac app where you, your friends, and your AI companions share the same space. Talk, build, and watch ideas take shape together.

### Key Concepts

**Companions** — Each companion runs a specific model (Claude or Gemini, configurable per companion). They have persistent fold, position, and creases across sessions — meaning they carry relationship memory without being re-prompted each time.

**Command agents** — Any local binary or script can be wrapped as a companion using a simple NDJSON protocol on stdin/stdout. Working directory and environment variables are configurable per agent.

**Terminal companions** — Claude Code or Gemini CLI can run as native companions, appearing inline as a live terminal port. Channel messages route directly into the CLI; responses post back to the channel.

**Provider companions** — Connect GitHub, Stripe, Cloudflare, or any REST API as companions without an SDK. The companion IS the integration — just a system prompt and `rest.call`.

**Ports** — Interactive surfaces that companions build on the fly inside conversations. A port runs sandboxed HTML/CSS/JS with access to the `port42.*` bridge API. Ports can be visualizations, dashboards, 3D scenes, live simulations, or games. They can be popped out onto the shell desktop and persist across app restarts. Every port is versioned — companions can read a port's current HTML before updating it.

**Heartbeats** — Channels can fire a wake-up prompt to companions on a schedule (1m to 60m), keeping them active without manual prodding.

**Remote API** — An HTTP `/call` endpoint lets any external tool, script, or AI agent call the Port42 bridge API via `curl`.

**Multiplayer** — Share a link and anyone joins with two clicks, with their companions alongside.

## Setup Workflow

### Step 1: Install Port42

Download `Port42.dmg` from the project page and drag it into your Applications folder. Launch it — no installer needed.

### Step 2: Add Your First Companion

1. Click the **+** button in the companion sidebar.
2. Choose a model provider — **Claude** or **Gemini**.
3. Give the companion a name and a system prompt defining its role.
4. The companion appears in the sidebar and is ready to use in any channel.

### Step 3: Create a Channel and Start Building

1. Create a new channel (the conversation space where companions live).
2. Add one or more companions to the channel.
3. Type a message. Both you and your companions can reply.
4. Ask a companion to build something — companions emit ports using the ` ```port ` code fence:

````
```port
<title>companion dashboard</title>
<meta name="version" content="1">
<div id="app"></div>
<script>
  const companions = await port42.companions.list()
  document.getElementById('app').innerHTML =
    companions.map(c => `<div>${c.name} (${c.model})</div>`).join('')
  port42.on('message', e => console.log('new:', e.sender))
</script>
```
````

The port renders inline and can be popped out to the desktop.

### Step 4: Connect a Provider Companion

In Settings, add an API integration (GitHub, Stripe, Cloudflare, or a custom REST endpoint). The provider companion wraps that API as a companion you can message directly inside any channel.

## Port42 Bridge API Reference

Ports run in a sandboxed webview with no network access. All data flows through the `port42.*` bridge:

| Method | Returns | Description |
|---|---|---|
| `port42.user.get()` | `{ id, displayName }` | Current user info |
| `port42.companions.list()` | `[{ id, name, model, trigger }]` | All companions |
| `port42.companions.get(id)` | `{ id, name, model, systemPrompt }` | Companion details |
| `port42.companions.invoke(id, prompt, opts?)` | `{ text }` | Call companion AI from a port |

Companions can also call `port_create()`, `port_push()`, `port_get_html()`, and `port_history()` to manage ports programmatically.

## Security Notes

- **Local-first**: All data stays on your machine. No cloud dependency.
- **Open protocol**: E2E encrypted, open source. Any agent framework can plug in.
- **Sandboxed ports**: Ports run in a sandboxed webview with no network access — only the `port42.*` bridge API.
- **No third-party data sharing**: No analytics, no telemetry beyond crash reports.

## FAQ

**Q: Is this another AI chat wrapper?**
**A:** No. Unlike chat interfaces where you paste code snippets, Port42 lets companions build live interactive ports — visualizations, dashboards, tools — that persist inside the conversation and can be popped out to the desktop.

**Q: What models does Port42 support?**
**A:** Per-companion model selection — Claude or Gemini, configurable in companion settings. The companion runs the model you specify for that companion.

**Q: Can I run this on Intel Mac?**
**A:** The project page targets Apple Silicon (M1+). Performance on Intel is not documented.

**Q: Is the source code available?**
**A:** Yes — the native macOS app is open source (MIT) at `github.com/gordonmattey/port42-native`. The companion protocol is open.

**Q: Does it work offline?**
**A:** Yes. Port42 is local-first — no cloud dependency. Your data stays on your machine.

## Conclusion

Port42 is a fresh take on human-AI collaboration that goes beyond chat. By giving AI companions the ability to emit live, interactive ports inside shared conversations, it creates a space where building and talking happen in the same place. The open protocol and local-first architecture make it interesting for developers who want to extend the companion model without being locked into a SaaS platform.

If you want to work alongside AI that actually builds things while you discuss them, Port42 is worth a look — especially on Apple Silicon Macs where it runs natively.
