## What Is FutureSearch?

FutureSearch is an AI forecasting tool that exited public beta in August 2026. The team started in August 2023, working in the Tetlock-ian "forecast anything" tradition. The tool answers questions about the future — scientific progress, AI timelines, geopolitics, and other domains where uncertainty is high but structured reasoning helps.

The product is not a prediction market. It is closer to "deep research" but focused specifically on forecasting: giving probabilistic answers to open-ended questions about what will happen, with explicit reasoning.

The HN launch post states:

> "We started FutureSearch in August 2023. We're currently #1 of 194 in the most competitive AI forecasting tournament, and we score above the #3 and #2 human forecasters in the premier mixed human-bot tournaments."

The founding team came from Metaculus, where they pushed human forecasting to the limit on questions like when AGI would arrive. At FutureSearch, they co-authored the AI 2027 timeline forecast, predicting superhuman coding and research around 2032.

## Key Features

### Public Track Record

Every forecast is public and verifiable. The tool participates in tournaments with documented results, letting anyone check the accuracy claims before relying on the tool.

### ForecastBench Scoring

Forecasts are evaluated against ForecastBench, a standard benchmark for forecasting accuracy. FutureSearch scores above the superforecaster median — the top tier of human forecasting performance.

### Decision Forecasts

Beyond "what will happen," FutureSearch supports decision forecasts: "If I do X, will I achieve this outcome?" This is useful for strategic planning where the question is conditional.

### Free Tier

The free tier provides access to some of the highest-effort forecasters, letting users verify quality before paying.

### MCP Server and Claude Code Integration

From the docs page:

> "The plugin bundles an MCP server and a skill that guides Claude to write Python SDK code for advanced pipelines."

This installs both the MCP server and skills together, enabling programmatic access to FutureSearch forecasting capabilities from Claude Code.

## FAQ

**Q: Is FutureSearch a prediction market?**
**A:** No. It is an AI forecasting tool. It does evaluate forecasters on prediction markets, but the core product is probabilistic forecasting on open questions, not trading.

**Q: How accurate is it?**
**A:** The team claims #1 of 194 in Metaculus's Summer 2026 FutureEval tournament, scoring above the superforecaster median on ForecastBench. You can verify this by checking the public tournament results.

**Q: Does it cost money?**
**A:** There is a free tier. Paid plans are available for higher-volume usage.

**Q: Can I use it programmatically?**
**A:** Yes. The tool offers an MCP server integration for Claude Code, as well as a Python SDK for advanced pipelines.
