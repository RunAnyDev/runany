## What Is Palmier Pro?

Palmier Pro is a macOS-native video editor built from scratch in Swift, with AI generation baked into the timeline. It comes from Y Combinator's S24 batch and targets creators and developers who want to work alongside AI agents on video projects.

The north star is Adobe Premiere Pro, but with AI-native workflows. You can generate videos and images from within the editor using state-of-the-art models, then cut and arrange them on a traditional timeline alongside AI-generated clips.

### Core features

The README describes these capabilities directly:

- **Swift-native editor** — built from scratch with native macOS frameworks
- **Built-in Generative AI** — generate videos and images with Seedance, Kling, and Nano Banana Pro directly in the timeline
- **MCP server** — exposes a local HTTP MCP server at `http://127.0.0.1:19789/mcp` when the app is running, allowing AI agents to manipulate the timeline
- **Cross-agent collaboration** — connect Claude Code, Codex, or Cursor agents to work on the same project

## Setup Workflow

### Prerequisites

- macOS 26 (Tahoe) — this is a very recent macOS version
- Apple Silicon (M-series chip)
- macOS 26 is currently in beta as of July 2026

### Install Palmier Pro

Download the macOS DMG from the GitHub releases page:

```bash
# Download latest release (verify URL from releases page)
open "https://github.com/palmier-io/palmier-pro/releases/latest/download/PalmierPro.dmg"
```

After mounting the DMG, drag Palmier Pro into your Applications folder.

### Connect an AI agent via MCP

When Palmier Pro is running, it exposes an MCP server at `http://127.0.0.1:19789/mcp`. Add it to your preferred AI coding tool:

**Claude Code:**

```bash
claude mcp add --transport http palmier-pro http://127.0.0.1:19789/mcp
```

**Codex:**

```bash
codex mcp add palmier-pro --url http://127.0.0.1:19789/mcp
```

**Cursor:**

Add the following to `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "palmier-pro": {
      "type": "http",
      "url": "http://127.0.0.1:19789/mcp"
    }
  }
}
```

Alternatively, open the app and go to **Help** → **MCP Instructions** → **Install in Cursor** for the guided flow.

### Generate your first video

1. Open Palmier Pro and create a new project
2. Click **AI Generate** in the toolbar
3. Choose a model (Seedance, Kling, or Nano Banana Pro)
4. Enter a prompt and click Generate
5. The clip appears on the timeline — arrange it like any video clip

## Deeper Analysis

### What makes it different from other AI video tools

Most AI video generators are web-only or CLI-first. Palmier Pro embeds generation directly into a familiar timeline-based NLE (non-linear editor), which means you can:

- Mix AI-generated clips with real footage
- Use traditional cuts, transitions, and effects alongside generative content
- Have an AI agent read and modify the timeline through the MCP protocol

The MCP integration is the key differentiator. Rather than using a chat interface to describe what you want, you can have a Code Agent open the project file, read the timeline state, and make edits — or generate new clips — through the same MCP interface that connects it to code.

### Architecture

Palmier Pro is a native macOS app written in Swift. It does not use Electron or a web view. This gives it direct access to Metal for GPU-accelerated rendering and AVFoundation for video playback and encoding.

The MCP server runs as a local HTTP endpoint within the app process, polling the timeline state and translating MCP tool calls into editor operations.

### Supported AI models

From the README, these models are integrated:

- **Seedance** — ByteDance's video generation model
- **Kling** — Kuaishou's video generation model
- **Nano Banana Pro** — the project ships its own model

All three are called via on-device inference (the models are bundled with the app) rather than API calls to external servers.

## FAQ

**Q: Is Palmier Pro free?**
**A:** Yes, it is open-source under GPL-3.0 and the DMG download is free.

**Q: What macOS version is required?**
**A:** macOS 26 (Tahoe) on Apple Silicon. This is a very recent beta OS version as of mid-2026.

**Q: Can I use my own video footage alongside AI-generated clips?**
**A:** Yes. Palmier Pro is a full timeline editor — you can import real footage, cut it, and arrange it alongside AI-generated clips on the same timeline.

**Q: Does it require an internet connection?**
**A:** No. All three AI models (Seedance, Kling, Nano Banana Pro) run on-device via Metal GPU acceleration. No cloud API calls are made.

**Q: How does the MCP server work?**
**A:** When the app is open, it starts an HTTP server at `http://127.0.0.1:19789/mcp`. AI tools like Claude Code and Codex connect to this endpoint using the MCP protocol, read the timeline state, and call tools to generate clips or manipulate the project.
