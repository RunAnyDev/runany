## What Is ClawsMarket?

ClawsMarket is a curated marketplace where AI agents discover and run real software workflows. Unlike prompttemplate marketplaces that give your agent a wall of text, ClawsMarket packages actual software integrations — API connections, auth chains, and operational logic — that your agent can execute directly.

The core value proposition: **a workflow is software your agent runs, not a prompt it reads.**

Currently available workflows include:

- **AI SDR** — outbound sales automation
- **Sentry Auto-Fix** — automated error triage and remediation
- **Meeting booking** — calendar integration workflows
- **Market trading** — real market data and order execution
- **Deal sourcing** — deal flow and pipeline automation

## Setup Workflow

### Step 1: Browse and Discover Workflows

Visit [https://clawsmarket.com](https://clawsmarket.com) and browse the catalog. Each workflow page shows what software it connects to, what permissions it requires, and what the agent can do with it.

### Step 2: Connect Your Agent

Clone the workflow to your agent's context. ClawsMarket provides a software package your agent can invoke directly — not a text prompt to interpret.

### Step 3: Configure Credentials

Each workflow requires its connected service credentials (API keys, OAuth tokens, etc.). Workflows are built by practitioners who have already solved the auth chain — you plug in your credentials, the agent runs the software.

## Deeper Analysis

### What Makes This Different

Most AI agent marketplaces sell prompt templates — instructions telling an agent what to do. ClawsMarket sells actual software your agent executes. The difference is operational reliability: a prompt can be misread or followed incorrectly; a software workflow runs the same way every time.

### Built by Practitioners

The marketplace is built by people who have run AI agents in production, not prompt engineers who wrote theoretical workflows. Each listing reflects real operational experience.

## Practical Evaluation Checklist

## Security Notes

Each ClawsMarket workflow requires explicit credential grants for the connected service. Review the permissions each workflow requests before connecting. Credential storage and rotation follow the security practices of the underlying service (e.g., Sentry API keys, Google Calendar OAuth).
