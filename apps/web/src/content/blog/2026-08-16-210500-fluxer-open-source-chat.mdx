## What Is Fluxer?

Fluxer is a free, open-source instant messaging and VoIP chat app for friends, groups, and communities. It directly competes with Discord, offering text channels, voice calls, video calls, and screen sharing — without the proprietary lock-in.

The project's README describes it as:

> "A free and open source instant messaging and VoIP chat app built for friends, groups, and communities."

The key differentiator from Discord is its open-source nature and self-hosting option called **Plutonium**. As of August 2026, Fluxer is in public beta with clients for web, desktop (Windows, macOS, Linux), and mobile (iOS and Android in public testing).

## Platform Support

From the [download page](https://fluxer.app/download), Fluxer supports:

- **Web** — browser-based client at [web.canary.fluxer.app](https://web.canary.fluxer.app)
- **Desktop** — Windows, macOS, and Linux native clients
- **Mobile** — iOS and Android (public testing phase)

The desktop client is a native application, not a wrapped web view, which should provide a more consistent experience than Electron-based alternatives.

## Self-Hosting With Plutonium

The self-hosting option is branded **Plutonium** and targets users who want full control over their communication infrastructure. The [Operator Guide](https://docs.fluxer.app/) in the docs covers self-hosting your own Fluxer instance.

As of mid-June 2026, the team was finalizing the API and self-hosting documentation, having paused open-source releases to build out trust and safety infrastructure after spam waves. The latest stable source is being prepared for release.

## Key Features

From the product description and site copy:

- **Text channels** — organized chat with threads and categories
- **Voice and video** — real-time VoIP with screen sharing
- **WebRTC-based** — peer-to-peer connections where possible
- **Self-hostable** — run your own instance via Plutonium
- **Open source** — code available on GitHub under AGPL-3.0
- **Privacy-focused** — no proprietary lock-in, your data stays yours
- **International** — supports 35+ languages from the web client

## Setup Workflow

### Try the Web Client

No installation required:

1. Open [web.canary.fluxer.app](https://web.canary.fluxer.app) in your browser
2. Create an account or sign in
3. Start using text channels or join voice calls immediately

The canary channel runs the latest build with recent audio/video improvements.

### Install Desktop Client

1. Visit [fluxer.app/download](https://fluxer.app/download)
2. Download the client for your OS (Windows, macOS, or Linux)
3. Install and sign in — same account works across all platforms

### Self-Hosting (Plutonium)

The self-hosted option requires running your own Fluxer server instance. Consult the [Operator Guide](https://docs.fluxer.app/) for server requirements and deployment steps.

## FAQ

**Q: How does Fluxer compare to Discord?**
**A:** Fluxer is open-source and self-hostable, while Discord is proprietary. The feature set is similar (text, voice, video, screen sharing), but Fluxer is still in active development and may be missing some mature features Discord has built over years.

**Q: Is Fluxer free to use?**
**A:** Yes, the hosted service at fluxer.app is free. Self-hosting is also free under the AGPL-3.0 license — you only pay for your own server infrastructure.

**Q: What platforms does the mobile app support?**
**A:** iOS and Android are in public testing as of August 2026. The desktop clients (Windows, macOS, Linux) are more mature.

**Q: What license is the code released under?**
**A:** AGPL-3.0, confirmed from the `LICENSE` file in the main branch. Note that AGPL is a strong copyleft license — any network-using derivative works must also be released under compatible open-source terms.

**Q: Is the self-hosting documentation complete?**
**A:** As of mid-June 2026, the team was finalizing API and self-hosting docs. Check [docs.fluxer.app](https://docs.fluxer.app/) for the latest status.

**Q: Does Fluxer support end-to-end encryption?**
**A:** Check the [2026 roadmap](https://blog.fluxer.app/roadmap-2026/) for the latest on E2E encryption status.
