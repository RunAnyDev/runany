## What Is Inset AI?

Inset AI is a macOS-native desktop overlay application that brings AI assistance directly into any running application on your Mac. Think of it as a floating AI panel — triggered by a global keyboard shortcut — that can read the context of whatever you are working on, including selected text or a screenshot, and respond in place.

The product is built by Andrii Romasiun and launched on Hacker News in late 2025. It targets developers, writers, and power users who need AI help throughout their entire workflow without repeatedly switching to a browser tab or ChatGPT window.

Key claims from the product page:

- Works in any macOS application or website
- Supports GPT-5, Gemini, and any OpenAI-compatible API model
- Screenshot and selected-text context understanding
- Privacy-first: no data stored on external servers
- 753+ users at launch; 4.8-star average rating (174 reviews)

## Setup Workflow

### Step 1: Download and Install

Download the macOS app from [useinset.com](https://useinset.com) and install it like any macOS application. The app runs in the background after launch.

### Step 2: Connect an AI Model

On first launch, Inset AI prompts you to connect an AI provider. It supports any OpenAI-compatible API endpoint, which means you can use:

- OpenAI (GPT-4o, GPT-5)
- Google Gemini (via AI Studio API endpoint)
- Anthropic Claude (via OpenAI-compatible proxy)
- Self-hosted models (Ollama, LM Studio, etc.)

### Step 3: Set Your Shortcut

Assign a global keyboard shortcut (default: option+T) to summon the overlay. The shortcut works from any application.

### Step 4: Use It

1. Press the shortcut in any app
2. Optionally select text or take a screenshot to give the AI context
3. Ask your question or give an instruction
4. Receive a context-aware response inline

## Deeper Analysis

### The Problem It Solves

The standard AI workflow involves constant context switching: you are in a code editor, you need AI help, you open a browser, navigate to ChatGPT, paste context, ask, copy the answer, return to your editor. Inset AI collapses this into one keystroke.

This is similar to what tools like [Rectify](https://runany.dev/blog/rectify-ai-vs-code-extension/) (VS Code extension) or [F拾取](/blog/fuzzy-ai-code-autocomplete) aim to do, but Inset takes the cross-application approach — working system-wide rather than inside a single IDE.

### Privacy Model

The product page explicitly states "No data stored on servers. Direct API connections. Your data stays yours." This means screenshots and selected text are sent directly to your configured AI provider API — Inset does not act as a proxy or store them. This is a meaningful distinction from browser-extension AI tools that route requests through their own servers.

### Pricing

Inset AI is free for 7 days, then **$10/month**. That puts it in the same bracket as a single AI API key but without the token-metering anxiety. For heavy daily users, $10/month is competitive with GPT-4o API costs alone.

## FAQ

**Q: Does it work on Windows or Linux?**
**A:** No — Inset AI is macOS only at this time.

**Q: Which AI models does it support?**
**A:** Any model with an OpenAI-compatible API endpoint, including GPT-4o, GPT-5, Google Gemini, and self-hosted models via Ollama or LM Studio.

**Q: Is my data stored anywhere?**
**A:** The product page states data is not stored on Inset's servers. Screenshots and text are sent directly to your configured AI provider API.

**Q: Does it work offline?**
**A:** No — an internet connection is required to communicate with AI provider APIs.

**Q: How much does it cost?**
**A:** $10/month after a 7-day free trial.

## Conclusion

Inset AI solves the context-switching problem that plagues most AI workflows. By living as a system-wide overlay on macOS, it makes AI assistance accessible from within any application — Figma, Terminal, Slack, Photoshop — without ever leaving your work surface.

If you primarily work on a Mac and want AI assistance that follows you across every window, Inset AI is worth trying.
