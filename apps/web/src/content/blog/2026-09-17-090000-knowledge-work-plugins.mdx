> **TL;DR:** `anthropics/knowledge-work-plugins` is Anthropic's open-source repository of plugins primarily intended for knowledge workers to use inside Claude Cowork. Apache-2.0, Python, and at 24,307 stars.

## What it is

`anthropics/knowledge-work-plugins` describes itself as "Open source repository of plugins primarily intended for knowledge workers to use in Claude Cowork." It lives under the `anthropics` GitHub organisation, the language is Python, the license is Apache-2.0, and the project is at 24,307 stars with 2,923 forks. It is not archived.

The repo is the curated upstream of plugins that Anthropic ships for Claude Cowork, the agent surface aimed at non-developer knowledge workers.

## What it does well

A plugins repository only earns its place if the plugins inside are reusable as building blocks rather than one-off demos. This one is curated by Anthropic itself, which raises the bar.

- **Curated upstream.** Because Anthropic maintains the set, you can read the plugins as a reference for how a Claude Cowork plugin is supposed to be structured, rather than guessing from third-party examples.
- **Knowledge-worker focus.** The target persona is the non-developer knowledge worker, so the plugins lean toward document workflows, research assistance, and structured writing rather than code generation.
- **Apache-2.0 licensing.** Forks and downstream redistribution are explicitly allowed, which matters for teams that want to vendor the plugins inside a larger product.
- **Stable naming.** Because the repo is part of Anthropic's public organisation, the plugin identifiers are stable references you can pin in your own agent config.

## How to try it

Claude Cowork consumes plugins from a directory; the canonical pattern is:

```bash
git clone https://github.com/anthropics/knowledge-work-plugins.git
# then point Claude Cowork at the cloned directory
```

Each plugin is self-contained, so you can install only the ones relevant to your workflow.

## When it fits, and when it doesn't

This repo fits Claude Cowork users who want Anthropic's own plugin set as a starting point, and developers building their own plugins who want a reference for the expected plugin shape. It is less attractive if you have already settled on a private plugin registry — mixing upstream and private plugins adds maintenance overhead.

Apache-2.0 plus 24k stars places it firmly in the "established, redistribute-friendly" tier of the Claude plugin ecosystem.
