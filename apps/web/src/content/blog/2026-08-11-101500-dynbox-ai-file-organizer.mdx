## What Is Dynbox?

Dynbox is a web-based AI file manager that sits on top of your existing cloud storage accounts. Rather than navigating folders manually, you describe what you want in plain English — "move all meeting PDFs from July to the Projects folder" or "find the contract I drafted about the Acme deal" — and the AI executes it.

The core promise is converting file *management* into file *conversation*. Instead of remembering where you saved something, you describe what it contains or what it relates to, and Dynbox's vector search finds it semantically.

Key capabilities directly from the product page:

- **AI Chat** — ask questions like "show me all receipts over $500" or "find the Q3 financial summary" and the AI retrieves, moves, or renames matching files
- **Semantic search** — powered by vector embeddings, so you search by meaning ("that presentation about the product launch") rather than exact filename
- **Automated folders** — set rules to sort files into folders automatically in the background (Pro feature)
- **Demo mode** — try the full experience with a set of sample files before connecting your real accounts
- **Privacy-first** — files are not stored on Dynbox's servers; you control which files the AI can access
- **Coming soon: Local file access** — connect your computer's local folders directly

## Setup Workflow

### Step 1: Create a Free Account

Visit [dynbox.app](https://dynbox.app) and click **Join for free**. No credit card required for the Free tier.

### Step 2: Connect Your Cloud Storage

After login, connect at least one cloud account:

1. Click your avatar → **Vaults** or the connection panel
2. Click **Connect** next to Google Drive, Dropbox, or OneDrive
3. Authorize Dynbox in the OAuth flow — files are never stored on Dynbox servers

### Step 3: Try Demo Mode First

If you want to explore before connecting real accounts, click **Demo mode** on the main dashboard. You'll get a pre-populated set of sample files and can test all AI operations.

### Step 4: Start Chatting with Your Files

In the main chat interface, type natural language commands:

```
Move all PDF invoices from last month to the Finance folder
Find files related to the Q3 product roadmap presentation
Rename all screenshots from the March 15 demo to include the date
Archive files in Downloads older than 6 months
```

The AI shows you a preview of every action before executing — you approve, reject, or selectively apply changes.

## Semantic Search Deep Dive

Unlike traditional filename search, Dynbox indexes file content using vector embeddings. This means a query like "quarterly sales report" will surface documents that contain relevant content even if the filename says nothing about "sales" or "quarterly."

This is especially useful for:

- Large archives where folder structures have degraded over time
- Shared drives with inconsistent naming conventions
- Finding related documents across unrelated folder trees

## Automated Sorting Rules

On the Pro plan, you can create persistent rules for automatic file organization:

- Route files by type (all `.pdf` invoices → `Finance/Invoices`)
- Route by sender domain (all files from `@acme.com` → `Clients/Acme`)
- Schedule-based rules (files older than X days → `Archive/`)

Rules run in the background; you get a notification when files are moved.

## FAQ

**Q: Does Dynbox work with local files?**
**A:** Not yet. Local file access is listed as "coming soon" on the product page. Currently only Google Drive, Dropbox, and OneDrive are supported.

**Q: What happens when I run out of credits on the Free plan?**
**A:** AI operations pause until the next month when 50 credits reset. Non-AI operations (browsing, manual moves) are unaffected.

**Q: Can I undo an AI action?**
**A:** The AI shows a preview before executing changes. After execution, files can be moved back manually or by sending a follow-up chat command ("undo last move").

**Q: Is there a per-file or per-organization monthly cap on the Enterprise plan?**
**A:** Enterprise pricing and limits are custom — contact `enterprise@dynbox.app` for details.

**Q: Does it work with shared drives / team accounts?**
**A:** The Pro plan supports up to 5 members. Enterprise includes centralized team billing and SSO. Specific shared drive support depends on your cloud provider's OAuth scoping.

## Conclusion

Dynbox targets a specific pain point — the inevitable descent of cloud drives into disorganized file graveyards — and addresses it with natural language AI rather than manual folder hierarchies. The free tier is generous enough to evaluate whether the semantic search actually works well for your file types, and the Pro plan's automation rules could replace some recurring manual cleanup workflows.

The "coming soon" local file support is the biggest gap for power users managing Downloads folders, but the cloud-first approach keeps the product simple and focused.
