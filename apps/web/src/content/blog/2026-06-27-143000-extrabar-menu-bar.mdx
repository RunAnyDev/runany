## What Is ExtraBar?

ExtraBar reimagines the macOS menu bar as a keyboard-first command center. Instead of the standard Apple menu bar, you get a fully customizable bar that lives at the top of your screen, giving you instant access to:

- **Shortcuts and deep links** — open apps, URLs, files with a keystroke
- **Quick actions** — trigger scripts, automation, or shell commands
- **Custom menus** — organize tools and workflows your way

The key selling point: **no permissions required**. ExtraBar does not ask for Accessibility, Automation, or Full Disk Access — it runs entirely within standard macOS sandboxing, using the menu bar space that every macOS app already occupies.

## Setup Workflow

### Step 1: Download and Install

Download ExtraBar from the Mac App Store:

```
https://apps.apple.com/us/app/extrabar/id1668363952
```

Open the app after installation. The menu bar will immediately show the ExtraBar interface.

### Step 2: Configure Your Menu Bar

Click the ExtraBar icon in the menu bar to open the configuration panel. From here you can:

- Add new items via the **+** button
- Assign keyboard shortcuts to any item
- Import and export your configuration

### Step 3: Add Your First Shortcut

1. Click the **+** button in the ExtraBar panel
2. Choose the item type: **App**, **URL**, **Script**, or **Folder**
3. Fill in the target (app path, URL, or shell command)
4. Assign a keyboard shortcut (e.g. `⌘ + Shift + 1`)
5. Press **Save**

The item now appears in your menu bar and is accessible via its keyboard shortcut.

### Step 4: Organize with Folders

Group related items into folders for a cleaner menu bar. Right-click any item and select **Move to Folder**, then choose or create a folder.

## Security Notes

ExtraBar advertises **no permissions required**, which is a meaningful security posture for a menu bar app. However:

- Review any scripts you add before assigning them to ExtraBar
- Be cautious with scripts that require `sudo` or modify system files
- The app is distributed via the Mac App Store, which provides some sandboxing
