> **TL;DR:** Ciaren is an open-core visual workflow builder for local data pipelines and lightweight ML. Build pipelines on a drag-and-drop canvas, preview every step on real data, and export clean pandas or Polars Python code you own — no lock-in.

## The core promise

Ciaren targets the gap between writing dataframe code by hand and committing to a full no-code platform. Design pipelines on a drag-and-drop canvas, inspect every transformation on real data as you go, then export the equivalent pandas or Polars Python code.

The exported code is plain, readable Python you can run anywhere, version in Git, and audit without Ciaren present. The README puts it directly:

> "Build data and ML pipelines on a canvas, preview every step, then export readable pandas, Polars, or lazy Polars code with no proprietary runtime."

This makes Ciaren useful for teams who want visual iteration speed but refuse to lose ownership of their data transformation logic. You don't get locked into a config DSL or a compiled blob — the export is the code you would have written by hand.

## Installing it

Ciaren is distributed as a single Python package. The PyPI wheel bundles the React editor, so there's no separate frontend package to install:

```bash
python -m pip install --upgrade pip
python -m pip install ciaren
ciaren serve
```bash

Open `http://localhost:8055`. On first start, Ciaren seeds sample datasets and working example flows so you can preview, run, and export something real before uploading your own data. For reproducible evaluation, pin to a specific release:

```bash
python -m pip install "ciaren==0.2.0"
```bash

Docker is supported too if you'd rather not touch Python directly:

```bash
docker run -p 8055:8055 ciaren/ciaren
```

## What's in the canvas

The canvas uses React Flow under the hood. Nodes represent data sources (CSV, SQL, Parquet), transformations (Fill Nulls, Remove Outliers, Scale Features), joins, model training steps, and outputs. You wire them together and see data flow.

Before running the full pipeline, Ciaren streams a sample of real data through each node. You can inspect schema changes, null counts, and value distributions at every step without executing the entire flow — this is genuinely useful for catching bad joins or filter logic before running a full dataset through.

The defining differentiator is the Python export. Every node maps to a specific pandas or Polars operation. As of v0.2.0, the exporter supports pandas, Polars, and lazy Polars backends. If you've been writing dataframe code for years, this is the moment you can tell whether Ciaren's output matches your style or fights it.

The plugin API is Apache-2.0 licensed, separate from the AGPL-3.0 core. You can add custom nodes, connectors, engines, model providers, validators, and exporters without GPL obligations. The plugin SDK ships with the main install. A marketplace is planned but not yet live.

The platform ships with 80 built-in nodes covering data ingestion, transformation, feature engineering, ML, validation, and visualization.

## What it isn't

Ciaren is not a hosted ETL SaaS. It doesn't have a cloud runtime you push pipelines to. It's a desktop-class application that runs locally, and the output is Python you take and deploy yourself.

It's also not a replacement for dbt. dbt handles transformation logic in a SQL-first world with a strong opinion on testing and documentation. Ciaren is Python-native, visual-first, and covers the broader ML prototyping lifecycle dbt doesn't address.

SQLite works out of the box. Data does not leave your machine unless you explicitly configure a remote connector. The pipeline executor runs locally via Python.

## Status

Ciaren is in alpha (v0.2.0). The README is explicit that APIs, workflow formats, generated code, plugin interfaces, and internal data models may change before 1.0.0. Production use on critical workflows is not yet advisable, but the README correctly invites real-workflow evaluation today.

For data teams that want visual iteration but stay in a code-first workflow, Ciaren's sweet spot is between KNIME/Alteryx (more mature but heavier and less developer-friendly) and writing everything in pandas/Polars by hand. If you regularly prototype data pipelines or ML workflows and want a visual canvas that respects your code, install it, run the demo, and export one pipeline to see if the output matches what you would write yourself.
