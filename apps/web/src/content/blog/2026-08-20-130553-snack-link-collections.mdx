## What Is Snack?

Snack is a web-only tool for curating and sharing lists of links around a specific theme. According to the site's own meta description: "Create, organize, and share curated collections of links."

The product sits at the intersection of a bookmark manager and a link-in-bio tool. You can create themed collections — "My favourite design tools", "Weekend reads", "AI research" — and share the whole set with a single URL.

### Core features

From the public site and HN launch post, Snack offers:

- **Create collections** — start a named list and add any URL
- **Organize** — reorder links within a collection
- **Share publicly** — each collection gets a public Snack URL
- **Browse without an account** — anyone can view a shared collection
- **Free to use** — no pricing tier mentioned on the site

## Setup Workflow

Snack has no installation step — it runs entirely in the browser.

### Step 1: Open the site

Navigate to [snack.xyz](https://snack.xyz). The landing page shows a sign-up prompt alongside the core value proposition.

### Step 2: Create your first collection

1. Click **Get Started** (sign in or register)
2. Create a new collection — give it a name and optional description
3. Paste URLs into the collection. Snack accepts any valid link.
4. Drag to reorder links within the collection

### Step 3: Share the collection

Each collection receives a unique public URL on `snack.xyz`. Share that link directly — recipients can view the full list without creating an account.

## Security Notes

Snack is a closed-source web application. As with any link-sharing tool:

- Only add links you trust — Snack could theoretically redirect shared links at any time
- The service stores your collections on its servers
- No mention of data export or account deletion on the public-facing site

## Conclusion

Snack fills a simple gap: instead of sharing a messy chain of browser bookmarks or pasting 15 URLs into a doc, you build one tidy, themed list and share a single link. It is entirely free, requires no installation, and the UX is clean enough that non-technical users can onboard instantly.

The main limitation is the lack of self-hosting or open-source options — if you need to own your data or embed this behind a firewall, Snack is not the right tool. But for personal use, team knowledge-sharing, or public resource lists, it is a friction-free solution worth keeping in the bookmarks bar.
