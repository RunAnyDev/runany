## What Is Keyjump?

Keyjump is a browser extension for Chrome and Firefox that replaces your new tab page with a keyboard-driven launcher. Instead of clicking a bookmark or typing a URL, you press a single key to open any site you have saved.

The core concept is simple: every shortcut you define maps to one key. Press `g`, and GitHub opens. Press `m` twice, and your mail folder appears. Press `y` followed by a search query, and YouTube opens with that search already running.

The product is local-first. Your shortcuts and preferences live in the browser, not a server. An optional sync feature exists for users who want their config across machines, but it is opt-in.

## Installation

Open [keyjump.app](https://keyjump.app) in Chrome or Firefox and click the install link for your browser:

```
Chrome:  https://chrome.google.com/webstore
Firefox: https://addons.mozilla.org
```

Or click **Install extension** on the main page — it routes to the correct store for your browser. The demo mode on the landing page lets you try the launcher without installing, which is the fastest way to confirm the interaction model before committing.

## How It Works

### One Key, One Site

After installing, you see a list of your shortcuts. Each has a single associated key. Press that key on the new tab page and the site opens in the current tab.

Examples from the default config:

- `g` → `github.com`
- `m` → `mail.google.com`
- `y` → `youtube.com`
- `c` → `calendar.google.com`
- `w` → `wikipedia.org`

### Two Keys, One Folder

Press a folder key first, then another key inside that folder to open a specific item. This keeps related sites grouped without taking up screen real estate.

### Search Mode

Press a key followed by free text, and the site opens with a search query. For example, pressing `y` then typing `lofi` opens YouTube with a search for "lofi". The engine used for search depends on the site — the product page describes this as the site's own search being invoked.

### Global Launcher

`Alt+K` opens the Keyjump launcher from any page, not just the new tab. `Alt+Shift+K` saves the current page to Keyjump without switching tabs.

### Themes and Sync

You can customize the launcher with different themes and wallpapers. Optional browser-based sync keeps your shortcuts consistent across machines.

## FAQ

**Q: Is this open source?**
**A:** No. Keyjump is a closed-source browser extension. No public source repository was found at time of writing.

**Q: Does it work on Safari?**
**A:** The product page only lists Chrome and Firefox as supported browsers.

**Q: How is this different from a browser bookmark bar?**
**A:** The bookmark bar requires a mouse or trackpad. Keyjump is entirely keyboard-driven and opens on every new tab automatically — no clicking required.

**Q: Is my data sent to Keyjump's servers?**
**A:** The product is local-first. Sync is optional and uses browser-based storage. For full privacy, use it without signing in.

**Q: Can I import or export my shortcuts?**
**A:** Check the Docs link on [keyjump.app](https://keyjump.app) for the latest on import/export and keyboard shortcut management.

**Q: Does the demo on the landing page work without installing?**
**A:** Yes — the demo on keyjump.app is a live in-browser preview that works on first load without an account or extension install.

## Conclusion

Keyjump solves a narrow but real problem: keyboard-driven site access without the overhead of learning a general-purpose launcher. Its local-first design means no account, no sync obligations, and no data leaving your browser unless you explicitly opt in.

For power users who already map `g` to GitHub in muscle memory, Keyjump makes that pattern universal across every new tab. The two-key folder system keeps the single-key space from getting crowded, and the `Alt+K` global launcher means you never need to switch tabs to open a saved site.

If you spend any portion of your day in a browser and want to reduce mouse reach, it is worth a five-minute install to test whether the keyboard-first model fits your flow.
