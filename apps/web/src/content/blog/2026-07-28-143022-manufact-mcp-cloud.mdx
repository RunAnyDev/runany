## What Is Manufact?

Manufact is a YC S25-backed company that builds and maintains the open-source [mcp-use](https://github.com/mcp-use/mcp-use) framework — the fullstack toolkit for building MCP servers and MCP apps. Their hosted product, **Manufact Cloud**, handles deployment, cross-client testing, analytics, and distribution for MCP apps and servers.

The mcp-use SDK supports **TypeScript** (npm: `mcp-use`) and **Python** (PyPI: `mcp_use`), letting you create tools that ChatGPT Apps, Claude Connectors, and Gemini extensions can all consume from a single codebase. The company claims you can go from `git push` to a live MCP endpoint in under 60 seconds.

Key capabilities:

- **Build once, deploy everywhere** — a single mcp-use project connects to ChatGPT, Claude, and Gemini simultaneously
- **Vibecode your MCP App** — describe what you want and the platform scaffolds the server and UI widgets
- **Cross-client testing** — run the same functional checks across all three AI platforms before publishing
- **Publishing checks** — audit your MCP app against ChatGPT Apps Store and Cloud Connectors requirements
- **Cloud Inspector** — trace, replay, and debug MCP traffic in production
- **Embeddable chat surfaces** — drop a chat widget powered by your MCP app into any product

The SDK ships with an open-source [MCP Inspector](https://inspector.mcp-use.com/inspector) for local debugging, and a registry of community-built templates (Chart Builder, Diagram Builder, and more).

## Setup Workflow

### Prerequisites

- Node.js 18+ or Python 3.10+
- A [Manufact Cloud](https://manufact.com) account (free tier available)
- GitHub repo for CI-connected deployments

### Step 1: Scaffold an MCP Server or App

```bash
# TypeScript
npx create-mcp-use-app@latest

# Python
pip install mcp_use
```

The CLI prompts you to choose a template (blank server, Chart Builder, etc.) and creates a ready-to-run project.

### Step 2: Define Your First Tool

```typescript
import { MCPServer, text } from "mcp-use/server";
import { z } from "zod";

const server = new MCPServer({
  name: "my-server",
  version: "1.0.0",
});

server.tool(
  { name: "echo", description: "Echoes a message back", schema: z.object({ message: z.string() }) },
  async ({ message }) => text(`You said: ${message}`)
);

server.start();
```

```python
from mcp_use import MCPServer, text
from pydantic import BaseModel

server = MCPServer(name="my-server", version="1.0.0")

@server.tool(name="echo", description="Echoes a message back")
async def echo(message: str) -> str:
    return f"You said: {message}"

server.start()
```

### Step 3: Test with the MCP Inspector

```bash
npx mcp-use inspect
# Opens https://inspector.mcp-use.com/inspector
```

Point the Inspector at your local server URL to step through tool calls, inspect request/response payloads, and validate your schema.

### Step 4: Deploy to Manufact Cloud

Connect your GitHub repo to Manufact Cloud from the dashboard. On every `git push`, Manufact Cloud:

1. Detects the mcp-use project structure
2. Runs the build and type-check
3. Deploys to their edge infrastructure
4. Provides a shareable MCP endpoint (e.g. `https://yellow-shadow-21833.run.mcp-use.com/mcp`)

You can then register this endpoint in ChatGPT Apps, Claude Connectors, or Gemini Extensions from the respective platform dashboards.

## FAQ

**Q: What is the difference between an MCP Server and an MCP App?**
**A:** An MCP Server is a backend service that exposes tools and resources via the Model Context Protocol. An MCP App is a frontend-facing experience (like a ChatGPT App or Claude Connector) that wraps the server with a conversational UI. mcp-use handles both — you write once and connect to either layer.

**Q: Does this work outside of Manufact Cloud?**
**A:** Yes. The mcp-use SDK is standalone open-source (MIT) and runs anywhere. Manufact Cloud adds hosting, cross-client testing, analytics, and a publishing pipeline on top.

**Q: How does it compare to building MCP servers with the official SDK?**
**A:** The official MCP SDK (from Anthropic) is low-level and transport-focused. mcp-use adds a high-level tool decorator API, a widget system for rendering rich outputs (charts, diagrams, etc.), and deployment infrastructure. It builds on top of the official SDK rather than replacing it.

**Q: Is there a free tier for Manufact Cloud?**
**A:** Yes. The free tier covers hobby projects and small deployments. Pricing details are on the [manufact.com/pricing](https://manufact.com/pricing) page.
