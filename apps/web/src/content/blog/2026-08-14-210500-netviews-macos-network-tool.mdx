## What Is NetViews?

NetViews is a native macOS application built for IT professionals, Wi-Fi engineers, and network administrators who need a clean, keyboard-driven alternative to clunky GUI network tools or scattered terminal commands.

The app was formerly known as PingStalker and has been renamed to NetViews. It is a one-time purchase at $19.99 (Standard edition), with no subscription required.

## Setup Workflow

### Step 1: Download and Install

Download the app from the [official website](https://www.netviews.app) and install it like any macOS application.

### Step 2: Grant Network Permissions

On first launch, macOS will prompt for network access permissions. Allow full access for the app to perform ping sweeps, port scans, and DNS lookups.

### Step 3: Start Scanning

Use the live network monitor to ping hosts with configurable intervals, receive desktop notifications on host state changes, and view DHCP, DNS, LACP/CDP, and VLAN tag information in real time.

## Deeper Analysis

### Network Scanning and Monitoring

NetViews discovers every device on your local network and tracks uptime with configurable alerts. The live monitor continuously pings specified hosts and sends macOS notifications when a device goes up or down.

### Wi-Fi Diagnostics

The app analyzes signal strength, channel congestion, and noise levels. It includes a Wi-Fi client checklist for auditing connectivity and supports Cloudflare-backed speed tests.

### Network Calculators and Tools

Built-in calculators help with CIDR subnetting, VLAN planning, and other common network engineering tasks. A QR code generator lets you share network credentials quickly.

### Port Scanning

Scan specific ports on target hosts to verify service availability. Combined with the live ping monitor, this gives a complete picture of network service health.

## FAQ

**Q: Is this a subscription?**
**A:** No. NetViews is a one-time purchase at $19.99 for the Standard edition. Volume licensing is available.

**Q: Does it replace tools like Wireshark or nmap?**
**A:** NetViews covers a different use case — real-time monitoring and quick diagnostics rather than deep packet analysis. For packet captures and penetration testing, you'll still want Wireshark and nmap.

**Q: Does it work on Intel and Apple Silicon Macs?**

**Q: Is there a free trial?**
