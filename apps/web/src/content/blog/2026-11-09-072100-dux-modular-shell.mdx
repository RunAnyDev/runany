> **TL;DR:** Dux Modular Shell puts a bar, launcher, control center, notification daemon, lock screen and file manager into a single Wayland desktop shell for niri, Hyprland, Sway and friends. It replaces the usual pile of waybar, mako, fuzzel, swaylock and polkit configs with one Quickshell and Go program you install with a single curl command.

## What it is

Wayland has a compositor but no desktop. That gap is where most of the work goes: you pick a bar, a notification daemon, a launcher, a lock screen, a polkit agent, and then wire the keybindings together yourself. Every distro guide starts with that shopping list.

Dux Modular Shell, from Dux Labs, is the whole list in one package. It is built on Quickshell for the interface and Go for the backend, and it targets niri, Hyprland, MangoWC, Sway, labwc, Scroll and Miracle WM. The project shipped as DMS for its first two years, and the 2.0 release in October 2026 renamed DankMaterialShell to Dux Shell. The current release is 2.1, nicknamed Stormborn.

The shell is the anchor, but the suite extends past it. Dux Files is a keyboard-first file manager with tabs and split view that also serves the FileManager1 and portal file chooser D-Bus interfaces. Dux Calendar handles local, Google, Microsoft and CalDAV calendars. Dux Greeter is a greetd login screen that matches the shell. Dsearch is the fast file search that powers launcher results.

## Why it matters

The pitch is not a prettier desktop. It is one configuration surface instead of six. Theme, launcher, panel, notifications and lock screen all live in the same place, and a wallpaper change recolors the whole stack, including GTK and Qt apps and your terminal and editor.

The launcher is the part that makes it feel different from a bar with a status tray bolted on. It searches applications, files, emoji and running windows, and it accepts calculator expressions. It can also be driven from the command line over an IPC socket, so a keybinding can toggle the spotlight overlay without the shell needing to know whether the terminal underneath is a real terminal or something like Ghostty.

Plugin support is more than a loading screen. Dux keeps a lockfile of your managed plugins pinned to exact Git commits, so the same plugin set can be reproduced on another machine with a single restore command.

## Getting it running

One command installs the shell and its dependencies on Arch, Fedora, Debian, Ubuntu, openSUSE and Gentoo:

```bash
curl -fsSL https://install.duxlabs.dev | sh
```

Arch users can skip the script, since the shell is already in the official extra repository:

```bash
sudo pacman -S dux-shell
```

NixOS and home-manager users declare it as a flake and import the module:

```nix
{
  inputs.dms.url = "github:duxlabs-dev/dux-shell";

  imports = [ inputs.dms.homeModules.dank-material-shell ];
}
```

Once it is running, the CLI drives the shell from keybindings or scripts:

```bash
dms run                                  # start the shell
dms ipc call spotlight toggle            # open or close the launcher
dms ipc call audio setvolume 50
dms ipc call wallpaper set /path/to/image.jpg
dms brightness list                      # list available displays
```

Plugins are managed the same way:

```bash
dms plugins search
dms plugins lock
dms plugins restore ~/plugins.lock.json
```

Building from source means two pieces, the Go core and the QML shell:

```bash
cd core
make              # build the dms CLI
make duxinstall   # build the installer
```

```bash
quickshell -p quickshell/
```

## What you get

| Area | What it does |
|---|---|
| Panel | Clock, workspaces, system tray and media controls |
| Launcher | Spotlight search across apps, files, emoji, windows and commands |
| Control center | Network, Bluetooth, audio, display and night mode in one panel |
| Notifications | Grouping, rich text and keyboard navigation |
| Monitoring | Live CPU, RAM and GPU metrics with a searchable process list |
| Session | Lock screen, idle detection, auto-lock and suspend with separate AC and battery settings |
| Theming | Wallpaper-derived color schemes applied across GTK, Qt, terminals and editors |

That list maps directly onto the tools it replaces: waybar, mako, fuzzel, swaylock, swayidle and polkit.

## What to watch for

The compositors with first-class support are niri, Hyprland, MangoWC, Sway, labwc, Scroll and Miracle WM. Other compositors work with reduced features, so check the compositor guide before you commit to a different window manager.

The project moves fast. It was created in July 2025, renamed its flagship product only a few weeks before this post, and the main repository carried 422 open issues when I looked. Expect the configuration format to shift between releases.

It is also a desktop environment in everything but name. If you enjoy taking your config apart one component at a time, replacing your bar on its own remains a legitimate workflow and this project does not want to stop you. But if you are the person with a dotfiles repo holding fifteen small pieces, the point of Dux is that it removes that.
