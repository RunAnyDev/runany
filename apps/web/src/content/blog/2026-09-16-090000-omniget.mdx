> **TL;DR:** Omniget is a Rust-based desktop download manager that wraps yt-dlp and supports 1,800+ sites including YouTube, Udemy, Hotmart, and Bilibili. It is licensed GPL-3.0 and ships with a built-in course player, PDF/EPUB reader, and music library.

## What it is

`tonhowtf/omniget` describes itself as a tool to "Download Udemy and Hotmart courses, YouTube videos, music and books — 1,800+ sites, no terminal." It is a free, open-source desktop app for Windows, macOS, and Linux, and it is built on top of `yt-dlp`. Topics include `bilibili-downloader`, `course-downloader`, `download-manager`, `downloader`, and `epub-reader`. The repository has 12,979 stars and 1,102 forks at the time of writing, and the homepage is https://tonho.wtf.

The language is Rust, the license is GPL-3.0, and the project was created in February 2026.

## What it does well

Omniget is positioned as the GUI counterpart to yt-dlp for users who don't live in a terminal.

- **Wide site coverage.** The "1,800+ sites" number is inherited from the yt-dlp extractor list, so anything yt-dlp supports in principle is reachable through Omniget's UI.
- **Bundled playback.** A built-in course player, PDF/EPUB reader, and music library mean downloaded files are usable without bouncing between apps.
- **Cross-platform binary.** Rust makes the install story simple — one binary per OS, no runtime to manage.
- **Local-first storage.** Files stay on your computer, which matches the description's "Your files stay on your computer" claim.

## How to try it

The README and homepage document the install path, which is a standard download-and-run flow for each platform:

```bash
# macOS / Linux: download the release tarball from GitHub
# then run the bundled binary
./omniget
```

The first launch walks you through picking a download directory. After that, paste a URL into the input field, pick a format from the dropdown, and let the app drive yt-dlp.

## When it fits, and when it doesn't

Omniget fits when you want a GUI on top of yt-dlp that also plays back what you download — lecture videos, ebooks, podcasts — and you prefer a single app over a folder of MP4s you open in VLC. It fits less well for one-off video grabs, where running yt-dlp directly is shorter, and less well for users who need a CLI-only workflow on a remote server, since the value here is the desktop UI.

The GPL-3.0 license also matters for downstream forks: any modified version you distribute must remain GPL-3.0 and disclose source. Personal use is unaffected.
