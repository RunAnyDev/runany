## What Is Intuned?

Intuned is a browser automation platform that bridges natural language prompts and production-grade Playwright code. The core differentiator is the **self-healing agent**: when a target site changes its DOM structure, Intuned Agent re-generates the failing selectors automatically rather than breaking silently.

It supports three primary use cases:

- **Scrapers** — e-commerce data extraction, government portals, job boards
- **Crawlers** — large-scale site indexing with Crawl4AI integration
- **RPA** — form submissions, account actions, services without APIs

You write in TypeScript or Python using Playwright directly, or delegate entirely to the AI agent for generation and maintenance.

## Setup Workflow

### Step 1: Sign Up and Get API Key

Visit [app.intunedhq.com](https://app.intunedhq.com) and sign in with GitHub or email. The free tier includes 1,000 credits—enough to generate and run several scrapers.

### Step 2: Install the SDK

```bash
npm install @intuned/sdk
# or
pip install intuned-sdk
```

### Step 3: Create a Scraper via Agent

```bash
npx intuned agent create \
  --prompt "Scrape product names and prices from example.com/products" \
  --schema '{"products":[{"name":"string","price":"number"}]}'
```

The agent generates a Playwright script, deploys it to Intuned infrastructure, and returns a job ID.

### Step 4: Run and Monitor

```bash
# Trigger a run
npx intuned job run <job-id>

# View logs and session recordings
npx intuned job logs <job-id> --stream
```

Session recordings capture every step—useful for debugging selector failures.

### Step 5: Handle Authentication

For sites requiring login, write a `create.ts` (or `.py`) that returns a session cookie or token. Intuned manages the lifecycle—validating, reusing, and recreating as needed.

```typescript
// create.ts
export default async function create(context: AuthContext) {
  const page = await context.browser.newPage();
  await page.goto('https://example.com/login');
  await page.fill('#username', process.env.USERNAME);
  await page.fill('#password', process.env.PASSWORD);
  await page.click('#submit');
  await context.storeSession(await page.context().cookies());
}
```

## Deeper Analysis

### Self-Healing Logic

When Playwright throws a selector timeout, Intuned Agent intercepts the error, re-analyzes the current DOM, and generates a new selector. This is not regex-based DOM diffing—it re-prompting the underlying model with the failure context and current page structure. The loop continues until the step succeeds or hits a max retry threshold.

### Stealth Stack

Intuned bundles several anti-detection mechanisms:

- Rotating user agents and browser fingerprints
- Built-in proxy rotation
- Captcha solving via integration (2Captcha, Anti-Captcha)
- WebGL canvas normalization

These are configurable per-job, not hard-coded defaults.

### Concurrency and Scaling

```bash
# Set parallelism
npx intuned job update <job-id> --parallel 10

# Scale to hundreds of machines
npx intuned job update <job-id> --machines 100
```

The infrastructure is managed by Intuned—you control the count via CLI or API.

### Crawl4AI Integration

For large-scale crawling, Intuned has first-class Crawl4AI support. You can deploy a Crawl4AI crawler and manage scheduling, retries, and storage through the same dashboard.

```bash
npx intuned crawler create \
  --engine crawl4ai \
  --start-url https://example.com/sitemap.xml
```

## FAQ

**Q: How does self-healing compare to traditional selector-based scrapers?**

**A:** Traditional scrapers break permanently when a site changes. Intuned re-generates the selector on failure, but this requires a live model call and adds 5-15 seconds per retry. For stable sites, traditional Playwright is faster. For high-churn targets (e-commerce with frequent re-designs), self-healing reduces maintenance overhead significantly.

**Q: Can I use my own Playwright scripts?**

**A:** Yes. You can write raw Playwright code in TypeScript or Python and deploy through the SDK without using the AI agent at all. The agent is optional—it generates code that you can then modify and own.

**Q: Does it handle JavaScript-heavy SPAs?**

**A:** Yes. Playwright waits for network idle by default. You can configure wait conditions per step for sites that load content dynamically.
