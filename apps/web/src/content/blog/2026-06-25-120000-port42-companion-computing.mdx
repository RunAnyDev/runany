## What Is Port42?

Port42 is the first **companion computing platform** — not another AI chat wrapper. The project describes it as "a native Mac app where you, your friends, and your AI companions share the same space. Talk, build, and watch ideas take shape together."

The core primitives:

- **Companions** — Multiple AI companions running in the same channel, powered by Claude or Gemini per-companion. They respond to each other and to you, riffing on ideas in real time.
- **Command agents** — Any local binary or script can be wrapped as a companion. The process speaks NDJSON on stdin/stdout; Port42 routes messages to it like any other companion.
- **Terminal companions** — Run Claude Code or Gemini CLI directly as native companions. Channel messages route into the CLI; responses post back inline.
- **Provider companions** — Connect GitHub, Stripe, Cloudflare, or any REST API as companions. The companion IS the integration — no SDK needed.
- **Ports** — Interactive surfaces (visualizations, dashboards, games) that companions build live inside conversations using HTML/CSS/JS via the Port42 Bridge API.
- **Swims** — Deep 1:1 sessions with any companion. Context never resets.
- **Heartbeats** — Channels can wake companions on a schedule (1m to 60m) to keep them active between messages.

## Setup Workflow

### Step 1: Download and Install

Download the DMG from the GitHub releases page:

```bash
curl -sL https://github.com/gordonmattey/port42-native/releases/latest/download/Port42.dmg -o ~/Downloads/Port42.dmg
```

Open the DMG and drag Port42 into your Applications folder. Requires macOS 14+ and Apple Silicon.

### Step 2: Configure AI Providers

On first launch, Port42 prompts you to add your AI provider credentials. Supported providers per the README:

- **Claude** (Anthropic) — set per companion
- **Gemini** (Google) — set per companion
- **OpenAI** and **OpenAI-compatible APIs**
- **OpenClaw**

You can mix and match providers across different companions in the same channel.

### Step 3: Add Your First Companion

1. Click the **+** button in the sidebar
2. Choose a provider (Claude, Gemini, etc.)
3. Give the companion a name and optional system prompt
4. The companion appears in your channel and is ready to interact

### Step 4: Connect a Terminal Companion (Optional)

If you have Claude Code installed, you can add it as a terminal companion:

1. Add a new companion and select **Terminal** type
2. Point it to your Claude Code binary
3. It appears as a live terminal port in your channel — messages route directly into the CLI

### Step 5: Run a Heartbeat (Optional)

To keep a companion active without manual prompting:

1. Open channel settings
2. Set a **Heartbeat** interval (1 to 60 minutes)
3. The companion fires its wake-up prompt on schedule automatically

## Deeper Analysis

### Port42 Bridge API

Ports are sandboxed webviews running inside conversations. They access data through the Port42 Bridge API. Companions emit ports using a ` ```port ` code fence. Example from the README:

```
```port
<title>companion dashboard</title>
<meta name="version" content="1">
<div id="app"></div>
<script>
  const companions = await port42.companions.list()
  const channel = await port42.channel.current()
  document.getElementById('app').innerHTML =
    companions.map(c => `<div>${c.name} (${c.model})</div>`).join('')

  port42.on('message', e => console.log('new:', e.sender))
```
```

Key bridge methods:

| Method | Returns |
|---|---|
| `port42.user.get()` | `{ id, name }` |
| `port42.companions.list()` | `[{ id, name, model, isActive }]` |
| `port42.companions.invoke(id, prompt)` | response text |
| `port42.ai.models()` | `[{ id, name, tier }]` |
| `port42.ai.complete(prompt, opts?)` | raw LLM response |
| `port42.messages.recent(n?)` | `[{ id, sender, content, timestamp }]` |
| `port42.channel.current()` | current channel metadata |

Ports persist across app restarts and channel switches. They can be popped out into floating windows.

### Relationship Memory

Companions carry persistent fold, position, and creases across sessions — they remember where they stood in previous conversations without being explicitly prompted. The README calls this "relationship memory."

### Remote API

Port42 exposes an HTTP `/call` endpoint. Any external tool, script, or AI coding agent can call the bridge API via `curl` with no additional setup beyond enabling it in Settings.

## Security Notes

- **End-to-end encrypted** — Port42 uses an open encryption protocol; your conversations do not leave your machine unencrypted
- **Local-first** — all data stays on your Mac; no mandatory cloud dependency
- **Open source** — the protocol and client are open, verifiable, and auditable
- **No SDK requirement** — REST API integrations (provider companions) require only a system prompt and `rest.call`, no third-party libraries

## FAQ

**Q: Is Port42 free?**
**A:** The core app is free and open source under the MIT license. The README does not mention paid tiers.

**Q: Does it work with any LLM besides Claude and Gemini?**
**A:** Yes — the README mentions OpenAI and any OpenAI-compatible API. OpenClaw is also listed as a supported provider.

**Q: Can multiple humans use Port42 together?**
**A:** Yes. The Multiplayer feature lets you share a link so anyone can join a channel with their own companions alongside yours.

**Q: What happens to my data if the company shuts down?**
**A:** Because it is local-first and open source with E2E encryption, your data is not dependent on any cloud service operated by the project.

**Q: Does Port42 work on Intel Macs?**
**A:** The README specifies Apple Silicon as a requirement, and the DMG is distributed for macOS 14+.
