## TL;DR

> **TL;DR:** LANCommander is an open-source, self-hosted game distribution platform that lets you run your own Steam-like library server on your hardware — no cloud, no subscription, full control.

## What Is LANCommander?

LANCommander is a self-hosted digital distribution platform for PC games. Think of it as running your own private Steam or GOG server — you supply the hardware and the games, and LANCommander handles the rest: game library management, downloads, updates, and launch shortcuts.

It was built over 14 months as a solo project by developer `pathartl` and released on Show HN in mid-2025. The project solves a real pain point for power users who want to own their game library outright, without relying on cloud services that can deprecate, region-lock, or simply shut down.

## Setup Workflow

### Step 1: Download and Install

LANCommander consists of two parts: the **server** (runs on your host machine) and the **client** (installed on each device that accesses the library).

Head to the [GitHub releases page](https://github.com/LANCommander/LANCommander/releases) and grab the latest build for your OS.

```bash
# Check the latest release
curl -s https://api.github.com/repos/LANCommander/LANCommander/releases/latest \
  | grep -E '"tag_name"|"browser_download_url"' | head -5
```text

### Step 2: Configure Your Game Library

Point LANCommander to a folder containing your game executables. The server indexes them automatically and generates download packages that clients can fetch over LAN.

```bash
# Typical folder structure
~/Games/
├── Doom Eternal/
│   └── DOOMEternalx64.exe
├── Hollow Knight/
│   └── Hollow Knight.exe
└── Stardew Valley/
    └── Stardew Valley.exe
```

The server generates a manifest of your library. Clients connect to the server's IP address and browse/download games from there.

### Step 3: Connect Clients

Install the client on any machine in your network. It discovers the server via LAN broadcast or you can point it directly at the server's IP:port. Games download at full LAN speeds — no internet bottleneck.

### Step 4: Launch Games

Once downloaded, games appear in the client with their own launch shortcuts. LANCommander tracks play time and metadata just like a normal launcher.

## Deeper Analysis

### Architecture

LANCommander is built in C# with Avalonia for the cross-platform UI. The server exposes a simple HTTP API for game manifests and package delivery. The client handles downloads, caching, and launch management.

```text
[Game Files] → [LANCommander Server] → [HTTP API] → [LANCommander Client] → [Game Launch]
     ↑              (your machine)         LAN           (any device)
```

### What It Does Well

- **No cloud dependency** — everything stays on your network
- **Full library ownership** — import existing game files, no re-downloading
- **Cross-platform** — Avalonia UI runs on Windows, macOS, Linux
- **Open source** — audit the code, contribute, fork

### Current Limitations

- No built-in achievement or cloud save sync (you handle saves yourself)
- No built-in multiplayer server browser — it's a library manager, not a gaming hub
- Still early-stage — v2.1.0 is recent, so breaking changes are possible

## Security Notes

LANCommander is designed for trusted LAN use. It has no authentication layer by default — anyone on your network can access the server if they know the IP. For untrusted networks, run it behind a VPN or firewall.

The server also serves game files over plain HTTP — not HTTPS. For most home networks this is fine, but keep it in mind if you expose it beyond a trusted subnet.

## FAQ

**Q: Is this a replacement for Steam?**
**A:** Not quite. LANCommander manages and launches games you already own locally. It does not handle game purchases, DRM, or online multiplayer matchmaking.

**Q: Can I use it with game files from multiple sources?**
**A:** Yes. Point LANCommander to any folder containing game executables. It does not validate where the files came from.

**Q: Does it support game updates?**
**A:** You handle updates manually by dropping updated files into the server's game folders. LANCommander re-indexes on next scan.

**Q: What platforms does the server support?**
**A:** Windows, Linux, and macOS via the .NET runtime.

## Conclusion

LANCommander fills a specific niche: power users who want full ownership of their game library without cloud dependencies. If you have a NAS or spare machine and a collection of game files, it gives you a clean, self-hosted alternative to proprietary launchers.

It's not a polished commercial product — expect rough edges and active development. But for open-source enthusiasts who want to self-host everything, it is a solid piece of infrastructure for a personal game library.
