## What Is LimanDoc?

LimanDoc is a knowledge visualization tool that replaces traditional folder hierarchies with infinite zoomable canvases. Instead of nesting files in folders, you place them on a visual canvas where you can see relationships at a glance.

The app stores all data in local files rather than a database, syncing immediately with any file changes made outside the app. This means your data stays portable and you're never locked into a proprietary format.

## Core Features

### Infinite Canvas with Inner Canvases

The main innovation is nested canvases - you can zoom into any element to reveal another canvas inside it. This mirrors how knowledge actually works: topics contain subtopics, documents reference other documents, and ideas branch in multiple directions.

### Multi-Format File Support

Files stored in a vault appear directly on the canvas:

- **PDFs** render inline for quick reference
- **Images** display at full resolution
- **Markdown files** render with full formatting
- **Text files** show content immediately
- **Icons** for visual organization

### Local-First Architecture

LimanDoc follows an offline-first philosophy:

- No central servers handle your files
- All data stored locally in your filesystem
- Peer-to-peer sync only (no cloud dependency)
- Works completely offline
- Changes sync immediately, even from external editors

### Markdown Support

Create rich documents with:

- Lists and todos
- Tables
- Embedded images
- Full markdown syntax

## Security Notes

LimanDoc's local-first architecture has security implications:

**Advantages:**
- Your files never leave your machine unless you explicitly sync
- No third-party servers store your data
- Full control over backups and encryption

**Considerations:**
- You're responsible for your own backups (unless you pay for Lifetime Ownership)
- P2P sync (when available) requires trust in connected devices
- Alpha software may have undiscovered vulnerabilities

## FAQ

**Q: Is LimanDoc open source?**

**A:** No. The founder plans to earn revenue from the software, so it remains proprietary. You can submit bugs and feature requests via GitHub discussions.

**Q: Can I use LimanDoc for free?**

**A:** Yes. The free tier includes unlimited projects, boards, and files with no feature restrictions. The paid tiers add convenience features like automatic backups and priority support.

**Q: How does LimanDoc differ from Obsidian or Notion?**

**A:** Obsidian uses markdown files in folders (hierarchical). Notion uses a database model with cloud sync. LimanDoc uses a visual canvas model with local file storage - you see all your content spatially rather than in nested folders or database views.

**Q: Will my data be portable if I stop using LimanDoc?**

**A:** Yes. Since LimanDoc stores data in standard files (markdown, PDFs, images) rather than a proprietary database, you can access everything with any file manager or compatible app.

**Q: Is the €34 lifetime price a one-time payment?**

**A:** Yes, but the price increases for new customers as more features are added. Early adopters lock in the current price permanently.
