## What It Is

Tech Leads Club's agent-skills registry is a curated catalog of skill definitions for professional AI coding agents. A "skill" here is a structured bundle — typically a `SKILL.md` plus code — that extends a coding agent's capabilities in a specific domain: framework-specific generation, refactoring recipes, test scaffolding, security review, and so on.

The project's pitch is that the wild-west approach to agent skills (anyone can publish anything) doesn't match the trust requirements of professional software teams. The registry exists to add a review layer between skill authors and the agents that consume them.

The current supported agents span the major commercial coding agents:

- **Antigravity**
- **Claude Code**
- **Cursor**
- **GitHub Copilot**

Skills from the registry are designed to load into any of these targets with minimal adaptation.

## Why It Matters

The agent-skills ecosystem has been growing fast, and not all of it has been quality-controlled. A skill with a subtly broken prompt can degrade an agent's output more than it helps. For professional teams that need to trust the tools they ship, this is a real problem.

Tech Leads Club's registry addresses it with three things:

- **Review and validation.** Skills are checked before they hit the registry. Authors can't unilaterally publish unvetted content.
- **Cross-agent compatibility.** A single skill can target multiple agents, reducing fragmentation for users who work with more than one.
- **Versioning and trust signals.** The registry tracks versions, so users can pin to known-good revisions rather than chasing the latest.

For engineering leaders who want to roll out agent capabilities to a team without each engineer hunting through random GitHub repos for "the right skill," a curated registry is a meaningful operational improvement.

## Practical Trade-Offs

A few honest caveats:

- **License is NOASSERTION.** The repository does not assert a standard open-source license. For internal use this is fine, but commercial redistribution should be reviewed against the project's actual terms.
- **Smaller ecosystem.** Compared to the broader agentskills.io / awesome-* collections, the curated registry is necessarily smaller. If you need a niche capability, it may not be there yet.
- **Vendor list is fixed.** Adding a new agent target requires a maintainer to author the bridge. The community can't trivially add new agents themselves.
- **Quality bar has trade-offs.** Curated means slower to publish and fewer total skills. The win is trust; the cost is breadth.

These trade-offs are the explicit point of a curated registry. They're not bugs.

## Who Should Care

This registry is a good fit for:

- **Engineering leaders** standardizing the AI tooling that their team uses.
- **Professional developers** who want vetted skill definitions rather than random community uploads.
- **Platform teams** building internal coding-agent platforms and wanting a trustworthy upstream to pull from.
- **Skill authors** who want their work in front of an audience that values quality over volume.

If you're an indie developer experimenting with cutting-edge agent capabilities, an unvetted skill collection may suit you better. If you're shipping AI-assisted code in a context where correctness matters, the curated registry is worth the slower pace.

## Summary

Tech Leads Club's agent-skills registry is a curated, cross-agent catalog of skill definitions for professional coding agents. The trade-off is explicit: smaller catalog, slower publication, higher trust. For teams that need to deploy AI-assisted coding with confidence, that trade-off is the right one.
