## What Is Ghidra MCP Server?

Most Ghidra integrations with AI agents give you a handful of read-only tools. [bethington/ghidra-mcp](https://github.com/bethington/ghidra-mcp) is different — it was built by a reverse engineer who uses it daily on real binaries.

The project exposes **251 MCP tools** covering every aspect of Ghidra's analysis engine:

- **Function analysis** — decompilation, call graphs, cross-references, completeness scoring
- **Data flow analysis** — PCode-graph value propagation (forward and backward) from any variable or register
- **Data structure discovery** — struct, union, and enum creation with field analysis
- **String extraction** — regex search, quality filtering, string-anchored function discovery
- **Live debugger integration** — 17 Java endpoints plus 22 Python bridge tools over Ghidra's TraceRmi framework (dbgeng on Windows PE, gdb/lldb otherwise)
- **P-code emulation** — run any function in isolation via Ghidra's `EmulatorHelper`; brute-force API hash resolution in milliseconds

## Setup Workflow

### Prerequisites

- Java 21 LTS (OpenJDK recommended)
- Apache Maven 3.9+
- Ghidra 12.1.2
- Python 3.10+ with pip

### Step 1: Install via pip

```bash
pip install ghidra-mcp
```

### Step 2: Run the setup tool

```bash
python -m tools.setup
```

The `ensure-prereqs` command installs runtime Python requirements plus the Ghidra JARs needed in the local Maven repository. The `deploy` command copies the build output, installs the user-profile extension, and patches Ghidra user config.

### Step 3: Start the MCP server

```bash
python -m tools.server
```

By default this starts the headless MCP server. For GUI mode, launch Ghidra normally and the extension activates automatically.

### Step 4: Connect an AI client

Any MCP-compatible AI client can connect to the server to access all 251 tools.

## Deeper Analysis

### Convention Enforcement

The project moves naming conventions from "things to remember" into the tool layer, where they can actually be enforced. Three tiers:

| Tier | Behavior | Example |
|------|----------|---------|
| **Auto-fix** | Applied silently | `count` field on a `uint32` → auto-prefixed `dwCount` |
| **Warn** | Change goes through, warning returned | `processData` → "name should be PascalCase" |
| **Reject** | Change blocked with explanation | `undefined → undefined` type change → blocked |

For AI agents, this means consistent output across every session and model without pasting a style guide into every prompt.

### Batch Operations

Bulk renaming, commenting, typing, and label management reduce API calls by up to 93 percent compared to individual tool calls.

### Cross-Binary Documentation Transfer

SHA-256 function hash matching propagates documentation across binary versions automatically. Document once, apply everywhere.

### Docker / CI/CD

Headless mode makes it suitable for automated analysis pipelines:

```bash
docker run -p 8192:8192 ghcr.io/bethington/ghidra-mcp:latest
```

## FAQ

**Q: What Ghidra version is required?**
**A:** Ghidra 12.1.2 or compatible. Shared Ghidra Server users need server version 12.1, 12.0.5, or newer.

**Q: Can this run without a display?**
**A:** Yes. Headless server mode works in Docker and CI/CD pipelines without any GUI.

**Q: What programming languages do the scripts support?**
**A:** Java scripts work by default. Python scripts require the Jython extension, installable via **File > Install Extensions** in the Ghidra GUI.

**Q: How does it compare to a standard Ghidra installation?**
**A:** Standard Ghidra is a GUI application. This MCP server wraps Ghidra's analysis engine as 251 programmatic tools accessible over a network protocol, making it suitable for AI agent integration.
