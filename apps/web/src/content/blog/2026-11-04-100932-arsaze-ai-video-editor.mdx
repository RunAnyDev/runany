> **TL;DR:** Arsaze puts an AI agent inside a real multi-track video timeline. Connect Claude, ChatGPT or Grok to its remote MCP server and the agent makes cuts, captions and grades that you watch happen and can undo. The desktop app for Windows, Mac and Linux runs transcription, background removal and exports on your own machine, free on every plan.

## What it is

Most AI video tools take a prompt, render a clip and hand it back. Arsaze keeps the editor and lets an agent operate it. The company's own phrase is "Cursor for video editing", and founder Arshad Azeez M (Sidhilynx) built the product around one idea: the agent should work on the same timeline you are looking at, not generate a separate result.

That timeline is a full non-linear editor. Multi-track video, text, overlays and audio, trim modes, color wheels, keyframes, an After Effects panel in beta. You can export an MP4 or an FCPXML project that opens in DaVinci Resolve and Premiere Pro with your cuts, transitions and captions intact. Arsaze runs in a browser and as a desktop app for Windows, macOS and Linux, and the company says it is used in 70 countries.

## Three ways to edit the same project

- **Tab** is autocomplete for editing. Make one edit and the editor previews the next one in the same style. Cut a pause and it offers the other pauses, grade a clip and it offers the matching grade on shots that look alike. Tab accepts it, Shift+Tab takes one part at a time, Esc leaves it alone. Nothing on the timeline changes until you press Tab, and every accepted suggestion is a single undo step.
- **Rewrite** treats the transcript as a document. Delete a word and that word is cut out of the video, and every cut stays a tracked change you can put back.
- **Agent** mode hands the controls to a chat client. Each tool call plays back live on the timeline as it happens, so you watch the agent work instead of waiting on a render.

## Connecting an agent over MCP

The server is remote, uses Streamable HTTP, and authenticates with OAuth 2.1 and PKCE. There is no API key to paste, and the first connection asks you to sign in to your Arsaze account and approve it.

Most MCP clients read a server block like this:

```json
{
  "mcpServers": {
    "arsaze": {
      "type": "http",
      "url": "https://api.arsaze.com/mcp"
    }
  }
}
```

Arsaze documents the interface for the main clients:

- Claude: Settings, then Connectors, then Add custom connector, then paste the server URL.
- ChatGPT: add a custom MCP connector and paste the same URL.
- Grok: grok.com/connectors, then New Connector, then Custom.

The guide says any client that speaks remote MCP over Streamable HTTP with OAuth 2.1 can connect, which covers Gemini, Codex, Cursor, Copilot and Windsurf too. You can check the connection and browse the available tools before touching a project:

```bash
npx @modelcontextprotocol/inspector https://api.arsaze.com/mcp
```

## What the agent is allowed to do

From the Arsaze MCP guide, the exposed tool surface covers:

- **Projects and assets**: list and create projects, search the asset library, upload media.
- **Timeline editing**: add, trim, split and ripple-delete clips, add transitions, render.
- **Color and effects**: LUTs, color wheels, RGB curves, HSL secondaries, cinematic looks.
- **Audio**: voiceover generation, automatic ducking, loudness normalization, sound effects.
- **Generation**: video, avatar video, voice, thumbnails, images, music and sound effects.
- **Captions and review**: automatic captions, shareable review links, comment threads.

Every edit is versioned as it happens, so a bad agent edit is a single undo away and nothing the agent does is one-way. You can also hand a project to a client as a review link, they draw on the frame and leave notes, and the agent reads those notes and applies the fixes.

## Local projects and the desktop app

The desktop build keeps your media on disk. A local project never uploads your video, audio or images, and you can still let an agent edit it, or switch that off per project. The timeline and its version history are stored in your account, so you need to be online while you edit. Unlimited local projects are available on any plan and you can push one to the cloud in one click.

What runs on your own processor is free forever on every tier, including Free: English speech-to-text (other languages fall back to cloud transcription and spend credits), background removal that cuts a person out without a green screen, motion tracking, and local exports that carry no watermark and do not eat cloud render hours. Exports render on Arsaze's servers by default, which means you do not need a fast machine to finish a project.

Current builds are Windows 2.0.1, macOS 1.3.0 in beta for Apple silicon running macOS 14 Sonoma or newer, and a 64-bit Linux AppImage:

```bash
chmod +x Arsaze-1.3.0-x86_64.AppImage
./Arsaze-1.3.0-x86_64.AppImage
```

## What it costs

Pricing is billed monthly in Indian rupees through Razorpay, with UPI, cards and net banking accepted. A free plan needs no card and includes the whole editor. The dividing line between free and paid is generation and cloud work, not editing features.

| Capability | Free plan | Paid plan |
| --- | --- | --- |
| Timeline, color, audio, captions | Included | Included |
| On-device transcription (English) | Included | Included |
| Background removal, motion tracking | Included | Included |
| Local exports, no watermark | Included | Included |
| AI generation (video, image, voice, music) | Needs a credit pack | Monthly credits |
| Cloud transcription, other languages | Needs a credit pack | Monthly credits |
| Cloud export hours | Needs a credit pack | Monthly allowance |
| AI assistant and Animate Studio | Needs a credit pack | Included |

Credit packs are one-time top-ups that never expire, and buying one on the free plan switches you to pay as you go. Enterprise pricing is negotiated around your volume of credits, render capacity and storage.

## What to watch for

The local-first story has a seam in it. Your footage stays on disk, but the timeline and version history live in your account, so the app needs an internet connection while you edit and while a local export runs. You also cannot transcribe non-English speech locally today.

Arsaze is commercial software (copyright Arsaze, made by Sidhilynx) and the GitHub repository it publishes, github.com/AnrosPrac/arsaze-mcp, holds connection documentation rather than the editor itself, with no license file present. Pricing is quoted in INR only, which is worth keeping in mind if you budget outside India.

Tab is the feature most likely to divide people. It is the most interesting idea here, since it turns a repetitive edit into a single keystroke, but suggestions arrive after every edit and Esc exists because you will want to dismiss them.
