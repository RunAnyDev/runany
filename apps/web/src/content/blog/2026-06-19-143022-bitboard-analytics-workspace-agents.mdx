## TL;DR

> **TL;DR:** BitBoard is a hosted analytics workspace designed for AI agents. Connect your data sources, query them using Claude, Cursor, or ChatGPT, and publish the results as durable, shareable dashboards instead of losing insights in ephemeral chat threads.

## What Is BitBoard?

BitBoard is a Y Combinator W26-backed analytics workspace that flips the script on how AI agents and humans collaborate on data work. Instead of running one-off queries in a chat window and losing the thread, BitBoard lets you wire up data sources, build queries with your favorite AI assistant, and publish the results as a hosted dashboard anyone can access — with a full trace of how each number was computed.

From the BitBoard docs: "Build hosted dashboards and reports with your agent."

## Key Features

- **AI-first query building** — compose queries using Claude, Cursor, or ChatGPT directly within the workspace
- **Data source connectors** — connect databases, APIs, and other data backends; query them through AI-assisted steps
- **Durable dashboards** — unlike chat threads, dashboards persist and can be shared with teammates or embedded externally
- **Full query traceability** — every number on a dashboard links back to its query lineage, so you can audit how it was computed
- **Free individual plan** — no credit card required, unlimited access for solo users

## FAQ

**Q: Is BitBoard open source?**
**A:** No. BitBoard is a hosted SaaS product. There is no public source repository.

**Q: Which AI models are supported?**
**A:** The workspace integrates with Claude, Cursor, and ChatGPT for query building. The exact scope of each integration is documented at docs.bitboard.work.

**Q: Does it support self-hosting?**
**A:** No. BitBoard is a fully hosted service. The Teams plan offers centralized admin and billing for organizations, but the infrastructure remains on BitBoard's side.

**Q: What data sources can I connect?**
**A:** BitBoard provides connectors for databases and APIs. Check the docs at docs.bitboard.work for the current list of supported backends.

**Q: Is there a free trial for Teams?**
**A:** Teams pricing is custom. You contact BitBoard directly via the contact page to discuss terms.

## Conclusion

BitBoard tackles a real problem: AI agents are great at exploring data, but the output — a chat thread — does not survive contact with the rest of the team. By letting you wire up data sources, run AI-assisted queries, and publish durable traceable dashboards, BitBoard makes analytics work from AI agents shareable and auditable. The free individual tier makes it easy to try without committing budget. If you regularly use Claude, Cursor, or ChatGPT to answer data questions, BitBoard is worth a look.
