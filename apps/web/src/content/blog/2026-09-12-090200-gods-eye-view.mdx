## TL;DR

> **TL;DR:** gods-eye-view is a single-page browser app that mimics a satellite-style situational awareness console. It pulls live open source feeds — ADS-B flights, AIS ship traffic, public satellite imagery — and renders them on a photoreal 3D globe with Cesium. Everything runs in the browser. There is no server to stand up.

## What Is gods-eye-view?

The repository description is one line: "A spy satellite simulator in your browser, except the data is real. Live open source spatial intelligence on a photoreal [globe]." That is the entire pitch. It is not a tool for intelligence analysts — it is a tech demo that happens to be useful for journalists, hobbyists, infra curious, and anyone who has ever wanted to watch every commercial flight on Earth at once.

The project lives at `bilawalsidhu/gods-eye-view` and uses Cesium, the open source WebGL globe engine, as its rendering layer. The topics — `3d-globe`, `cesium`, `flight-tracking`, `geospatial` — confirm the focus: a real, queryable geospatial dashboard in the browser.

## How It Works

The app is JavaScript end-to-end and renders in any modern browser that supports WebGL. There is no required backend:

- Flight positions come from open ADS-B aggregators that publish feeds.
- Ship positions come from public AIS feeds.
- Imagery comes from public satellite tile providers, also rendered by Cesium.
- The globe UI is a Cesium viewer with custom overlays for live tracks.

Because everything is browser-side, deployment is just hosting the static bundle. Open the URL, the globe loads, and feeds start drawing tracks in real time. There is no API key to register for the basic experience, although specific tile providers may require their own credentials if you self-host heavily.

## When To Use It

gods-eye-view is the right tool when:

- You want a visual explainer for how open source geospatial data actually works.
- You are building a dashboard or kiosk and need a Cesium-based starting point.
- You want to demo live ADS-B / AIS / satellite feeds without standing up a backend.
- You are curious what "open source intelligence" looks like at hobby scale.

It is not a substitute for paid satellite tasking, classified feeds, or commercial OSINT tooling. The data sources are public, the latency is whatever the upstream feeds deliver, and the rendering depends on the user's GPU and bandwidth.
