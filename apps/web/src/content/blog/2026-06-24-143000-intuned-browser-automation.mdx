## What Is Intuned?

Intuned describes itself as a code-first browser automation platform with two components:

1. **A deployment platform** — run browser automations as code with built-in authentication, stealth (anti-bot evasion), proxy rotation, captcha solving, scheduling, monitoring, and scale.
2. **An AI agent** — given a natural language prompt and a schema, Intuned Agent writes Playwright code that performs the automation. The agent then monitors runs, diagnoses failures, and self-heals broken selectors when sites change.

The platform supports three automation types:
- **Scrapers** — extract structured data from any website (e-commerce, job boards, government portals, etc.) on a schedule
- **Crawlers** — discover, navigate, and collect data across thousands of pages with sitemap following and link traversal
- **RPA** — browser-based workflow automation for form submissions, data entry, and account actions where no API exists

The output is always production-ready Playwright code you can read, debug, and own. You can write it by hand, or let the AI generate it.

## Setup Workflow

### Step 1: Create a free account

Sign up at [app.intuned.io](https://app.intuned.io). The Starter plan is free with limited compute hours.

### Step 2: Install the CLI

```bash
npm install -g @intuned/intuned
```

Or use the online IDE directly in the dashboard—no local setup required.

### Step 3: Initialize a project

```bash
intuned init
```

This creates an `intuned.json` configuration file in your project directory.

### Step 4: Define your automation

Create a `scrape.ts` file (or `.py`):

```typescript
// scrape.ts
export const schema = {
  productName: "string",
  price: "number",
  rating: "string",
};

export async function scrape(page: Page) {
  await page.goto("https://example.com/products");
  const products = [];
  for (const row of await page.locator(".product-card").all()) {
    products.push({
      productName: await row.locator(".title").textContent(),
      price: await row.locator(".price").textContent(),
      rating: await row.locator(".rating").textContent(),
    });
  }
  return products;
}
```

### Step 5: Run locally or deploy

```bash
# Run locally
intuned run

# Deploy to Intuned cloud
intuned deploy
```

## Deeper Analysis

### How the AI agent works

The Intuned Agent takes a natural language description of what you want to scrape and a JSON schema defining the output shape. It generates Playwright code, tests it against the live page, and iterates until it works. If a run fails later due to a site change, the agent receives the failure trace, diagnoses the broken selector, and patches the code autonomously.

### Authenticated scraping

For sites behind a login, Intuned manages the session lifecycle via `create.ts` (validates/authenticates) and `check.ts` (verifies session is still active). You define these functions; Intuned handles when to call them and how to persist session state across runs.

### Stealth and bot detection

Intuned's stealth mode handles:
- Anti-detection browser fingerprints
- Proxy rotation (residential and datacenter)
- Captcha detection and solving

The platform has integrations with Browser Use, Stagehand, Anthropic Computer Use, OpenAI CUA, and Gemini Computer Use for AI-driven UI interaction—alternatively, you can control the browser directly via Playwright API calls (faster, lower cost).

### Integrations

The platform ships with first-class integrations for:
- **Crawl4AI** — deploy and scale crawlers without managing infrastructure
- **Webhook / AWS S3 / Cloudflare R2 / Supabase** — data sinks for scraped output
- **1Password** — secret management via the 1Password integration

## Practical Evaluation Checklist

- Write a scraper for a public site in under 15 minutes
- Verify the AI-generated code is readable Playwright (not a black box)
- Test self-healing by manually breaking a selector and checking if the agent fixes it
- Confirm authenticated scraping works with a site requiring login
- Check the observability dashboard for trace and session recording
- Evaluate stealth mode against a known bot-detection site (e.g., Cloudflare protected)

- Credentials and secrets are managed via 1Password integration or environment variables

- Data retention policies vary by plan (7 days free, 30 days paid, custom enterprise)

## FAQ

**Q: Is the core platform open source?**
**A:** No. The Intuned platform is proprietary SaaS. They publish a [cookbook of example scripts](https://github.com/intuned/cookbook) on GitHub, but the core platform and AI agent are not open source.

**Q: How does Intuned compare to browser-use.com or Camoufox?**
**A:** browser-use.com is a Python library for AI-driven browser control via LLM. Camoufox is a Python anti-detection browser built on Playwright. Intuned is a hosted platform—it handles infrastructure, scheduling, monitoring, and AI code generation on top of Playwright. The output is still Playwright code you own.

**Q: Does it support Python?**
**A:** Yes. You can write automations in TypeScript or Python using Playwright or compatible frameworks.

**Q: What happens if the AI generates broken code?**
**A:** You own and can edit the generated Playwright code directly. The AI agent assists and maintains, but you always have full control over the source.

**Q: Can I self-host Intuned?**
**A:** No. Intuned is a hosted SaaS platform. There is no self-hosted option at this time.

## Conclusion

Intuned fills the gap between writing a one-off Playwright script and running a full scraping infrastructure. The AI agent handles code generation and maintenance—the two most time-consuming parts of browser automation at scale. If you regularly deal with sites that change without notice, require authentication, or need scheduled runs with observability, Intuned is worth evaluating. The free Starter plan gives you enough hours to build and test a real scraper before committing to a paid tier.
