> **TL;DR:** `abue-ammar/tinycast` is a Swift-built macOS launcher, hotkey manager, and clipboard history tool that stays small enough to read. It is at 5,628 stars and ships its own homepage at `abue-ammar.github.io/tinycast`.

## What it is

`abue-ammar/tinycast` describes itself as "Tinycast — a tiny, fully native macOS launcher, hotkeys, and clipboard history." The repo is authored by `abue-ammar`, the language is Swift, the license is `NOASSERTION` (the upstream has not pinned an SPDX identifier), and the project sits at 5,628 stars with 271 forks. It is not archived, and the repository ships a homepage at `https://abue-ammar.github.io/tinycast/`.

The pitch is "fully native" — no Electron wrapper, no helper VM, no Rosetta. For a launcher that runs in the foreground every few minutes, that translates into noticeably less CPU and memory overhead than the JavaScript-based alternatives.

## What it does well

A native macOS utility has three jobs: launch apps fast, give you reliable hotkeys, and keep your clipboard history without leaking it. Tinycast hits all three.

- **Launcher.** A keystroke brings up a search box that matches app names and runs the chosen one via the standard macOS APIs. The behaviour is close to Spotlight or Raycast, but it lives in the user's terminal-free muscle-memory lane.
- **Hotkeys.** System-level keyboard shortcuts are configurable per-action, so you can wire a key combination to any of the bundled behaviours without learning a scripting language.
- **Clipboard history.** The past items are kept locally, which matters for a tool that reads whatever is on the clipboard. There is no cloud round-trip.
- **Tiny footprint.** The repo's stated emphasis on size means fewer dependencies to update, fewer attack surfaces to think about, and faster cold launches.

## How to try it

The homepage has the binary; for source builds:

```bash
git clone https://github.com/abue-ammar/tinycast.git
open tinycast.xcodeproj   # build with Xcode
```

Once running, the launcher is bound to a configurable hotkey and the clipboard history window appears with another shortcut.

## When it fits, and when it doesn't

Tinycast fits anyone on macOS who wants a launcher and clipboard manager without the overhead of a cross-platform framework, especially on Apple Silicon where native code is the cheap path. It is less attractive if you are not on macOS, or if your launcher muscle memory is locked to a specific tool's UI conventions and you do not want to relearn.
