## What Is Intuned?

Intuned solves the "Zapier problem at scale" — when you need to integrate with a service that has no API, your only traditional options were either paying for a Zapier integration or building a fragile scraper that breaks the moment the website changes.

Intuned flips this. You give it a goal (e.g., "extract all product listings from this supplier portal"), and the Intuned Agent watches a human perform the task in a browser. It reverse-engineers the underlying network calls or DOM interactions, then generates deterministic, production-ready code that replicates the workflow.

The generated code runs on Intuned's infrastructure with:
- Auth session management (cookie-based, OAuth, email OTP, TOTP)
- Captcha solving (reCAPTCHA, Cloudflare)
- Retry logic and observability
- Concurrent execution control

The AI agent also monitors the automation and proactively rewrites the code when the target site changes.

## Setup Workflow

### Step 1: Install the CLI

```bash
npm install -g @intuned/cli
```

### Step 2: Create a project from a template

```bash
npx create-intuned-project@latest
```

The interactive wizard asks for language (TypeScript or Python), a template (e.g., `starter-rpa`, `starter-auth`, `captcha-in-login`), and a project name.

### Step 3: Configure your API key

Create a `.env` file:

```
INTUNED_API_KEY=your_api_key_here
```

Get your key from the [Intuned dashboard](https://app.intuned.io).

### Step 4: Run an API locally

**TypeScript:**

```bash
yarn install
intuned dev run api <api-name> .parameters/api/<api-name>/default.json
```

**Python:**

```bash
uv sync
intuned dev run api <api-name> .parameters/api/<api-name>/default.json
```

The cookbook repo includes 30+ examples covering RPA, auth sessions, captcha solving, AI-powered extraction, and network interception.

## Deeper Analysis

### What the AI agent actually does

The agent uses a combination of browser automation (Playwright under the hood) and network interception to observe the human performing a workflow. It captures:

1. **Network calls** — reverse-engineers API requests, headers, and body formats
2. **DOM interactions** — records clicks, form fills, and pagination patterns
3. **Auth flows** — captures cookies, session tokens, or full OAuth exchanges

From this, it generates a project with:
- A `runner.ts` / `runner.py` — the execution entry point
- Per-API parameter files in `.parameters/api/<name>/`
- Auth session definitions
- Retry and concurrency config

### Two execution models

**Runs** — single API execution via SDK. You pass parameters, get a result back. Built for RPA and on-demand integrations.

```typescript
const result = await intunedClient.project.run.start("rpa-example", {
  api: "list",
  parameters: { category: "books" },
  retry: { maximumAttempts: 4 },
  authSession: { id: "test-auth-session" },
});
```

**Jobs** — scheduled, batched execution across multiple machines. Built for scrapers and crawlers with high throughput needs.

## Practical Evaluation Checklist

- **Does it require the site to have an API?** No — browser automation is the fallback
- **How does it handle site changes?** AI agent proactively monitors and rewrites automation code
- **Auth support:** Cookie-based, OAuth, email OTP, TOTP, secret OTP
- **Concurrent execution:** Yes — Jobs model supports parallel machines
- **Language support:** TypeScript and Python
- **Captcha solving:** Built-in for reCAPTCHA and Cloudflare
- **Local development:** `intuned dev run` for fast iteration without cloud execution

## Security Notes

- Auth sessions are stored and managed by Intuned's infrastructure
- API keys are required for cloud execution
- The platform runs your code on their machines; review their [Terms of Service](https://intunedhq.com/docs/main/06-resources/terms-of-service) for your use case
- Code is generated deterministically — you own and can audit the output

## FAQ

**Q: How is this different from using Playwright directly?**
**A:** Playwright is the underlying browser tool, but Intuned automates the hardest part — figuring out *what* to automate. Without Intuned, you have to reverse-engineer the target site yourself, write the Playwright code, and maintain it when the site changes. Intuned's agent does the reverse-engineering and ongoing maintenance.

**Q: Does it work with any website?**
**A:** Any website accessible via browser. Sites with strong bot detection may vary; the platform has stealth mode features on higher plans.

**Q: Is the generated code mine?**
**A:** Yes. The cookbook generates standard TypeScript/Python projects using Playwright and your choice of AI provider (Anthropic, OpenAI, Gemini). You own the code and can run it outside Intuned's infrastructure if you prefer.

**Q: What does the AI agent actually generate?**
**A:** A complete project with a runner script, API parameter files, and auth session definitions. The agent observes a human performing the workflow in a browser and outputs the equivalent programmatic steps.

**Q: How does pricing work?**
**A:** Developer plan is $25/mo with 100 compute hours and 100 job runs included. Overage is $0.12/hour for compute and $0.12/run for job runs. Startup ($120/mo) includes 500 compute hours and 400 job runs. All plans include AI credit (Developer gets $5/mo).

## Conclusion

Intuned targets the long tail of web integrations — the services that have no API but you still need to automate. The AI agent approach shifts the burden from "write fragile scraper code" to "show the AI what you want, get production code." For developers building data pipelines, RPA tools, or any integration that needs to survive site changes, this is worth evaluating.

The free tier gives you enough to test the workflow end-to-end before committing to a paid plan.
