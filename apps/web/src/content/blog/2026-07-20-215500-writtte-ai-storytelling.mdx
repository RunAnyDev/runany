## What Is Writtte?

Writtte is a web-based AI writing editor designed for long-form content creation. The product is aimed at indie founders, bloggers, and creators who need to produce polished articles regularly but find existing tools either too bare-bones (plain editors) or too noisy (bloated all-in-one suites).

The core promise is a **distraction-free writing environment** with AI assistance wired in — think Hemingway Editor meets Notion AI, but scoped specifically to article and blog post workflows.

On the publishing side, Writtte integrates directly with **WordPress**, **Medium**, **Substack**, and plain **Markdown export**. This is the practical differentiator: the output format is baked in, not bolted on after the fact.

```
Writtte workflow:
Idea → Distraction-free draft → AI refine → One-click publish
                                    ↓
              WordPress | Medium | Substack | .md file
```

## Key Features

**Distraction-free editor**
Clean, minimal interface. No toolbars cluttering the writing area. The editor itself is the product — not a vehicle for upselling a suite of features you will never use.

**AI-assisted drafting**
AI helps at the sentence and paragraph level: rephrasing, tightening prose, expanding ideas. The AI is an in-editor assistant, not a separate chat window you have to copy-paste into.

**Direct publishing integrations**
Content can be sent directly to connected accounts:
- WordPress (via REST API)
- Medium (via Medium API)
- Substack (via Substack publishing)
- Markdown file download for static site authors

**Format templates**
The editor supports article-length templates (intro → body → conclusion) rather than generic blank-page syndrome. Starting from a structure reduces the friction of a blank screen.

## Setup Workflow

Writtte is a web app — no installation required.

### Step 1: Create an account

Visit [writtte.xyz](https://writtte.xyz) and sign up with email or a social account (Google/GitHub if offered).

### Step 2: Connect your publishing accounts

In the sidebar or settings, connect the platforms you publish to:

```text
Settings → Publishing
  → Connect WordPress (enter your site URL + application password)
  → Connect Medium (OAuth via Medium integration)
  → Connect Substack (OAuth via Substack)
```

Each connection is one-time. After that, publishing is a single click from within the editor.

### Step 3: Start a new article

Click **New Article** and choose a template or start from scratch. The editor opens in full-screen distraction-free mode.

### Step 4: Write with AI assist

Use AI commands via keyboard shortcut or sidebar panel:
- `Ctrl+Shift+R` — refine selected text
- `Ctrl+Shift+E` — expand selected text
- `Ctrl+Shift+S` — simplify / tighten prose

### Step 5: Publish

When the draft is ready, click **Publish** and select your destination:
- **Draft** — save to Writtte cloud
- **WordPress** — pushes to your connected site
- **Medium** — publishes to your Medium publication
- **Substack** — posts to your Substack newsletter
- **Download .md** — saves Markdown to your machine

## Security Notes

- Writtte stores your drafts in their cloud — treat it like any cloud writing tool.
- Publishing integrations require API credentials (WordPress application password, OAuth tokens for Medium/Substack). These are stored by Writtte.
- For WordPress self-hosted sites, use a dedicated application password rather than your main admin password. This can be revoked independently at `your-site.com/wp-admin/users.php`.
- No content is used for model training by default on most tiers — check the privacy policy for your plan.
