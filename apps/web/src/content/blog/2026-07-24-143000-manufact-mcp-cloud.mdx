## What Is Manufact?

Manufact is a YC S25 company building infrastructure for the Model Context Protocol (MCP) ecosystem. Their flagship product, **Manufact Cloud**, is a managed hosting platform for MCP servers and agents. They also maintain **mcp-use**, an open-source SDK for building MCP servers and clients in TypeScript and Python.

The mcp-use repo has over 10,000 stars on GitHub and is actively maintained. The SDK lets developers build once and deploy across multiple MCP clients (ChatGPT, Claude, etc.) without rewriting integration code.

### Key features from the mcp-use SDK

- **Cross-client compatibility** — build MCP Apps for ChatGPT, Claude Connectors, and MCP Servers for AI agents from a single codebase
- **TypeScript and Python** — SDKs available for both languages
- **Inspector** — built-in debugging tool for tracing, replaying, and inspecting MCP traffic
- **Templates** — pre-configured starters for common MCP frameworks and use cases

## Setup Workflow

### Prerequisites

- Node.js 18+ or Python 3.10+
- A Manufact Cloud account (free tier available)

### Step 1: Install the SDK

```bash
# TypeScript
npm install mcp-use

# Python
pip install mcp-use
```

### Step 2: Create an MCP Server

```typescript
import { createServer } from 'mcp-use';

const server = createServer({
  name: 'my-mcp-server',
  version: '1.0.0',
});

server.tool('greet', {
  description: 'Greet a user by name',
  schema: {
    name: { type: 'string', required: true },
  },
  async handler({ name }) {
    return { message: `Hello, ${name}!` };
  },
});

server.start();
```

### Step 3: Deploy to Manufact Cloud

```bash
npx mcp-use deploy
```

The CLI handles containerization, scaling, and routing. Manufact Cloud provides a dashboard for monitoring latency, usage, and reliability across deployed servers.

## Deeper Analysis

Manufact fills a gap in the MCP ecosystem: while the protocol itself is open, there is no managed hosting platform purpose-built for MCP workloads. Running MCP servers on generic PaaS infrastructure requires custom health checks, traffic routing, and multi-client testing.

The **Cloud Inspector** is particularly useful — it captures real MCP traffic in production and lets you replay sessions for debugging. This is valuable because MCP interactions are stateful and multi-step, making reproduction of issues difficult without a recording mechanism.

The **cross-client testing** feature lets you verify your MCP server behaves identically across ChatGPT, Claude Desktop, and other MCP clients before shipping.

## FAQ

**Q: Is mcp-use the same as the official MCP SDK from Anthropic?**

**A:** No. Anthropic released the MCP specification and reference implementations. mcp-use is a third-party open-source SDK maintained by the Manufact team, designed for building production-ready MCP apps and servers with cross-client support.

**Q: Can I self-host MCP servers without Manufact Cloud?**

**A:** Yes. The mcp-use SDK is open-source and runs on any Node.js or Python hosting environment. Manufact Cloud adds managed infrastructure, scaling, and the Cloud Inspector for production deployments.

**Q: What MCP clients are supported?**

**A:** The mcp-use SDK targets ChatGPT (Apps), Claude (Desktop and Connectors), and any client implementing the standard MCP protocol. Check the [mcp-use compatibility matrix](https://manufact.com/mcp-use) for the full list.

**Q: Does Manufact work with existing MCP servers built on the official Anthropic SDK?**

**A:** Yes, as long as the server implements the standard MCP protocol. Manufact Cloud acts as a hosting and routing layer, not a protocol translator.
