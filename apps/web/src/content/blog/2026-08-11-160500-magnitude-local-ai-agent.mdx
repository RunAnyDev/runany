## What Is Magnitude?

Magnitude is an open-source AI agent built on local models, with its own inference engine. From the project's README:

> "Open source agent built on local models, with its own inference engine. 100% private and offline. No token costs. No API keys. No rate limits."

It supports macOS and Linux natively; Windows is supported through WSL.

## Setup Workflow

### Step 1: Install the CLI

```bash
npm install -g @magnitudedev/cli
```

### Step 2: Initialize in your project

```bash
cd your-project
magnitude
```

The CLI will profile your hardware and guide you through the first-run model download.

### Step 3: Add capabilities with skills

Magnitude ships with file editing and shell execution out of the box. Extend it with skills:

```bash
npx skills add vercel-labs/agent-browser   # drive your logged-in Chrome browser
npx skills add anthropics/skills/xlsx      # read and build Excel spreadsheets
npx skills add anthropics/skills/pptx      # build PowerPoint decks
npx skills add anthropics/skills/docx      # read and write Word documents
npx skills add anthropics/skills/pdf       # read, fill, and create PDFs
```

Skills are reusable capability packages sourced from [skills.sh](https://www.skills.sh).

## How the Inference Engine Works

Magnitude includes a custom inference engine written in Rust on top of [llama.cpp](https://github.com/ggerganov/llama.cpp). Key capabilities:

- **Verified model configurations** — tested presets for known models
- **Memory profiling** — calculates RAM requirements before loading
- **Tuned batching** — optimized for agent workloads (parallel agents retain full context windows)
- **Native performance metrics** — surfaces prefill, cache reuse, and generation speed in the agent UI

## FAQ

**Q: Does Magnitude require an internet connection?**
**A:** Only for the initial model download. After that, it runs fully offline.

**Q: What models does it support?**
**A:** Magnitude profiles your hardware and recommends models. It uses llama.cpp under the hood, supporting any GGUF-format model.

**Q: How does it compare to using the OpenAI or Anthropic API directly?**
**A:** Magnitude keeps all data on your machine. You trade API convenience for complete data privacy and zero per-token cost.

**Q: Does it work on Windows?**
**A:** Windows is supported through WSL. Native Windows support is not yet available.

## Conclusion

Magnitude replaces the API call with a local inference engine, giving you an AI agent that never phones home. Install it with one npm command, point it at a local model, and add skills as needed. The Apache 2.0 license means you can inspect, modify, and redistribute the inference engine.
