## TL;DR

> **TL;DR:** `LinkSwift` is a browser userscript that turns share pages on Chinese cloud storage into direct download links you can hand to a download manager. It covers eight services, from Baidu and Aliyun through to Quark and 123Pan, and is the most-starred project on this list at 23,755 stars under AGPL-3.0.

## What it is

The repository describes itself, in Chinese, as a JavaScript-based tool for obtaining direct download addresses for files on cloud drives. It is a modification of an earlier project, 网盘直链下载助手, which translates roughly as "cloud drive direct link download assistant". That lineage is the whole idea: instead of pulling files down through a web interface that may be slow, limited, or gated, you get a URL and use whatever downloader you prefer.

Eight services are named in the description, and the GitHub topics corroborate several of them:

| Service | Chinese name |
| --- | --- |
| Baidu Netdisk | 百度网盘 |
| Aliyun Drive | 阿里云盘 |
| China Mobile Cloud | 中国移动云盘 |
| Tianyi Cloud | 天翼云盘 |
| Xunlei Cloud | 迅雷云盘 |
| Quark Cloud | 夸克网盘 |
| UC Cloud | UC网盘 |
| 123Pan | 123云盘 |

The repository's topics include `123pan`, `aliyun-drive`, `aliyunpan`, and `baidu`, which line up with the description, plus `aria2`. That last topic is the practical point: the output is a direct link, and `aria2` is the downloader it is being pointed at.

JavaScript is the language, AGPL-3.0 is the license, and it is one of the older repositories on this list, created on 10 August 2022. It has 23,755 stars, 1,439 forks, and 38 open issues, and it was last pushed on 10 September 2026.

## How to try it

The homepage the repository declares is not a site. It is a raw userscript file:

```text
https://github.com/hmjz100/LinkSwift/raw/main/（改）网盘直链下载助手.user.js
```

The `.user.js` extension is the convention browser script managers such as Tampermonkey use, which is why the project is distributed as a file rather than a package. A more recent default branch is available, since the repository's default branch is `dev` while the declared homepage still points at `main`.

Once a link is in hand, `aria2` takes it directly:

```bash
aria2c "https://example.com/file.zip"
```

## When to use it

Reach for it when you are pulling a large file from one of these services and the web downloader is the bottleneck. Direct links also play better with segmented and resumed downloading, which is why the `aria2` topic is on the repository.

Because it is a userscript rather than a service, it does the work inside a browser you already have open and logged in. Nothing about it requires giving up your account credentials to a third party.

## When NOT to use it

A userscript runs with access to the pages you visit, so weigh that against what the convenience is worth. Installing it means trusting third-party code inside your logged-in session, and AGPL-3.0 governs how modifications are shared, not how safe a given script is to run.

It is also built for a specific purpose. If you need scheduled sync, sharing, or team access to these drives, this is the wrong tool.
