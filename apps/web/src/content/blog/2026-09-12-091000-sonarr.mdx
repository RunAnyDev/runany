## TL;DR

> **TL;DR:** Sonarr is a mature, open source PVR (personal video recorder) for TV shows. It automates the download pipeline — find episodes, grab them from newsgroups or BitTorrent, sort them into your library, and rename them to a clean scheme. It is the TV-show counterpart to its sibling project Radarr, and it has been the default self-hosted media manager for over a decade.

## What Is Sonarr?

The repository description is direct: "Smart PVR for newsgroup and bittorrent users." Sonarr lives at `Sonarr/Sonarr` and is one of the older projects on GitHub's trending list — the codebase is mature, the install base is large, and the project has years of community polish behind it.

Sonarr sits in the *Servarr suite* of self-hosted media tools. The pattern across the suite is the same: each project automates one type of media. Sonarr owns TV shows, Radarr owns movies, Lidarr owns music, Readarr owns books, and so on.

## How It Works

The C# codebase runs as a long-lived service on a server. The architecture implied by the project:

- A library view that tracks the TV shows you follow and which episodes you own.
- Indexer integrations with newsgroups (via NZB) and BitTorrent trackers.
- A download client integration — Sonarr hands off to SABnzbd, qBittorrent, Transmission, etc.
- Post-processing that sorts downloads into the library, renames files to a consistent scheme, and updates metadata.

The user-facing experience is a web UI. You add a show, Sonarr checks the schedule, grabs new episodes as they air, and drops them into your media folder ready for Plex, Jellyfin, or Kodi to serve.

## When To Use It

Sonarr is the right tool when:

- You run a self-hosted media server (Plex, Jellyfin, Emby, Kodi) and want automated TV-show management.
- You are comfortable operating a long-lived service and configuring indexers and download clients.
- You want a project that has stood the test of time rather than the newest shiny alternative.

It is not a streaming service, it does not provide content, and it does not bypass copyright. Sonarr is a library manager. What it grabs is determined by the indexers and sources you point it at.
