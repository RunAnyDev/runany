## What Is Sourcetable Superagents?

Sourcetable Superagents is an extension of the Sourcetable platform that lets you connect a spreadsheet interface to external data sources — databases, APIs, and MCP servers — and query them using natural language. Instead of writing SQL or building ETL pipelines, you type a question in plain English and the AI translates it into a live query against your connected source.

The platform supports Postgres, MySQL, MongoDB, Google Analytics, Stripe, and any API or MCP server you wire up. Query results populate directly into the spreadsheet, where you can pivot, filter, and summarize them like any other sheet data.

## Setup Workflow

### Step 1: Create a free Sourcetable account

Sign up at [sourcetable.com](https://sourcetable.com). The base spreadsheet is free to use; AI query credits are usage-limited on the free plan.

### Step 2: Add a data source

From the dashboard, click **Sources** and select your target:

- **Database**: Postgres, MySQL, MongoDB — enter connection credentials
- **API**: Paste an OpenAPI spec or define endpoints manually
- **MCP Server**: Connect to any MCP-compatible server via its URL

### Step 3: Create a Superagent

Navigate to **Superagents** in the sidebar. Click **New Superagent**, choose your connected source, and start typing queries in natural language.

Example prompts:

```
Show me daily revenue from Stripe for the last 30 days
List all users who signed up via Google Analytics in Q2
Summarize PostgreSQL inventory counts by product category
```

The Superagent translates your question into a query, executes it against the source, and returns results as spreadsheet rows.

### Step 4: Build reports

Once data is in the sheet, use Sourcetable built-in pivots and charts to visualize results. Export to Excel or Google Sheets if needed.

## FAQ

**Q: Is the base spreadsheet actually free?**
**A:** Yes. Sourcetable's spreadsheet is free to use like Google Sheets. AI-powered features (including Superagent queries) have per-month credit limits. Upgrade to Pro for more credits.

**Q: Does it support Google Sheets as a data source?**
**A:** The base platform can read/write Google Sheets. Superagents extends this to databases and APIs.

**Q: What MCP servers are compatible?**
**A:** Any server that exposes the standard MCP protocol over HTTP. You provide the server URL during setup.

**Q: Is the underlying AI query translation accurate for complex SQL?**
**A:** For straightforward SELECT/FILTER/GROUP queries, accuracy is high. Very complex joins across multiple sources may require manual SQL refinement.
