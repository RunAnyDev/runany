> **TL;DR:** Taste-Skill là agent skill (28.7k ⭐ GitHub) giúp AI agent như Codex, Cursor, Claude Code tạo frontend có design language thật — không còn generic slop. Cài qua `npx skills add`, prompt bình thường.

## Vấn Đề

AI tạo code nhanh nhưng giao diện... xấu. Không phải xấu do bug — mà xấu vì:

- Layout luôn giống nhau (sidebar + card grid)
- Typography không có hierarchy rõ ràng
- Spacing inconsistent
- Animation y nhau ở mọi nơi
- Font luôn là system-ui, màu luôn là blue-500

Đó gọi là **"AI slop"** — output hợp lệ nhưng nhàm chán, generic, không có "taste".

## Taste-Skill Là Gì?

Taste-Skill là tập hợp **agent skills** cho Codex, Cursor, Claude Code, giúp AI đọc brief rồi tự động áp design language vào code thay vì xuất ra generic UI.

```
npx skills add https://github.com/Leonxlnx/taste-skill
```

### Các skills có sẵn

| Skill | Mô tả |
|---|---|
| `design-taste-frontend` | Default v2 — đọc brief, infer design language, tune VARIANCE/MOTION/DENSITY |
| `design-taste-frontend-v1` | Phiên bản gốc, giữ nguyên cho ai cần |
| `gpt-taste` | Phiên bản strict hơn cho GPT/Codex |
| `image-to-code` | Prompt ảnh → phân tích → code |
| `redesign-existing-projects` | Cải thiện UI project có sẵn |
| `soft-skill` | Premium, calm, expensive look |
| `minimalist-skill` | Notion/Linear vibes |
| `brutalist-skill` | Swiss type, sharp contrast |

### Core concept: ba dials

Taste-Skill v2 hoạt động qua 3 điều chỉnh:

- **VARIANCE** — layout có biến đổi, không lặp lại pattern
- **MOTION** — animation có mục đích, GSAP skeleton chuẩn
- **DENSITY** — spacing và typography có hierarchy rõ

Agent đọc brief → infer design direction → tune 3 dials → output code có taste thật.

## Setup

### 1. Cài đặt agent skill

```bash
# Cài toàn bộ skills
npx skills add https://github.com/Leonxlnx/taste-skill

# Hoặc cài từng skill
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

### 2. Kết hợp với Codex / Cursor

Dùng Codex:

```bash
# Khởi động Codex
codex

# Paste vào terminal:
# Follow skill: design-taste-frontend
# Context: tạo landing page cho AI writing tool
```

Dùng Cursor:

```
/skill design-taste-frontend
tạo landing page cho AI writing tool
```

### 3. Workflow Image-to-Code

Nếu muốn dùng ảnh reference:

```bash
# 1. Cài skill
npx skills add https://github.com/Leonxlnx/taste-skill --skill "image-to-code"

# 2. Prompt cho ChatGPT Images / Codex Image:
# "tạo landing page cho AI writing tool, premium feel, editorial style"

# 3. Feed ảnh vào agent kèm skill:
# "phân tích ảnh này và implement bằng React + Tailwind"
```

## So Sánh

### Không có Taste-Skill
- AI tạo card grid → button → form
- Font: system-ui
- Màu: blue-500 generic
- Spacing: equal everywhere
- Kết quả: *functional but boring*

### Có Taste-Skill
- Agent đọc brief → chọn editorial/brand direction
- Font: Playfair Display + Inter, hierarchy rõ
- Motion: spring easing, staggered reveals
- Kết quả: *frontend có personality*

## Ví Dụ Thực Tế

Prompt cho Codex (không Taste-Skill):

```
tạo landing page cho startup AI
```

Output: Hero → Features → Pricing → CTA. Generic, functional, boring.

Prompt cho Codex (có Taste-Skill):

```
follow skill: design-taste-frontend
brief: landing page cho AI writing startup
direction: editorial, premium, calm
audience: developers, writers
```

Output: Strong typography, whitespace-driven, subtle motion, personality.
