## What Is Context.dev?

Context.dev is a web context API designed for AI agents and LLM pipelines. Instead of juggling browser automation, proxy rotation, and HTML parsers, you call one REST API and get back structured data ready for ingestion.

The product launched on Hacker News in July 2026 as a Y Combinator S26 batch company. Its feature set spans three areas:

1. **Web scraping** — URL to markdown, rendered HTML, or extracted images
2. **Website crawling** — full-site crawl returning one markdown document per page
3. **Brand data** — logos, colors, fonts, company metadata, transaction identification, and AI extraction via custom JSON schemas

Formerly known as Brand.dev, the project rebranded to Context.dev in 2026.

## Setup Workflow

### Step 1: Install the SDK

Pick your language. The API also works with raw HTTP calls.

```bash
# TypeScript / Node.js
npm install context.dev

# Python
pip install context.dev

# Ruby
gem install context.dev

# Go
go get github.com/context-dot-dev/context-go-sdk
```

### Step 2: Get an API Key

Sign up at [context.dev/signup](https://www.context.dev/signup). No credit card is required for the free tier.

Set the key as an environment variable:

```bash
export CONTEXT_DEV_API_KEY="your_key_here"
```

### Step 3: Scrape a URL

```typescript
import ContextDev from 'context.dev';

const client = new ContextDev({ apiKey: process.env['CONTEXT_DEV_API_KEY'] });

// Clean markdown from any URL — ideal for RAG ingestion
const { markdown } = await client.web.webScrapeMd({
  url: 'https://openai.com/pricing'
});

console.log(markdown);
```

### Step 4: Crawl a Full Website

```typescript
// Crawl up to 50 pages at depth 3, returns one markdown doc per page
const { results, metadata } = await client.web.webCrawlMd({
  url: 'https://docs.stripe.com',
  maxPages: 50,
  maxDepth: 3,
  useMainContentOnly: true
});

console.log(`Crawled ${results.length} pages`);
```

### Step 5: Extract Structured Data with a JSON Schema

```typescript
import ContextDev from 'context.dev';
import { z } from 'zod';

const contextDevClient = new ContextDev({ apiKey: process.env['CONTEXT_DEV_API_KEY'] });

const schema = z.object({
  company_name: z.string(),
  pricing_tiers: z.array(
    z.object({
      tier_name: z.string(),
      tier_description: z.string(),
      tier_price: z.number(),
      tier_currency: z.string(),
    })
  ),
});

const result = await contextDevClient.web.extract({
  url: 'https://www.context.dev',
  schema: schema.toJSONSchema(),
});

console.log(result.data.pricing_tiers);
```

### Step 6: Get Brand Data by Domain

```typescript
// Logos, colors, fonts, socials — in one call
const brand = await client.brand.retrieve({ domain: 'stripe.com', type: 'by_domain' });
console.log(brand.logo, brand.primaryColor, brand.font);
```

## Deeper Analysis

### What makes it different from raw scraping

The core value is removing the plumbing. A typical scraping pipeline needs a headless browser, retry logic, JavaScript rendering, and content extraction — Context.dev handles all of that server-side. The API executes JavaScript, waits for dynamic content, and returns cleaned output.

For AI use cases, the markdown endpoint is the primary entry point. It strips navigation, ads, and footers, returning only the readable content — suitable for direct injection into an LLM prompt or storage in a vector database.

### The MCP server

Context.dev ships a Model Context Protocol server. If you are using Claude Code, Cursor, or Windsurf, the MCP server lets the IDE directly query Context.dev without any custom code. The documentation is at [docs.context.dev/integrations/no-code/mcp](https://docs.context.dev/integrations/no-code/mcp).

### Pricing

Pricing is credit-based. The page states "Start free, build for $25" — the free tier covers initial experimentation. At scale, credits are purchased in blocks. Full plan details are at [context.dev/pricing](https://www.context.dev/pricing).

### Agent Authentication

For autonomous agents that need to self-register and obtain credentials without human intervention, Context.dev provides an agentic auth flow documented at [context.dev/auth.md](https://www.context.dev/auth.md). This is notable for workflows where you spin up ephemeral agents that need to call the API on behalf of a user.

## FAQ

**Q: Is there a GitHub repository?**
**A:** Context.dev is not a self-hostable open-source project. It is a hosted API service. The SDKs are published to package registries but the core infrastructure is not open source.

**Q: How does it compare to Firecrawl?**
**A:** The official comparison page at [context.dev/compare/the-top-firecrawl-alternative](https://www.context.dev/compare/the-top-firecrawl-alternative) addresses this. Both do full-site crawling, but Context.dev adds typed entity data (logos, colors, fonts) in the same API rather than requiring separate calls.

**Q: Can I self-host it?**
**A:** No. Context.dev is a hosted API. There is no self-hosted option.

**Q: Does it support streaming?**
**A:** The API is synchronous per call (scrape one URL, crawl one site). For large crawling jobs, the response returns multiple documents in a single payload. Streaming is not currently documented in the API reference.

**Q: What is the free tier limit?**
**A:** Sign-up is free with no credit card required. Full usage limits are on the pricing page at [context.dev/pricing](https://www.context.dev/pricing).
