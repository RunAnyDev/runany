## TL;DR

> **TL;DR:** i-have-adhd is a Claude Code skill that rewrites the agent's output style. Instead of long explanations before the actual answer, the agent surfaces the punchline first, then short supporting bullets. It's a single Python file in a Claude skill format — install it as a skill, trigger it by phrasing, and your agent stops burying the answer under narrative scaffolding.

## What Is i-have-adhd?

i-have-adhd is one of the highest-trending skills on GitHub right now, and the concept is unusually concrete. The repository ships a Claude skill (in the `.skill` format used by Claude Code plugins and Cowork) that overrides the default output style when the trigger description matches. The description on GitHub is short: "A skill to stop your coding agent from burying the answer. ADHD-friendly output." The whole project is built around that single behavior change.

The skill targets a real friction point. Default coding agents tend to write essays — context, caveats, alternatives, then the actual answer. For neurodivergent users, or anyone who wants scannable output, that style is a tax. i-have-adhd flips the ordering: the conclusion comes first, then the minimum context needed to use it, then optional deep-dive sections the user can ignore.

## How It Works

The skill is small and self-contained. You install it as a Claude skill (the project describes download-and-import into Claude Code or Cowork), and once installed, the trigger description activates the rewritten output style. The repo's topics — `adhd`, `claude-code-plugin`, `claude-skills`, `claude-` — confirm it targets the Claude Code plugin ecosystem specifically.

The rewritten style has a few consistent moves:

- Lead with the answer in the first sentence, not the second paragraph.
- Use short bullets for any reasoning the user still needs.
- Push every optional explanation behind a "deep dive" header the reader can skip.
- Drop filler phrases ("It's worth noting that…", "Let me explain…").
- Keep code blocks compact and runnable.

None of that is novel on its own. What's notable is that the skill makes it automatic instead of something you have to ask for every turn.

## When To Use It

i-have-adhd is the right tool when:

- You regularly ask coding agents for short answers and get back essays.
- You want a one-line answer in the first sentence and the rest optional.
- You are working with a Claude Code or Cowork setup that supports the `.skill` format.

It is not a general-purpose agent framework, it does not change which model you use, and it does not install any package — the project is a behavior layer over an existing Claude setup.
