## What Is ProvenMetal?

ProvenMetal is a YC S26-backed PCB manufacturing service that replaces the fragmented manual workflow of sourcing components, coordinating fab houses, and managing assembly through a single platform. Instead of emailing manufacturers for quotes and tracking down out-of-stock parts yourself, you upload your design files and ProvenMetal handles the rest.

The platform is built around two open-source plugins — one for KiCad and one for Altium — that send your bill of materials (BOM) directly to the ProvenMetal ordering platform the moment you finalize a design. The system automatically procures components across US and overseas distributors, selects qualified fabrication and assembly partners, and delivers boards with AOI, X-ray inspection, and functional test.

## Setup Workflow

### Step 1: Install the KiCad or Altium Plugin

The KiCad and Altium plugins are open-source (MIT) and live on GitHub:

```bash
# KiCad plugin
git clone https://github.com/proven-metal/provenmetal-kicad.git
# Follow the install instructions in the repo's README

# Altium plugin
git clone https://github.com/proven-metal/provenmetal-altium.git
# Follow the install instructions in the repo's README
```

Both plugins transmit your BOM to ProvenMetal's platform. Your design files stay on your machine — only the BOM and design metadata are shared.

### Step 2: Configure Your Build Preferences

From within your EDA tool, open the ProvenMetal plugin panel. You can specify:

- **Turn time priority** — Standard (5-7 days) or expedited
- **Assembly location** — US-only assembly or global fab partners with US assembly
- **Test coverage** — AOI only, AOI plus X-ray, or full functional test with bring-up
- **Compliance requirements** — ITAR, AS9100, ISO 9001 (certified partners available)

### Step 3: Submit and Review the Quote

Once you initiate a build, ProvenMetal returns a quote covering:

1. Bare board fabrication
2. Component procurement (auto-sourced across distributor inventory)
3. Assembly in the US
4. Inspection and test

No account is required to see the quote. You approve before anything is ordered.

### Step 4: Automated DFM Review

Before fabrication begins, ProvenMetal runs an automated Design for Manufacturability (DFM) check using Anthropic's Claude model in zero-retention mode — meaning your design data is not used for model training. The review checks panelization, drill tolerances, minimum trace widths, and SMD pad geometry. If the DFM check surfaces issues, a human review with no external AI processing is available as an alternative.

### Step 5: Track and Receive

ProvenMetal manages the full supply chain coordination. You receive tracking at each milestone: board fab complete, components kitted, assembly in progress, inspection passed, shipped.

## Deeper Analysis

### The Problem With Traditional PCB Procurement

Ordering a PCB prototype through a traditional manufacturer involves a multi-day back-and-forth: quote requests, DFM questions, component availability confirmations, and logistics coordination spread across email threads. For quick-turn builds (2-4 layer boards, 5-10 day windows), this overhead can consume a meaningful share of the project timeline.

Component procurement is the sharpest bottleneck. A single out-of-stock part can stall an entire board build. ProvenMetal addresses this by automatically sourcing the full BOM from US and overseas distributors at order time, and — critically — ordering long lead-time parts before layout is finalized when you work with them during the design phase.

### KiCad and Altium Integration

The plugin architecture matters for a specific reason: it closes the loop between design intent and manufacturing input at the earliest possible moment. When you finalize your layout in KiCad or Altium, the BOM is already in ProvenMetal's platform, ready for quote generation and component pre-order. This prevents the common failure mode where a design is layout-complete but unbuildable due to unavailable parts.

Both plugins are MIT-licensed, so the integration code is auditable and forkable.

### Pricing Model

ProvenMetal charges a transparent margin on the order value. The HN launch post notes roughly $70K in revenue across 11 orders in the first six weeks post-launch. The platform aggregates fabrication, assembly, and component procurement under one invoice rather than requiring you to coordinate separate vendors.

## FAQ

**Q: Does ProvenMetal work with open-source EDA tools other than KiCad?**
**A:** Currently the primary integrations are KiCad and Altium via open-source plugins. Support for other EDA tools would need to be evaluated against the current platform API.

**Q: Can I get a quote without creating an account?**
**A:** Yes. The website allows you to upload design files and review the full quote — scope, price, and ship date — before approving anything. No account is required to see pricing.

**Q: What happens if a component is out of stock?**
**A:** The system automatically checks distributor inventory across US and overseas channels. If a part is unavailable, ProvenMetal suggests alternatives and can proceed with your approval once an acceptable substitute is confirmed.

**Q: Is there a minimum order size?**
**A:** The platform is optimized for prototype and small-batch runs (typically 1-50 units). For high-volume orders, contact ProvenMetal directly for a custom quote.

**Q: How is the automated DFM review different from a human review?**
**A:** The automated check uses Claude to catch panelization issues, drill tolerance problems, and pad geometry violations at machine speed. A human review adds context-aware engineering judgment. ProvenMetal offers the automated path as the default and a human-only path for designs requiring tighter control.

## Conclusion

ProvenMetal targets a specific pain point that every hardware engineer recognizes: the gap between a finished PCB layout and a physically assembled board on your bench. By automating BOM procurement, connecting directly to fabrication and assembly partners, and running DFM checks before fab starts, it collapses a typically 2-3 week process into 5-7 days.

The open-source KiCad and Altium plugins are the right abstraction — the design tool is where manufacturing decisions get made, and bridging that gap at the source is more efficient than chasing quotes after the fact.

For hardware teams running quick-turn iterations, or individual engineers who want manufacturing-grade PCBs without a procurement degree, ProvenMetal is worth evaluating.
