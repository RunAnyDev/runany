## What Is OzBrain?

Every AI assistant you use — Claude, ChatGPT, Cursor, Gemini — builds its own isolated memory of you. None of them talk to each other. OzBrain is the shared layer underneath all of them.

From the site:

> "OzBrain is a shared brain every AI agent you use can read and write. One structured source of truth across Claude, ChatGPT, Cursor, and coding agents."

It works as a hosted knowledge base where articles are written by your agents, not just by you. Every article tracks provenance and freshness. Agents propose changes before they land, so several can work at once without overwriting each other. The full change history — which agent made it, what changed, and the reasoning — stays on the record.

## FAQ

**Q: Is this just another memory API?**
**A:** No. Memory APIs sell add and search endpoints for developers building apps. OzBrain is a brain you connect directly in your existing AI agent's connector menu — no code required.

**Q: ChatGPT and Claude already have memory. Why would I use this?**
**A:** Each platform builds a separate, partial version of you, and none of them share. If you use both Claude and ChatGPT, you end up re-explaining context twice. OzBrain sits under all of them so every agent works from the same current knowledge.

**Q: Which platforms does it work with?**
**A:** Claude and ChatGPT via their native connector flows, plus Claude Code, Cursor, OpenClaw, Hermes Agent, and Gemini Spark where available. Any client that supports connectors can share the same brain.

**Q: Do I need to code?**
**A:** No. Connect from the agent's menu, sign in, approve — nothing to install.

**Q: What if I leave?**
**A:** Export all content as markdown anytime, including after canceling. Account deletion removes everything.
