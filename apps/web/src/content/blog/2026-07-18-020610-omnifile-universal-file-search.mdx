## TL;DR

> **TL;DR:** OmniFile is a cross-platform desktop app that searches local drives and seven cloud services (Google Drive, Dropbox, Box, SharePoint, Slack, Notion) from a single keyboard shortcut. Built with Tauri and Rust, indexes stay local, and a Pro lifetime license costs $129.

## What Is OmniFile?

OmniFile is a desktop file-search tool that unifies local filesystem search with cloud storage integrations. Instead of opening GDrive in a browser, Dropbox on the web, and Finder for local files, you press one keyboard shortcut and search everything from OmniFile. It is built with [Tauri](https://tauri.app), [React](https://react.dev), and [TypeScript](https://www.typescriptlang.org) on the frontend, with a [Rust](https://www.rust-lang.org) backend for performance and secure file handling.

The product launched on Hacker News in early 2026 and caught attention for its privacy-first approach — all indexing happens locally, so cloud credentials never leave the machine.

## Setup

OmniFile is available for macOS and Windows. Installation is straightforward:

### Step 1: Download

Visit [omnifile.app](https://omnifile.app) and click **Download**. The installer is 11 MB and takes about 60 seconds to become ready after installation.

### Step 2: Grant Permissions

On first launch, OmniFile requests access to:

- **Local files** — standard filesystem access for local drive indexing
- **Cloud accounts** — OAuth connections for each service you want to integrate (Google Drive, Dropbox, Box, SharePoint, Slack, Notion)

### Step 3: Configure Cloud Integrations (Optional)

Open **Settings → Integrations** and connect the cloud services you use. Each integration uses OAuth and stores credentials locally — no cloud-based auth servers are involved.

### Step 4: Search

Press the global keyboard shortcut (default: `Ctrl+Space` on Windows, `Cmd+Space` on macOS) to open the search bar. Type your query and OmniFile returns results from all configured sources in ranked order.

## Features

### Unified Search

Query local files and all connected cloud services simultaneously. OmniFile maintains a local index updated in the background as files change.

### Cloud Integrations

OmniFile currently supports seven cloud services:

- Google Drive
- Dropbox
- Box
- SharePoint
- Slack
- Notion
- OneDrive (implied by SharePoint)

### Fuzzy Search

The search uses fuzzy matching, so `annul rept` matches `Annual Report.pdf`.

### File Preview and Quick Actions

Results show file previews and quick actions — open, share, or reveal in the native app.

### Privacy-First Architecture

All indexing happens on-device. Cloud credentials are stored locally and never transmitted to a third-party auth service.

### Cross-Platform

Tauri provides native binaries for both macOS and Windows from a single codebase.

## FAQ

**Q: Does OmniFile upload my files to a server?**
**A:** No. All indexing happens locally on your machine. Cloud credentials are stored locally and used to query cloud APIs directly.

**Q: Can I use it without creating an account?**
**A:** Yes. The free local-search tier requires no signup. Cloud integrations require OAuth but no account creation on OmniFile's side.

**Q: How does it index cloud files?**
**A:** OmniFile queries the cloud APIs (GDrive, Dropbox, etc.) and builds a local index. This index is refreshed in the background when files change.

**Q: Does it work offline?**
**A:** Local search works fully offline. Cloud search requires an internet connection to query the respective APIs.

**Q: Is the Pro license a subscription?**
**A:** No — it is a one-time lifetime purchase ($129) that includes all current and future Pro features.
