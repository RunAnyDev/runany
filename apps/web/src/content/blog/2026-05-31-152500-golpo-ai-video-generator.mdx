## What Is Golpo?

Golpo is a YC S25-backed AI tool that generates whiteboard-style explainer videos. You feed it a document, a README, or a plain-text prompt, and it outputs a video with time-aligned graphics and spoken narration. The target use cases are product onboarding flows, developer tutorials, and internal training docs — content that traditionally requires a video editor, a scriptwriter, and hours of iteration.

The founders ([Shraman and Shreyas Kar](https://news.ycombinator.com/user?id=golpoai)) observed that existing AI video tools excel at cinematic, flashy content but struggle with clarity-driven material: product demos, workflow walkthroughs, and technical explainers. Those still get made manually because the output needs to be coherent and educational, not just visually impressive.

Golpo's engine syncs voice narration to animated graphics, producing output that reads more like a Khan Academy video than a TikTok clip. That makes it directly useful for developer-facing content teams who need to produce documentation at scale without hiring a video production team.

## How It Works

### Step 1: Feed It Content

Paste a document URL, upload a text file, or write a prompt from scratch. Golpo accepts plain text, markdown, and HTML inputs. For API documentation or READMEs, pointing it at a raw GitHub URL is the fastest path.

### Step 2: AI Generates Script + Visuals

Golpo's engine parses the input, generates a narration script, and creates synchronized whiteboard-style graphics. The output is not a deepfake or a talking head — it's the hand-drawn diagram aesthetic that has proven effective for explaining technical concepts (think DrawKit or Excalidraw animated).

### Step 3: Export or Embed

The finished video exports as an MP4. You can embed it on a documentation site, attach it to a product changelog, or use it in a developer portal. The embeddable player means you do not need to host the file yourself.

## Why This Is Useful for Developer Content

Writing good documentation is hard. Recording a video walkthrough is harder and slower. A tool that turns a README into a coherent 2-minute explainer closes a real gap — especially for:

- **Library maintainers** who want a quick visual intro without learning video production
- **Developer tool startups** shipping a new API and needing a demo video for the docs
- **Internal platform teams** creating onboarding content for engineering hires

The whiteboard animation style is not a limitation — it is a deliberate choice that keeps the production fast and the output universally readable.

## FAQ

**Q:** Can it handle very long documents?
**A:** The tool processes entire documents in one pass. Very long technical specs may be truncated or summarized by the AI before visual generation. Shorter, focused inputs produce the best results.

**Q:** Does it support languages other than English?
**A:** The narration quality has been optimized for English. Non-English inputs may work but the narration fidelity will vary.

**Q:** Can I edit the generated video?
**A:** The generated video is a finished export — there is no timeline editor. You regenerate with adjusted input if you want changes. For custom editing, export the MP4 and import into a video editor.

**Q:** Is there an API for programmatic video generation?
**A:** No public API was mentioned in the launch post. The product is currently web-first.

**Q:** How does it compare to tools likeloom or Tapflow?
**A:** Loom records a human talking through a screen. Golpo generates an animated explainer without a presenter. They solve different problems — Golpo is for scalable, repeatable content; Loom is for personal screen recordings.

## Conclusion

Golpo fills a specific niche that AI video tools have largely ignored: clarity-first explainer content for technical audiences. By targeting whiteboard-style narration rather than cinematic generation, it produces output that is faster to make and easier to consume for developer documentation. If you regularly create technical tutorials, product demos, or onboarding content, it is worth a 10-minute experiment on the free tier. The time savings over manual video production compounds quickly at scale.
