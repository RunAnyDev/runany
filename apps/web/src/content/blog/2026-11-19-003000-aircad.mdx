> **TL;DR:** Aircad puts 2D drafting and 3D solid modeling in a browser tab, with a command line of 151 commands, real-time multiplayer editing, and an AI agent that drafts every change for you to apply or discard. The free tier covers three personal files, Pro is $19 a month, and Team is $35 per editor.

## What Aircad actually is

Aircad is a CAD application you open in a browser tab. It draws 2D and models 3D solids in the same file, at the same time, from the same command line. No installer, no local save path, and no separate modeler: a Timber pavilion and its floor plan sit in one workspace with split views showing a selected curved member next to the roof material and a structural assembly sheet.

That combination is unusual enough to be worth a closer look. Most "browser CAD" products turn out to be a viewer with a pen tool bolted on. Aircad's own comparison pages go head to head with AutoCAD, Rhino, SketchUp, Onshape, BricsCAD, DraftSight, QCAD and LibreCAD, which is the kind of claim a thin viewer does not usually make. It launched on Hacker News on November 10, 2026 and picked up 96 points.

The part that matters most in practice is not the modeling. It is that the AI agent inside the editor is bound to the same file model the human commands use, and that every change it makes has to be approved before it lands.

## The command line carries the work

Aircad has 151 commands, and the whole set is reachable from one text field. The [command reference](https://aircad.com/docs/commands) groups them the way an AutoCAD user expects: Draw, Annotate, Modify, and onward. There are separate commands for every dimension type you would care about, including the awkward ones. `DimJoggedRadius` exists for an arc whose center is too far away to draw a radius to, and `DimDistribute` spaces parallel dimensions out from a base one.

The syntax is the familiar AutoCAD dialect. From the [Line command page](https://aircad.com/docs/commands/line), you type `Line` or its shortcut `l`, then click or type points. A relative offset uses `@`, so `@5,3` moves 5 across and 3 up from the start point. You can lock a length and then swing the pointer, or lock an angle with a degree mark such as `30deg`, and the line follows.

```text
l
0,0
@5,3
```

Typed coordinates work on the command line too, so a whole line can be placed without a click:

```text
Line start=0,0 end=10,5
```

Dimensions follow the geometry they measure, which is the detail that separates a real CAD tool from a drawing app. Change the arc and the radius dimension rides along with it.

## The agent drafts, you approve

The AI features live on the command line. Press Cmd+J on macOS or Ctrl J on Windows and the input field turns into an agent prompt. You can also type `Agent` followed by a question and it fires as an ordinary command.

There are four distinct jobs behind that one button, and they are worth separating because they fail differently. Ask answers questions about the file. Edit describes a change and produces a draft. Commands writes a real command you can then run like any other. Render repaints a framed view as an image, with styles like Photoreal, Watercolor, Marker sketch, Clay and Dusk, up to four at a time.

![The Aircad command line switched into agent mode, with a question typed and the model menu visible](https://cdn.runany.dev/blog/inline/aircad-agent.webp)

What the agent does not do is guess. According to the [agent documentation](https://aircad.com/docs/ask), it never receives a pasted drawing. It starts from an overview of units, spaces, layers, styles, blocks and the current selection, sees the commands you have run since your last question, and reads the rest by running short read-only scripts against the script API. When it needs a point or a set of edges, it asks you on the canvas, with snaps and typed coordinates working the same way they do for a human.

Everything it changes arrives tinted on the canvas with a question. Apply with Enter, discard with Escape, or reply in plain words ("make them 1200 wide instead") and it drafts the whole thing again. An applied change is a single undo step, so the escape hatch never gets expensive. There is also an auto-apply toggle for people who get tired of confirming.

You can bring your own model. The list on the [AI page](https://aircad.com/ai) covers Auto, Claude, GPT, Gemini, DeepSeek and GLM, with Auto picking for you at the standard rate. Aircad also runs an MCP server, so Claude, ChatGPT, Codex or Gemini can read the file you have open and draft changes you still review on the canvas. The MCP connection is free on every plan, including Free.

## Multiplayer editing and a version history

Sharing a file gives everyone the same live drawing rather than a copy. You can see who is working where, and each edit shows up for everyone as it happens. The design goal here is to kill the `final_v3.pdf` workflow, which is a problem every CAD shop has and most CAD software leaves in place.

Review is folded into the same app. Comments attach to the geometry they refer to, redlines and marked-up PDFs are included, and the pricing page is explicit that no separate review subscription is required. Access is split by role: editors need a seat, while anyone who only opens, comments or reviews is a viewer and viewers are free.

Version history is unlimited, with an activity feed recording who changed what and when. You can compare any two revisions and see additions, changes and deletions tinted directly in the drawing, fork from any point in the history to experiment without touching the original, and restore an earlier version whenever you need to.

## Files, formats, and a JavaScript script API

The [import documentation](https://aircad.com/docs/importing) lists what the editor's Import menu accepts: Aircad files, DWG, DXF, SVG, Rhino (`.3dm`), STEP (`.step`, `.stp`), glTF (`.glb`, `.gltf`), STL and OBJ. PNG and JPEG are not on the menu, because those get placed with the Image command instead. You can drag a file straight onto the canvas and Aircad goes by the extension.

| Direction | Formats | Notes |
| --- | --- | --- |
| Import | DWG, DXF, SVG, 3DM, STEP, glTF, STL, OBJ | DWG and DXF keep layouts, layers, blocks and dimensions |
| Export | DWG, DXF, PDF, Rhino | DWG and DXF are written in AutoCAD 2018 format |
| Model export | STEP, GLB, STL, OBJ | Greyed out while a layout is showing |

The AutoCAD 2018 note matters if you have older downstream software. Every AutoCAD since 2018 opens what Aircad writes, but anything older than that is out of reach. Conversions happen on Aircad's servers, and the download starts when the file is ready rather than immediately.

Scripting is where this gets more interesting than the usual browser CAD story. The [script API](https://aircad.com/docs/script-api) is JavaScript running on the same API the built-in commands use. A script is a module that imports from `"aircad"` and exports a default `main(cad)`. Geometry is treated as values, so `Curve.line(a, b)` creates a line without touching the file, and `cad.doc.add` is the single call that puts a value in. A run is one transaction and one undo step: it commits when `main` returns, and nothing survives a thrown error or an Escape keypress.

Here is the Torus command from the docs, abridged to the body of the function:

```javascript
export default async function main(cad) {
  const center = await cad.input.point("center");
  const ring = cad.display.show();
  const major = await cad.input.length("majorRadius", {
    from: center,
    onChange: (r) => ring.set(Curve.circle(Plane.at(center), r)),
  });
  const body = cad.display.show();
  const minor = await cad.input.length("tubeRadius", {
    from: Vec3.add(center, Vec3.of(major, 0)),
    onChange: (r) => body.set(r < major ? BRep.torus(Plane.at(center), major, r) : null),
  });
  if (!(minor < major)) throw new Error("The tube radius must be smaller than the major radius.");
  return cad.doc.add(BRep.torus(Plane.at(center), major, minor));
}
```

A command adds a manifest with a name, a `kind` of `"command"`, the capabilities it needs, and its declared inputs. The host grants no more than the manifest lists, and scripts run in a sandbox with no network access. That last point is worth repeating, because scripts in a CAD file are exactly the kind of thing that has historically been a security problem.

## What it costs

The [pricing page](https://aircad.com/pricing) has three tiers, and the interesting wrinkle is a "Founder's Club" that discounts new accounts for as long as they stay subscribed, open until January 31, 2027 or until the places run out.

| Plan | Price | Key limits and inclusions |
| --- | --- | --- |
| Free | $0 forever | 3 personal files, 3 DWG or DXF conversions a month, 30 days of version history, 200 AI credits |
| Pro | $19 per month, or $190 per year | Unlimited files, unlimited DWG and DXF import and export, full version history and restore, published libraries, monthly AI allowance |
| Team | $35 per editor per month | Shared workspace and libraries, roles and permissions, pooled AI credits, viewers and reviewers free |

Going over a limit never deletes anything, which is a better failure mode than most. Files past the limit become read-only and editing returns as soon as you are back under it.

## What to watch for

The Free tier is genuinely small, and the 3 DWG or DXF conversions per month count imports as well as exports. If your work involves moving DWG files back and forth, that number is the one to think about first.

DWG output is AutoCAD 2018 format only, and conversions run on Aircad's servers, so exports need a network round trip. AI renders also run on their servers, which the docs frame as a feature since you can close the tab while one finishes, but it means the tab cannot be your only copy of the work.

AI credits are consumed per request and priced by the model you pick, with the cost shown under each answer. Pro and Team get a monthly allowance, and both can buy more. The Founder's Club price is stated as yours for as long as you stay subscribed, which is worth factoring into any plan comparison you do against a competing desktop tool.

Finally, this is a young product. The version history, the MCP server and the command count all describe an editor that is shipping quickly, and the surface area is large enough that some rough edges are likely. The Free plan is the cheapest way to find out whether the command line feels like yours.
