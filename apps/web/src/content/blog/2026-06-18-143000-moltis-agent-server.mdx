## TL;DR

> **TL;DR:** Moltis is a self-hosted AI agent server in Rust — one binary, sandboxed tool execution, memory, voice, and MCP support, with no Node.js or npm required.

## What Is Moltis?

Moltis is an open-source personal agent server built entirely in Rust. Unlike Electron- or Node.js-based agent runners, it ships as a single static binary that runs on a Mac Mini, Raspberry Pi, or any Linux server you own. Every tool call executes inside a sandboxed container (Docker, Podman, or Apple App Container), so your host machine is never exposed to arbitrary tool code.

The project positions itself as a privacy-first, auditable alternative to cloud-hosted agent services. Your API keys never leave your machine — the model interface and agent loop run locally, and all tool execution is containerized by default.

**Core features (from README):**

- Persistent chat sessions with cross-session memory (SQLite + FTS + vector memory)
- Built-in STT and TTS for voice I/O
- Multi-platform messaging: Telegram, Signal, Discord, WhatsApp, Microsoft Teams
- Browser automation, SSH, and MCP server integration (stdio + HTTP/SSE)
- Autonomous skill improvement — the agent can rewrite its own skills
- Auditable codebase: ~270K lines of Rust across 59 workspace crates

## Quick Setup

Moltis installs as a single binary with no runtime dependencies.

### Option 1 — Install script (macOS / Linux)

```bash
curl -fsSL https://www.moltis.org/install.sh | sh
```

### Option 2 — Homebrew

```bash
brew install moltis-org/tap/moltis
```

### Option 3 — Docker

```bash
docker pull ghcr.io/moltis-org/moltis:latest
```

### Option 4 — Build from source

```bash
cargo install moltis --git https://github.com/moltis-org/moltis
```

After installation, run `moltis` to start the server. The web UI handles API key management, tool inventory, and skill configuration.

## Architecture

Moltis is organized as a Rust workspace of 59 crates (~270K lines of Rust, measured by `tokei`). Key crates:

| Crate | Role |
|---|---|
| `moltis-gateway` | HTTP/WS server, RPC, auth |
| `moltis-tools` | Tool execution and sandboxing |
| `moltis-providers` | LLM provider implementations |
| `moltis-agents` | Agent loop, streaming, prompt assembly |
| `moltis-chat` | Chat engine, agent orchestration |

The agent runner and model interface are ~7.5K lines; the full provider abstraction adds ~19K more. Unsafe code is isolated to FFI boundaries and precompiled runtime, not the core agent loop.

## FAQ

**Q: Does Moltis require an API key for the LLM?**
**A:** Yes. Moltis is a server framework — it implements the tool-calling interface for multiple LLM providers (OpenAI, Anthropic, local models, etc.). You provide your own API keys, which are stored in a Vault within the server and never leave your machine.

**Q: How does sandboxing work?**
**A:** Tool execution runs inside Docker, Podman, or Apple's App Container runtime by default. The host never executes tool code directly — the agent sends commands to the sandboxed container over a secure channel.

**Q: Can I run Moltis on a Raspberry Pi?**
**A:** Yes. Moltis is a single static Rust binary with no Node.js or npm dependency. It runs on any ARM64 or amd64 Linux host. The web UI and voice features require more resources, but the core agent server is lightweight.

**Q: What is "autonomous skill improvement"?**
**A:** The agent can rewrite and extend its own bundled skills based on feedback or new requirements. This is distinct from a plugin marketplace — skills are first-class workspace members the agent can inspect and modify.

## Conclusion

Moltis fills a specific niche: users who want a self-hosted agent server without the operational complexity of Node.js, Python environments, or multiple microservices. The Rust binary distribution, containerized tool execution, and Vault-based key management make it one of the most security-conscious open-source agent runners available.

If you are evaluating local AI agent servers and want to avoid runtime dependency hell, Moltis is worth a look. The comparison table in the README is unusually detailed — it directly names OpenClaw and Hermes Agent, which signals the project is confident in its position.
